# 算法笔记：缺失的第一个正数（力扣 41 题）

## 题目描述
给你一个未排序的整数数组 `nums` ，请你找出其中没有出现的最小的正整数。
要求实现时间复杂度为 `O(n)` 并且只使用常数级别额外空间的解决方案。

---

## 核心思路：把数组本身当哈希表

数组长度为 `n`，答案一定在 `[1, n+1]` 范围内（最坏情况是 `1~n` 全出现，答案为 `n+1`）。

所以我们完全可以用**下标 `0 ~ n-1`** 来代表数字 **`1 ~ n`** 是否出现过。

**标记方式**：数字 `x` 出现过，就把下标 `x-1` 位置的值取为**负数**，作为"已出现"的标记。

---

## 图解示例

以 `nums = [3, 4, -1, 1]`，`n = 4` 为例：

### 第 1 步：清理负数和 0

把所有 `<= 0` 的数替换成 `n + 1 = 5`，让它们不影响后续判断（因为 5 超出了我们关心的 `[1, 4]` 范围）。

```
清理前：[3, 4, -1, 1]
清理后：[3, 4,  5, 1]
```

### 第 2 步：遍历每个数，给对应位置"打标记"

遍历每个数 `num`，如果 `num` 在 `[1, n]` 范围内，就把下标 `num - 1` 处的值**取负**，表示"这个数出现过了"。

| 当前值 `num` | 代表数字 | 标记位置（`num - 1`） | 数组变化 |
| :---: | :---: | :---: | :--- |
| 3 | 3 | 下标 2 | `[3, 4, -5, 1]` |
| 4 | 4 | 下标 3 | `[3, 4, -5, -1]` |
| 5 | 5 | `> n`，跳过 | 不变 |
| 1 | 1 | 下标 0 | `[-3, 4, -5, -1]` |

### 第 3 步：找第一个正数的下标

遍历数组，第一个值仍为正数的位置，就是没出现过的最小正数：

```
[-3, 4, -5, -1]
      ↑
   下标 1 是正数 → 答案 = 1 + 1 = 2
```

> **直觉**：下标 `i` 位置是负的，说明 `i+1` 出现过；第一个还是正数的位置，就是没出现过的最小正数。

---

## 代码实现 (Java)

```java
class Solution {
    public int firstMissingPositive(int[] nums) {
        int n = nums.length;

        // 1. 清理负数和 0，替换为 n + 1
        for (int i = 0; i < n; i++) {
            if (nums[i] <= 0) {
                nums[i] = n + 1;
            }
        }

        // 2. 用负号标记：数字 num 出现过，就在下标 num-1 处取负
        for (int i = 0; i < n; i++) {
            int num = Math.abs(nums[i]);
            if (num <= n) {
                nums[num - 1] = -Math.abs(nums[num - 1]);
            }
        }

        // 3. 第一个 nums[i] > 0 的下标 i，i + 1 即为答案
        for (int i = 0; i < n; i++) {
            if (nums[i] > 0) {
                return i + 1;
            }
        }

        // 1 ~ n 全出现了，答案为 n + 1
        return n + 1;
    }
}
```

---

## 复杂度分析

* **时间复杂度**：$O(n)$。三个 `for` 循环各遍历一次数组，总计 $3n$，即 $O(n)$。
* **空间复杂度**：$O(1)$。直接在原数组上用正负号做标记，没有使用额外空间。

---

## 💡 关键点总结

| 要点 | 说明 |
| :--- | :--- |
| **为什么能这样用？** | 答案范围是 `[1, n+1]`，刚好可以用下标 `0 ~ n-1` 一一对应 |
| **为什么第 1 步要清理负数？** | 因为后面要用正负号做标记，原始负数会干扰判断 |
| **为什么用 `-Math.abs()`？** | 防止同一个位置被多次取负后又变回正数（先 `abs` 保证是正数，再取负） |
| **本质** | 把数组自身当作哈希表，用正负号代替额外的 `HashSet` |
