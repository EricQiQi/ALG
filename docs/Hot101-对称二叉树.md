# 对称二叉树（Symmetric Tree）

## 题目描述

给你一个二叉树的根节点 `root`，检查它是否是镜像对称的。

```
对称：               不对称：
     1                    1
    / \                  / \
   2   2                2   2
  / \ / \                \   \
 4  5 5  4               3   3
```

---

## 方法1：遍历对比（自创）

### 思路

左子树做**前序遍历**（根→左→右），右子树做**对称遍历**（根→右→左），比较两个结果是否相同。

```
左子树前序（根左右）：2, 4, 5
右子树对称（根右左）：2, 4, 5    → 相同 ✓

注意：null 也要记录（用 -101 占位），否则 [1,2] 和 [1,null,2] 会误判为相同
```

### 代码

```java
public boolean isSymmetric(TreeNode root) {
    if (root == null) return true;
    List<Integer> leftList = new ArrayList<>();
    preOrder(root.left, leftList);       // 根 左 右
    List<Integer> rightList = new ArrayList<>();
    mirrorOrder(root.right, rightList);  // 根 右 左
    return leftList.equals(rightList);
}

private void preOrder(TreeNode root, List<Integer> res) {
    if (root == null) { res.add(-101); return; }  // null 占位
    res.add(root.val);
    preOrder(root.left, res);
    preOrder(root.right, res);
}

private void mirrorOrder(TreeNode root, List<Integer> res) {
    if (root == null) { res.add(-101); return; }  // null 占位
    res.add(root.val);
    mirrorOrder(root.right, res);
    mirrorOrder(root.left, res);
}
```

## 方法2：递归

### 思路

对称的本质：**左子树的左边 = 右子树的右边，左子树的右边 = 右子树的左边**。

→ 同时传入左右子树的节点，交叉对比。

```
check(p, q)：
  p.left  ↔  q.right    （外侧对外侧）
  p.right ↔  q.left     （内侧对内侧）
```

### 代码

```java
public boolean isSymmetric(TreeNode root) {
    return check(root.left, root.right);
}

public boolean check(TreeNode p, TreeNode q) {
    if (p == null && q == null) return true;
    if (p == null || q == null) return false;
    return p.val == q.val
        && check(p.left, q.right)    // 外侧
        && check(p.right, q.left);   // 内侧
}
```

### 复杂度

| 类型 | 复杂度 | 说明 |
|------|--------|------|
| 时间 | O(n) | 每个节点访问一次 |
| 空间 | O(n) | 递归栈深度，最坏情况退化为链表 |

## 方法3：迭代（BFS）

### 思路

把递归改成队列：每次取出一对 `(u, v)` 对比，然后按**对称顺序**把它们的子节点入队。

### 代码

```java
public boolean isSymmetric(TreeNode root) {
    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);
    queue.offer(root);
    while (!queue.isEmpty()) {
        TreeNode u = queue.poll();
        TreeNode v = queue.poll();
        if (u == null && v == null) continue;
        if (u == null || v == null || u.val != v.val) return false;
        // 对称入队：u的左配v的右，u的右配v的左
        queue.offer(u.left);  queue.offer(v.right);
        queue.offer(u.right); queue.offer(v.left);
    }
    return true;
}
```

---

## 三种方法对比

| | 方法1 遍历对比 | 方法2 递归 | 方法3 迭代 |
|--|--------------|----------|----------|
| 核心思想 | 左前序 = 右对称序 | 交叉递归对比 | BFS 成对出队入队 |
| 代码量 | 较多（两个遍历 + 占位） | 最少 | 中等 |
| 推荐度 | 思路直观但不简洁 | **推荐** | 适合不想递归的场景 |

---

## 易错点

1. **null 必须占位**：方法1中 null 节点要加入特殊值，否则结构不同的树会被误判为对称
2. **递归对比方向**：`p.left` 配 `q.right`，`p.right` 配 `q.left`（交叉比，不是同侧比）
3. **迭代入队顺序**：`u.left, v.right` 一对，`u.right, v.left` 一对（保持对称配对）

## 记忆口诀

```
对称就是照镜子：左的左 = 右的右，左的右 = 右的左。
递归交叉比，迭代成对入队。
```
