# 算法笔记：环形链表 II（力扣 142 题）

## 题目描述
给定一个链表的头节点 `head`，返回链表**开始入环的第一个节点**。如果无环，返回 `null`。

```
输入: head = 1→2→3→4，其中 4 的 next 指回节点 2
输出: 节点 2   （入环的第一个节点）
```

---

## 核心思想

> **在 141 判圈的基础上多一步：相遇后，一个指针回到 head，两指针同速走，再次相遇处就是入环点。**

先用快慢指针找到**相遇点**（证明有环），然后利用一个数学结论定位入口。

---

## 数学推导：为什么"回头同速走"能定位入口

```
head ──a──> [入口] ──b──> [相遇点]
              ↑              │
              └──────c───────┘     环长 = b + c
```

相遇时：
- 慢指针走了 `a + b`
- 快指针走了 `a + b + k(b+c)`（多绕了 k 圈）
- 快是慢的两倍：`a + b + k(b+c) = 2(a + b)`

化简得：**`a = (k-1)(b+c) + c`**

这个式子的含义是：**从 head 走 `a` 步到入口** ＝ **从相遇点走 `c` 步（再加若干整圈）也到入口**。

所以：一个指针从 `head` 出发、一个指针从`相遇点`出发，**同速各走一步**，必在**入口**相遇。

---

## 代码实现 (Java)

```java
public ListNode detectCycle(ListNode head) {
    if (head == null) return null;

    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;                 // 慢走一步
        fast = fast.next.next;            // 快走两步

        if (slow == fast) {               // 相遇，确认有环
            ListNode curr = head;         // 新指针从头出发
            while (slow != curr) {        // 与留在相遇点的 slow 同速走
                slow = slow.next;
                curr = curr.next;
            }
            return curr;                  // 相遇处即入环点
        }
    }
    return null;                          // fast 到尾，无环
}
```

---

## ❗关键易错点

**1. 相遇后 `slow` 保持不动，`curr` 从 head 出发**
不要重置 slow。让 slow 留在相遇点，curr 从 head 出发，两者**同速**（都走一步），相遇即入口。

**2. 循环条件仍是 `fast != null && fast.next != null`**
和 141 一样，保证 fast 能走两步，同时作为无环的退出出口。

**3. 第二阶段是"同速"，不再是快慢**
第一阶段 fast 走两步是为了制造相遇；第二阶段两个指针都走一步，靠的是 `a = c + k圈` 的距离关系。

---

## 复杂度分析

* **时间复杂度**：$O(n)$。第一阶段最多遍历环两圈，第二阶段最多走 `a` 步。
* **空间复杂度**：$O(1)$。仅用常数个指针。
