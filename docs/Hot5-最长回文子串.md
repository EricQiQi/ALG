# 算法笔记：最长回文子串（力扣 5 题）

## 题目描述
给你一个字符串 `s`，找到 `s` 中最长的**回文子串**（正着读、反着读都一样的那一段）。

```
输入：s = "babad"
输出："bab"
解释："aba" 同样是符合题意的答案。

输入：s = "cbbd"
输出："bb"
```

> 📌 关键理解：回文就像"镜子照出来的字"——以中间为轴左右对称。所以找最长回文的本质是**枚举对称中心，从中心往两边扩**，看能扩多远。注意对称中心有两种：一个**字符**（奇数长度，如 `"aba"`）或一个**缝隙**（偶数长度，如 `"abba"` 中间那条缝），每个位置都要试这两遍。

---

## 解法一：中心扩展法

### 1. 核心思想
站在字符串的每个位置上问一遍："以我为对称中心往两边看，两边字符一样就继续往外走，能走多远？"全程记录扩得最远的那次。

* **枚举中心**：对每个下标 `i` 做两次扩张——
  * 奇数长度：`expand(s, i, i)`，以 `s[i]` 为中心（如 `"aba"`）；
  * 偶数长度：`expand(s, i, i+1)`，以 `s[i]`、`s[i+1]` 之间的缝隙为中心（如 `"abba"`）。
* **扩张规则**：`left`、`right` 指针从中心出发，只要不越界且 `s[left] == s[right]`，就同时向外各走一步。
* **更新答案**：两种中心的较长者若超过 `maxLen`，则更新；起点由中心倒推：`start = i - (len-1)/2`。
* **返回**：`s.substring(start, start + maxLen)`。

### 2. 代码实现 (Java)

```java
class Solution {
    public String longestPalindrome(String s) {
        // 边界处理：空串或单字符直接返回
        if (s == null || s.length() < 2) {
            return s;
        }

        int start = 0;   // 最长回文子串的起始位置
        int maxLen = 1;  // 最长回文子串的长度

        for (int i = 0; i < s.length(); i++) {
            // 情况1：以 s[i] 为中心（奇数长度回文，如 "aba"）
            int len1 = expand(s, i, i);
            // 情况2：以 s[i] 和 s[i+1] 之间为中心（偶数长度回文，如 "abba"）
            int len2 = expand(s, i, i + 1);
            int len = Math.max(len1, len2);

            // 如果找到更长的回文，更新记录
            if (len > maxLen) {
                maxLen = len;
                start = i - (len - 1) / 2;  // 由中心倒推起始位置
            }
        }
        return s.substring(start, start + maxLen);
    }

    /** 从中心 (left, right) 向两边扩展，返回回文串长度 */
    private int expand(String s, int left, int right) {
        while (left >= 0 && right < s.length() && s.charAt(left) == s.charAt(right)) {
            left--;
            right++;
        }
        // 循环结束时 left 和 right 已多走一步，实际长度 = right - left - 1
        return right - left - 1;
    }
}
```

### 3. 复杂度分析
* **时间复杂度**：$O(n^2)$。字符串共 `2n-1` 个中心（n 个字符 + n-1 个缝隙），每个中心最坏扩 `O(n)` 步。
* **空间复杂度**：$O(1)$。只用了几个变量。

### 4. 扩展过程图解
以 `s = "babad"` 为例，只看关键的两个中心：

```text
中心 i=1（'a'）：  b (a) b a d   → b=b 继续扩，d≠越界停 → "bab"，长度 3 ✓
中心 i=2（'b'）：  b a (b) a d   → a=a 继续扩，b≠d 停    → "aba"，长度 3（并列）
中心缝隙 i=2：     b a b (a|d)   → a≠d，一步都不扩       → 长度 0

maxLen=3, start = 1 - (3-1)/2 = 0 → 返回 "bab"
```

> 直观记忆：**"一个中心，两边开花"** —— 枚举中心、双向扩张；中心有两种（字符本身、字符缝隙），别漏了偶数那半边。

## 解法二：动态规划（区间 DP）

### 1. 核心思想
反过来想：**一个大回文，掐头去尾之后，一定还是回文**。所以只要知道里层 `s[i+1..j-1]` 是不是回文，再加上两端字符相等，就能断定外层 `s[i..j]` 也是回文。

* **状态定义**：`dp[i][j]` = 子串 `s[i..j]` 是不是回文（true/false）。
* **状态转移**：
  $$dp[i][j] = (s[i] == s[j]) \ \&\& \ dp[i+1][j-1]$$
* **边界（初始条件）**：单个字符 `dp[i][i] = true`；长度 ≤ 3 且两端相等，直接就是回文（无需再看里层）。
* **填表顺序**：`dp[i][j]` 依赖**左下方**的 `dp[i+1][j-1]`，所以要按**子串长度从小到大**枚举，保证用到的短子串已算好。
* **记录答案**：每当 `dp[i][j]==true` 且 `len > maxLen`，就更新 `start=i`、`maxLen=len`。

### 2. 代码实现 (Java)

```java
class Solution {
    public String longestPalindrome(String s) {
        if (s == null || s.length() < 2) {
            return s;
        }

        int n = s.length();
        boolean[][] dp = new boolean[n][n];  // dp[i][j]: s[i..j] 是否回文
        int start = 0;
        int maxLen = 1;

        // 初始化：单个字符都是回文
        for (int i = 0; i < n; i++) {
            dp[i][i] = true;
        }

        // 按子串长度从小到大遍历
        for (int len = 2; len <= n; len++) {
            for (int i = 0; i + len - 1 < n; i++) {
                int j = i + len - 1;  // 子串结束位置

                if (s.charAt(i) != s.charAt(j)) {
                    dp[i][j] = false;
                } else if (len <= 3) {
                    // 长度 ≤ 3，两端相等就是回文
                    dp[i][j] = true;
                } else {
                    dp[i][j] = dp[i + 1][j - 1];
                }

                // 更新最长记录
                if (dp[i][j] && len > maxLen) {
                    maxLen = len;
                    start = i;
                }
            }
        }
        return s.substring(start, start + maxLen);
    }
}
```

### 3. 复杂度分析
* **时间复杂度**：$O(n^2)$。双重循环填满整张表。
* **空间复杂度**：$O(n^2)$。二维 `dp` 表（比中心扩展多，这是它性价比低的主因）。

### 4. 填表过程图解
以 `s = "babad"` 为例，先对角线全 true（单字符），再按长度 2→5 逐层填：

```text
len=1：dp[i][i] 全 true
len=2：b≠a、a≠b、b≠a、a≠d            → 全 false
len=3：b(a)b ✓、a(b)a ✓、b(a)d ✗      → dp[0][2]、dp[1][3] = true（maxLen=3）
len=5：b≠d                              → false
返回 s.substring(0, 3) = "bab"
```

> 直观记忆：**"两端相等 + 里层回文，才叫回文"** —— 从对角线（单字符）出发，一层一层往右上方包抄。

## 💡 总结
最长回文子串有两种主流写法：**中心扩展**把题目转化为"枚举 2n-1 个对称中心、各自向外扩张取最大"，空间最省、面试首选；**区间 DP** 则用"大回文掐头去尾还是回文"把问题拆成子区间查表，思路更通用但多吃 $O(n^2)$ 空间。两者本质都是在利用**回文的对称性**，只是一个"从中心往外扩"，一个"从外层往内查"。

| 特性 | 解法一：中心扩展 | 解法二：动态规划 |
| :--- | :--- | :--- |
| **思维出发点** | 以中心为轴向外扩，`s[left]==s[right]` 就继续走一步 | 两端相等 + 里层回文，则外层回文 |
| **状态/结构** | 无需状态表，`expand(left, right)` 现场扩 | `dp[i][j]` 二维表，按长度从小到大填 |
| **奇偶处理** | 显式试两种中心（字符、缝隙） | 天然覆盖，靠 `len<=3` 特判短串 |
| **时间 / 空间** | $O(n^2)$ / $O(1)$ | $O(n^2)$ / $O(n^2)$ |
| **适用场景** | 面试首选、手撕标配 | 练区间 DP 思想、作为对照解法 |

> 🔧 其他解法（本题未实现）：
> * **Manacher（马拉车）**：插入 `#` 统一奇偶 + 复用左侧镜像答案，做到 $O(n)$，实战答到中心扩展即可，马拉车作为口述加分项。

> ⚠️ 易错点：
> *中心扩展版*
> 1. **奇偶两种中心都要试**——只写 `expand(s, i, i)` 会漏掉 `"cbbd"` 里的 `"bb"`。
> 2. **`expand` 返回 `right - left - 1`**——循环退出时左右指针都已多走一步，长度要减回来（可用 `"a"` 验证：left=-1, right=1，返回 1）。
> 3. **起点倒推公式 `i - (len-1)/2` 奇偶通用**——别按奇偶分情况自己算，容易差一。
> *动态规划版*
> 4. **填表必须按长度从小到大**——`dp[i][j]` 依赖左下方的 `dp[i+1][j-1]`，若按行列顺推会用到还没算的值。
> 5. **短串要特判**——`len<=3` 时里层区间 `dp[i+1][j-1]` 非法（左端大于右端），两端相等即回文，直接置 true。
> 6. **对角线 `dp[i][i]=true` 别忘了初始化**——否则长度 1 的兜底答案就丢了。
> *两版通用*
> 7. **先做边界处理**——`null` 或长度小于 2 直接返回，避免后续 `maxLen=1` 的初值与空串冲突。
