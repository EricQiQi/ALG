# 二叉树的 DFS 与 BFS

## 一句话概括

| 策略 | 方向 | 数据结构 | 对应题目 |
|------|------|---------|---------|
| **DFS（深度优先）** | 一条路走到黑，撞墙再回头 | 递归 / 栈 | Hot94 前序、中序、后序 |
| **BFS（广度优先）** | 一层一层往外扩 | 队列 | Hot102 层序遍历 |

```text
DFS 路径（以"一路向左"为例）：        BFS 路径（逐层扩散）：

      1                                   1
     / \                                / \
    2   3         先扎到底             2   3          一层层来
   / \            再横着走            / \
  4   5                              4   5

  1→2→4→5→3                         1 → 2,3 → 4,5
```

---

## DFS 详解

DFS 的核心是**递归**，三种遍历只是 `add` 的位置不同：

```text
          前序           中序           后序
          ────           ────           ────
递归前     add            ↓              ↓
递归左      ↓            add             ↓
递归右      ↓             ↓            add
```

- **前序**（根左右）：先 add，再递归左右
- **中序**（左根右）：先递归左，add，再递归右
- **后序**（左右根）：先递归左右，最后 add

> 迭代版用**栈**模拟递归，详见 → [Hot94-二叉树的中序遍历](Hot94-二叉树的中序遍历.md)

### 适用场景

| 场景 | 为什么用 DFS |
|------|-------------|
| 路径问题（求和、找路径） | 天然沿着路径深入，回溯方便 |
| 二叉搜索树 | 中序遍历 = 有序序列 |
| 判断对称/翻转/相同 | 递归比较左右子树 |
| 求最大深度/最小深度 | 递归一行搞定 |

---

## BFS 详解

BFS 的核心是**队列 + `size` 锁定层**：

```text
Queue: [1] → poll 1, 入队 2,3 → [2,3] → poll 2,3, 入队 4,5 → [4,5]
       第0层              第1层                    第2层
```

关键代码：
```java
int size = queue.size();   // 锁定当前层
for (int i = 0; i < size; i++) {
    TreeNode node = queue.poll();
    // 处理 node，子节点入队
}
```

> 完整实现及变体详见 → [Hot102-二叉树的层序遍历](Hot102-二叉树的层序遍历.md)

### 适用场景

| 场景 | 为什么用 BFS |
|------|-------------|
| 层序遍历 / 按层输出 | 天然按层组织 |
| 最短路径 / 最小深度 | 第一次到达就是最短 |
| 右视图 / 左视图 | 每层取最后一个 / 第一个 |
| 锯齿形遍历 | 奇偶层交替正序逆序 |

---

## DFS vs BFS 对比

| 维度 | DFS | BFS |
|------|-----|-----|
| 数据结构 | 递归（调用栈）/ Stack | Queue |
| 遍历方向 | 纵向深入 | 横向逐层 |
| 时间复杂度 | O(n) | O(n) |
| 空间复杂度 | O(h)，h 为树高 | O(n)，最宽层节点数 |
| 代码风格 | 递归 3 行模板 | while + size 锁定 |
| 适合问题 | 路径、深度、BST | 层序、最短、按层统计 |

### 极端情况分析

```text
链状树（退化成链表）：     满二叉树：

    1                         1
     \                      / \
      2                    2   3
       \                  / \ / \
        3                4  5 6  7

DFS 栈深 = n（最深）      DFS 栈深 = log n（最浅）
BFS 队列 = 1（最省）      BFS 队列 = n/2（最费）
```

## 选型口诀

```
求深度、找路径、BST 排序 → DFS
求最短、按层统计、层序输出 → BFS
拿不准 → 先想 DFS（代码最短）
```
