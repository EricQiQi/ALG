# 算法笔记：最长公共子序列（力扣 1143 题）

## 题目描述
给定两个字符串 `text1` 和 `text2`，返回这两个字符串的**最长公共子序列的长度**。如果不存在公共子序列，返回 0。

**子序列**：从原字符串中**删除若干字符（可以不删）**、不改变剩余字符相对顺序得到的新串。如 `"ace"` 是 `"abcde"` 的子序列（删掉 `b`、`d`）。

```
输入：text1 = "abcde", text2 = "ace"
输出：3
解释：最长公共子序列是 "ace"，长度为 3。

输入：text1 = "abc", text2 = "abc"
输出：3

输入：text1 = "abc", text2 = "def"
输出：0
解释：两个字符串没有公共子序列。
```

> 📌 关键理解：区分**子序列 vs 子串**——子序列可以跳着取（不连续），子串必须连续。"中间可以挖洞"让暴力枚举变成天方夜谭，但也带来一个优秀的性质：**只依赖两个前缀的匹配情况**，天然适合二维 DP。

---

## 解法：多维动态规划（二维 DP 表）

### 1. 核心思想
把「两个前缀各取一段，比到末尾最多能对齐多长」定义为状态，按**两个字符串的当前字符是否相等**分类讨论。

* **状态定义**：`dp[i][j]` = `text1` 前 `i` 个字符与 `text2` 前 `j` 个字符的最长公共子序列长度。
* **状态转移**：比较 `text1[i-1]` 与 `text2[j-1]`：
  * **相等**：这个字符必然可以加入公共子序列，接在两个都去掉当前字符的子问题上：
    $$dp[i][j] = dp[i-1][j-1] + 1$$
  * **不等**：至少有一边的当前字符进不了 LCS，丢弃哪边更优取 max：
    $$dp[i][j] = \max(dp[i-1][j],\ dp[i][j-1])$$
* **边界（初始条件）**：`dp[0][j] = dp[i][0] = 0`——任何串和"空前缀"的 LCS 是 0，Java 数组默认值即满足，**无需显式初始化**。
* **返回**：`dp[m][n]`。

> 下标约定：`dp` 开 `(m+1) x (n+1)`，`dp[i][j]` 对应的是字符 `text1[i-1]`、`text2[j-1]`——多出的第 0 行/列是"空前缀"哨兵，省去边界特判。

### 2. 代码实现 (Java)

```java
class Solution {
    public int longestCommonSubsequence(String text1, String text2) {
        int m = text1.length();
        int n = text2.length();
        int[][] dp = new int[m + 1][n + 1];  // dp[i][j]: 前i个 vs 前j个 的 LCS 长度

        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (text1.charAt(i - 1) == text2.charAt(j - 1)) {
                    // 两边当前字符配对入 LCS，接在左上方旧答案上
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                } else {
                    // 配不上：放弃 text1 当前字符(上) 或 text2 当前字符(左)，取优
                    dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
                }
            }
        }
        return dp[m][n];
    }
}
```

### 3. 复杂度分析
* **时间复杂度**：$O(m \times n)$。双重循环，每格 $O(1)$。
* **空间复杂度**：$O(m \times n)$。二维 DP 表。

### 4. 填表过程图解
以 `text1 = "abcde"`、`text2 = "ace"` 为例（行 = `abcde`，列 = `ace`，第 0 行列为空前缀）：

```text
        ""  a  c  e
    ""   0  0  0  0
     a   0  1  1  1     ← a=a ✓ 左上+1
     b   0  1  1  1     ← b≠a/b≠c，取 max(上,左)
     c   0  1  2  2     ← c=c ✓ 接左上"1"变 2
     d   0  1  2  2
     e   0  1  2  3     ← e=e ✓ 接左上"2"变 3
返回 dp[5][3] = 3（即 LCS "ace"）
```

> 直观记忆：**相等看左上角 +1，不等取上、左较大值**——对角线是"配对成功"，横向纵向是"放弃一边继续找"。

---

## 💡 总结
最长公共子序列是**双串二维 DP 的模板题**：状态 `dp[i][j]` 表示两个前缀的 LCS 长度，当前字符"相等则左上 +1，不等则取上/左较大者"。多开一行一列当哨兵，边界全为 0，代码可以写得非常短。它与「不同路径/最小路径和」同属二维网格 DP，只是这里网格的行列分别代表两个串的前缀长度。

| 特性 | 说明 |
| :--- | :--- |
| **思维出发点** | 子序列可跳着取，末尾字符要么配对（左上+1），要么至少弃一边（max(上,左)）。 |
| **边界** | 第 0 行/第 0 列 = 0（空前缀），Java 默认值免初始化。 |
| **时间 / 空间** | $O(mn)$ / $O(mn)$。 |

> 🔧 相关变体：
> * **空间优化到 $O(n)$**：`dp[i][j]` 只依赖左上、上、左三格，可压成一维滚动数组，但需临时变量保存"左上旧值"（接最小路径和滚动数组的思路，但多一个斜角依赖，更难写）。
> * **输出 LCS 本身而非长度**：从 `dp[m][n]` 沿"相等走左上、不等走向值相等的一边"回溯即可。
> * **最长公共子串**：不等时直接归 0（`dp[i][j] = dp[i-1][j-1] + 1` 或 0），答案是全表最大值而非右下角——一字之差，体现"子串必须连续"。

> ⚠️ 易错点：
> 1. **`charAt(i-1)` 别写成 `charAt(i)`**——`dp` 的下标比字符串多 1（第 0 行/列是空前缀），字符比较必须回退一位，否则越界或错位。
> 2. **不等时是 max(上, 左)，不是 max(上, 左, 左上)**——左上一定 ≤ 上/左之一（少加 1 的旧状态），带上它不影响结果，但逻辑上不需要。
> 3. **子序列 ≠ 子串**——若误按"连续"处理（不等就归 0），求的是公共子串，示例 `"abcde"/"ace"` 会得到 1 而不是 3。
> 4. **循环上界是 `i <= m`、`j <= n`**——因为 dp 表多开了一行一列，写成 `< m` 会漏掉最后一行/列，右下角永远算不到。
