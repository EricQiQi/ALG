# 反转链表（Reverse Linked List）

## 题目描述

给你单链表的头节点 `head`，反转链表并返回。

```
输入：1 → 2 → 3 → 4 → 5
输出：5 → 4 → 3 → 2 → 1
```

---

## 方法1：迭代

### 思路

逐个节点把 `next` 指向前一个节点。需要三个指针：`prev`（前一个）、`curr`（当前）、`next`（暂存下一个）。

```
初始：  null ← 1    2 → 3 → 4 → 5
        prev   curr  next

第1步：  null ← 1 ← 2    3 → 4 → 5
              prev   curr  next

...直到 curr == null，prev 就是新头
```

### 代码

```java
public ListNode reverseList(ListNode head) {
    ListNode prev = null;
    ListNode curr = head;
    while (curr != null) {
        ListNode nextTemp = curr.next;  // 先存下一个
        curr.next = prev;               // 反转指向
        prev = curr;                    // prev 前进一步
        curr = nextTemp;                // curr 前进一步
    }
    return prev;
}
```

### 复杂度

| 类型 | 复杂度 |
|------|--------|
| 时间 | O(n) |
| 空间 | O(1) |

---

## 方法2：递归

### 思路

**假设 `reverseList(head.next)` 已经帮我把后面都反转了：**

```
原始：  1 → 2 → 3 → null
                ↑
        reverseList(head.next) 已反转后面：
        1 → 2 ← 3
                ↑ newHead = 3

现在只需要：
  head.next.next = head   →  1 ← 2 ← 3
  head.next = null        →  1 断开（变成尾部）
  return newHead
```

### 代码

```java
public ListNode reverseList(ListNode head) {
    if (head == null || head.next == null) return head;
    ListNode newHead = reverseList(head.next);
    head.next.next = head;   // 让下一个节点指回自己
    head.next = null;        // 自己断开
    return newHead;
}
```

### 复杂度

| 类型 | 复杂度 |
|------|--------|
| 时间 | O(n) |
| 空间 | O(n) 递归栈 |

---

## 两种方法对比

| | 迭代 | 递归 |
|--|------|------|
| 空间 | O(1) | O(n) 递归栈 |
| 代码 | 4行，需要3个指针 | 3行核心，但理解门槛高 |
| 思维 | 一步步翻 | 相信递归能搞定后面，只管当前节点 |
| 面试建议 | **必须会** | 加分项 |

---

## 易错点

1. **迭代法 nextTemp 不能漏**：必须先存 `curr.next` 再反转，否则丢失后续链表
2. **递归法 prev 初始为 null**：反转后原来的头变成尾，`next` 要指向 null
3. **递归终止条件**：`head == null || head.next == null`（不是只判 null，最后一个节点也要返回）
4. **递归法两行顺序**：先 `head.next.next = head`（接上），再 `head.next = null`（断开），反了会丢节点

递归两行：下一个指回我，我断开变尾巴。
