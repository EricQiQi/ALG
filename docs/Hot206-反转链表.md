# 反转链表（Reverse Linked List）

## 题目描述

给定单链表的头节点 `head`，反转链表，并返回反转后的链表。

示例：
```
输入：1 → 2 → 3 → 4 → 5 → null
输出：5 → 4 → 3 → 2 → 1 → null
```

---

## 核心思路

反转链表 = 把每个箭头**掉头**：

```
1 → 2 → 3 → null         null ← 1 ← 2 ← 3
```

三种解法都是围绕「掉头」做文章，只是做法不同：

| 解法 | 掉头方式 | 空间 |
|------|---------|------|
| 迭代法 | 边走边把 `curr.next` 改成指向前一个 | O(1) |
| 递归法 | 钻到最深处，回溯时逐层掉头 | O(n) |
| 头插法 | 新建节点插到新链表头部，天然倒序 | O(n) |

---

## 解法一：迭代法（原地掉头，最优）

### 原理图解

用三个指针接力：`prev` 指向已反转部分，`curr` 指向当前节点，`nextTemp` 先记下下一步。

```text
初始：  null   1 → 2 → 3 → null
        prev  curr

第1步： null ← 1    2 → 3 → null
             prev  curr

第2步： null ← 1 ← 2    3 → null
                  prev  curr

结束： null ← 1 ← 2 ← 3
                     prev(返回它)
```

### 代码实现

```java
public ListNode reverseList_1(ListNode head) {
    ListNode prev = null;
    ListNode curr = head;
    while (curr != null) {
        ListNode nextTemp = curr.next;  // 1. 先记下下一个节点，防止断链
        curr.next = prev;               // 2. 掉头：当前节点指向前一个
        prev = curr;                    // 3. prev 前进
        curr = nextTemp;                // 4. curr 前进
    }
    return prev;                        // prev 就是新头
}
```

### 复杂度

| 类型 | 复杂度 |
|------|--------|
| 时间 | O(n) |
| 空间 | O(1) |

> 口诀：**先存后断再前移**——先 `nextTemp` 存住，再断链掉头，最后两个指针同步前移。

## 解法二：递归法

### 原理图解

两句话：**先钻到最深处，返回时边走边掉头**。

```text
递归阶段（一路往下钻）：      回溯阶段（每弹一层掉一个头）：
reverse(1→2→3→4)              head=3: 4→3→null
  └→ reverse(2→3→4)           head=2: 4→3→2→null
       └→ reverse(3→4)        head=1: 4→3→2→1→null ✅
            └→ reverse(4)     ← 出口：单个节点直接返回
```

### 代码实现

```java
public ListNode reverseList_2(ListNode head) {
    if (head == null || head.next == null) return head;  // 出口
    ListNode newHead = reverseList_2(head.next);         // 假设后面已反转
    head.next.next = head;                               // 让后一个指回自己
    head.next = null;                                    // 自己断开，防成环
    return newHead;
}
```

### 最难的两行翻译成人话

```java
head.next.next = head;  // 我后面那个节点的 next，改成指向我
head.next = null;       // 我再也不指向它，防止 1↔2 成环死循环
```

### 复杂度

| 类型 | 复杂度 | 说明 |
|------|--------|------|
| 时间 | O(n) | |
| 空间 | O(n) | 递归栈深度 n |

### 为什么递归难想？

因为它的思考方式和普通代码相反：

- **执行顺序反**：`reverseList_2(head.next)` 要先钻到最深处，后面两行才逐层执行
- **要先信任**：写递归调用时得默认"后面那段已经反转好了"，只补当前这一层
- **状态叠加**：脑子里要同时装当前层（还没断链）和更深层（已反转）两套状态

破局方法：把递归调用当**黑盒**，只记一句承诺——"`head.next` 开头的链表已反转，返回新头 `newHead`"，然后专心做当前层的掉头。

## 解法三：头插法（新建节点）

### 原理图解

遍历原链表，每遇到一个节点就**新建一份插到新链表头部**，插着插着就反了：

```text
原链表：1 → 2 → 3
新链表：null

插 1：1 → null
插 2：2 → 1 → null
插 3：3 → 2 → 1 → null ✅
```

### 代码实现

```java
public ListNode reverseList_3(ListNode head) {
    ListNode prev = null;
    for (ListNode curr = head; curr != null; curr = curr.next) {
        prev = new ListNode(curr.val, prev);  // 新建节点，指向当前新链表头
    }
    return prev;
}
```

### 复杂度

| 类型 | 复杂度 |
|------|--------|
| 时间 | O(n) |
| 空间 | O(n) |

### 与迭代法的区别

| | 迭代法 | 头插法 |
|---|---|---|
| 是否新建节点 | 否，复用原节点 | 是，每个都 new |
| 是否改动原链表 | 会改动 | 原链表保持不动 |
| 空间 | O(1) | O(n) |

> 注意：`curr = curr.next` 遍历的是**原链表**，头插法新建的节点不影响它，所以两者能和平共存。

---

## 三种解法对比

| 维度 | 迭代法 | 递归法 | 头插法 |
|------|--------|--------|--------|
| 时间 | O(n) | O(n) | O(n) |
| 空间 | **O(1)** | O(n) | O(n) |
| 难度 | 简单直观 | 最绕 | 最简单 |
| 适用 | 面试首选 | 练递归思维 | 不能动原链表时 |

---

## 易错点

1. **迭代法忘记先存 `nextTemp`**：断链后就找不回下一个节点了
2. **递归法漏写 `head.next = null`**：`head` 和 `head.next` 互相指向，成环死循环
3. **递归出口写错**：必须是 `head == null || head.next == null`，缺 `head.next` 判断会 NPE
4. **头插法遍历错链表**：`curr` 必须走原链表，别在新建的链表上遍历
