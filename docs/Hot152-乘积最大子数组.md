# 算法笔记：乘积最大子数组（力扣 152 题）

## 题目描述
给你一个整数数组 `nums`，请你找出数组中**乘积最大的连续子数组**（该子数组中至少包含一个数字），并返回该子数组所对应的乘积。

```
输入：nums = [2,3,-2,4]
输出：6
解释：子数组 [2,3] 有最大乘积 6。

输入：nums = [-2,0,-1]
输出：0
解释：结果不能为 2，因为 [-2,-1] 不是连续子数组；最大为子数组 [0]。
```

> 📌 关键理解：本题与「最大子数组和」（Hot53）形似，但**乘法引入了两个新麻烦**——① 负数会让大小关系**反转**（上一步的最小负数乘积 × 当前负数 = 最大正数）；② 乘 0 会让整段**清零**。因此只维护「最大乘积」一个状态不够，必须**同时维护最大/最小两个状态**。

---

## 解法一：暴力枚举（$O(n^2)$）

### 1. 核心思想
枚举所有「以 `i` 开头」的子数组，终点 `j` 从 `i` 向右逐步扩展，边累乘边打擂台更新答案。起点换到下一个时，累乘器重置为 1。

### 2. 代码实现 (Java)

```java
class Solution {
    public int maxProduct(int[] nums) {
        int n = nums.length;
        int res = nums[0];

        for (int i = 0; i < n; i++) {        // 枚举起始位置 i
            int product = 1;                 // 累乘器，每换一个起点重置为 1
            for (int j = i; j < n; j++) {    // 终点 j 从 i 向右扩展，乘积逐步累乘
                product *= nums[j];
                res = Math.max(res, product);
            }
        }
        return res;
    }
}
```

### 3. 复杂度分析
* **时间复杂度**：$O(n^2)$。双重循环枚举所有 $\frac{n(n+1)}{2}$ 个子数组。
* **空间复杂度**：$O(1)$。只用了常数个变量。

---

## 解法二：动态规划（双状态滚动变量，$O(n)$）

### 1. 核心思想
定义状态：`maxDp` / `minDp` 分别表示**以当前位置结尾**的连续子数组的**最大/最小**乘积。
* **为什么要两个状态**：当 `nums[i]` 为负数时，上一步的 `minDp`（负数）乘它会**反转**为最大的正数，所以转移时必须同时参考上一步的最大值与最小值。
* **状态转移**（三个候选：当前数单独重开一段 / 接上一步最大 / 接上一步最小）：
  $$maxDp = \max(num,\ maxDp \times num,\ minDp \times num)$$
  $$minDp = \min(num,\ maxDp \times num,\ minDp \times num)$$
* **边界（初始化）**：第一个元素自己成段，`maxDp = minDp = res = nums[0]`。
* **返回**：所有位置 `maxDp` 的全局最大值（最大乘积**不一定以最后一个元素结尾**）。

### 2. 代码实现 (Java)

```java
class Solution {
    public int maxProduct(int[] nums) {
        int n = nums.length;
        int maxDp = nums[0];  // 以当前位置结尾的最大乘积
        int minDp = nums[0];  // 以当前位置结尾的最小乘积
        int res = nums[0];    // 全局最大乘积（最终答案）

        for (int i = 1; i < n; i++) {
            int num = nums[i];
            // 先暂存上一步状态与当前数的乘积，避免 maxDp 更新后污染 minDp 的计算
            int tempMax = maxDp * num;
            int tempMin = minDp * num;
            // 三个候选：num 自身（断开重开一段）、上一步最大乘积 × num、上一步最小乘积 × num
            maxDp = Math.max(num, Math.max(tempMax, tempMin));
            minDp = Math.min(num, Math.min(tempMax, tempMin));
            // 以每个位置结尾的最大乘积中取全局最大
            res = Math.max(res, maxDp);
        }
        return res;
    }
}
```

### 3. 复杂度分析
* **时间复杂度**：$O(n)$。单趟遍历。
* **空间复杂度**：$O(1)$。滚动变量代替 dp 数组。

### 4. 递推过程图解
以 `nums = [2,3,-2,4]` 为例：

```text
i   num   tempMax(=maxDp*num)  tempMin(=minDp*num)   maxDp   minDp   res
0    2         ——                  ——                  2       2      2
1    3         6                   6                   6       3      6
2   -2        -12                 -6                  -2     -12      6
3    4         -8                -48                   4     -48      6
返回 res = 6（来自子数组 [2,3]）
```

再用 `[-2,3,-4]` 看「最小值反转」的关键一幕：

```text
i   num   tempMax   tempMin    maxDp   minDp   res
0   -2      ——        ——         -2      -2     -2
1    3      -6        -6          3      -6      3
2   -4     -12        24         24     -12     24   ← minDp=-6 × -4 反转为最大
```

> 第 3 步若只维护 `maxDp`，`-2 × -4 = -8` 或单独取 `-4`，都得不到 24；正是**保留的最小乘积 `-6` 遇负转正**才接住答案。这就是双状态的必要性。

---

## 💡 总结
乘积最大子数组是**「以 i 结尾」型 DP + 双状态维护**的模板：乘法下负数会让大小反转，所以必须同时记账「最大」与「最小」两个滚动状态，转移时在「断开重开 / 接最大 / 接最小」三者中取极值，答案打擂台取全局最大。

| 特性 | 解法一：暴力枚举 | 解法二：动态规划 |
| :--- | :--- | :--- |
| **思维出发点** | 枚举所有以 i 开头的子数组，边累乘边打擂台 | 以 i 结尾维护 maxDp/minDp 双状态，负数触发反转 |
| **代码表现** | 双重循环，累乘器换起点重置为 1 | 单趟遍历，tempMax/tempMin 暂存后同步更新 |
| **时间** | $O(n^2)$ | $O(n)$ |
| **空间** | $O(1)$ | $O(1)$ |

> ⚠️ 易错点：① **必须维护 minDp**，只记最大值会在负数处丢答案（见 `[-2,3,-4]` 图解）；② **tempMax/tempMin 要先算**，否则 `maxDp` 更新后会污染 `minDp` 的转移；③ **状态带「以 i 结尾」**，三个候选里的 `num` 对应「断开重开一段」；④ 答案是 `max(maxDp)` 的**全局打擂台**，不是最后的 `maxDp`；⑤ `res` 初始化用 `nums[0]` 而不是 0（数组可能全为负数）。
