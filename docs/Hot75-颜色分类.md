# 算法笔记：颜色分类（力扣 75 题）

## 题目描述
给定一个包含红色、白色、蓝色（分别用 `0`、`1`、`2` 表示）的数组 `nums`，**原地**排序它们，使得相同颜色的元素相邻，并按照红、白、蓝顺序排列。

**进阶**：能否不使用数组库函数，一趟扫描解决？

```
输入：nums = [2,0,2,1,1,0]
输出：[0,0,1,1,2,2]

输入：nums = [2,0,1]
输出：[0,1,2]
```

> 📌 关键理解：值域只有 `0/1/2` 三种——排序问题退化成**划分问题**：把数组按值切成三段。这正是快排三路 partition 的原型（荷兰国旗问题），所以 $O(n)$ 一趟可解，根本不需要 $O(n\log n)$ 的通用排序。

---

## 方法一：三指针一次划分（荷兰国旗，推荐）

### 核心逻辑
维护四个区间，`i` 是"未检查区"的侦察兵，`p0`/`p2` 是左右两段的边界：

```
[0 .. p0-1]   全是 0     ← 红区（已定）
[p0 .. i-1]   全是 1     ← 白区（已定）
[i  .. p2]    待检查     ← 侦察区
[p2+1 .. n-1] 全是 2     ← 蓝区（已定）

不变式：p0 ≤ i，循环直到侦察区清空（i > p2）
```

`i` 处三种情况：

* **见 0**：和 `p0` 换（把 0 送进红区，从红区换回的必是 1 或自己，**已在白区验证过**）→ `p0++`、`i++` 双进；
* **见 1**：本就属于白区 → `i++`；
* **见 2**：和 `p2` 换（把 2 送进蓝区），但从 `p2` 换回来的元素**从未检查过** → 只 `p2--`，**`i` 原地不动**，下一轮重新裁决。

### 代码实现

```java
public void sortColors_1(int[] nums) {
    int p0 = 0;
    int i = 0;
    int p2 = nums.length - 1;

    while (i <= p2) {                 // 侦察区非空就继续
        if (nums[i] == 0) {
            swap(nums, i, p0);        // 0 归红区，换回的是已验证的 1
            p0++;
            i++;                      // 可以安全双进
        } else if (nums[i] == 1) {
            i++;                      // 白区原地收下
        } else {
            swap(nums, i, p2);        // 2 归蓝区
            p2--;
            // i 不前进！从 p2 换回来的元素还没检查过
        }
    }
}
```

### 追踪图解
以 `[2,0,2,1,1,0]` 为例（`|` 标出四区边界）：

```text
[2,0,2,1,1,0]  i=0 见2 ↔ p2(末位0)   → [0,0,2,1,1,2]  p2=4，i 停在 0
[0,0,2,1,1,2]  i=0 见0 ↔ p0(自己)    → [0|0,2,1,1|2]  p0=1, i=1
[0,0,2,1,1,2]  i=1 见0 ↔ p0(自己)    → [0,0|2,1,1|2]  p0=2, i=2
[0,0,2,1,1,2]  i=2 见2 ↔ p2(位4的1)  → [0,0|1,1|2,2]  p2=3，i 停在 2
[0,0,1,1,2,2]  i=2 见1 → i=3；i=3 见1 → i=4 > p2，收工
```

> 直观记忆：**见 0 前换双步进，见 1 放行进一步，见 2 后换须原地**——区别只在"换回来的元素干不干净"：p0 递过来的是检查过的 1，p2 递过来的是没检查过的未知数。

## 方法二：计数排序（两趟读写）

### 核心逻辑
值域只有 3 个数，第一趟数出各值的个数，第二趟按个数依次回填 `0、0、…、1、1、…、2、2、…`。完全绕开交换。

### 代码实现

```java
public void sortColors_2(int[] nums) {
    int count0 = 0, count1 = 0, count2 = 0;   // 三个计数器就是全部"空间"
    for (int num : nums) {
        if (num == 0) count0++;
        else if (num == 1) count1++;
        else count2++;
    }
    int index = 0;
    for (int i = 0; i < count0; i++) nums[index++] = 0;
    for (int i = 0; i < count1; i++) nums[index++] = 1;
    for (int i = 0; i < count2; i++) nums[index++] = 2;
}
```

## 方法三：单指针两趟划分

### 核心逻辑
把"三段"拆成两次"两段"操作：第一趟把全部 0 换到前段，第二趟从 0 段之后开始把全部 1 换到中段的正确位置——0 段、1 段就位后，2 自动留在尾部。相当于**按低位到高位各做一次 partition**（LSD 思路）。

### 代码实现

```java
public void sortColors_3(int[] nums) {
    int p = 0;
    for (int i = 0; i < nums.length; i++) {   // 第一趟：0 全部归前
        if (nums[i] == 0) { swap(nums, i, p); p++; }
    }
    for (int i = p; i < nums.length; i++) {   // 第二趟：从 0 段尾起，1 归中
        if (nums[i] == 1) { swap(nums, i, p); p++; }
    }
    // 剩下的天然全是 2
}
```

## 复杂度对照

| 方法 | 时间 | 空间 | 扫描趟数 | 特点 |
| :--- | :---: | :---: | :---: | :--- |
| **三指针** | $O(n)$ | $O(1)$ | **1 趟** | 进阶题解，交换次数最少 |
| **计数排序** | $O(n)$ | $O(1)$（值域固定为 3） | 2 趟 | 无交换只读写，最好写 |
| **单指针** | $O(n)$ | $O(1)$ | 2 趟 | 三指针的"降维拼装版" |

> **方法对比**：三指针是唯一的一趟解法且交换次数上界 $n$ 次，面试必须掌握；计数排序胜在零风险（没有任何指针细节）；单指针介于两者之间，是通往快排三路 partition 的阶梯。通用 `Arrays.sort` 反而最差——$O(n\log n)$ 且浪费了"值域只有 3"的承诺。

---

## 💡 总结
颜色分类 = **荷兰国旗问题** = **快排三路 partition**，是"按值划分"这一思想的母题：用区间不变式管理三个边界指针，每步操作都要问一句"**换回来的元素检查过没有**"——检查过就推进 `i`，没检查过就留在原地再审。k 色版本照此推广为 k-1 个边界即可。

> 🔑 记忆口诀：**见 0 前换双步，见 1 直走，见 2 后换 i 不动**（p2 递来的生面孔必须重新审）。
