# 旋转图像（Rotate Image）

## 题目描述

给定一个 `n x n` 的二维矩阵 `matrix` 表示一个图像，请你将图像**顺时针旋转 90 度**。

> 约束：必须在**原地**修改矩阵，不能使用另一个矩阵（空间复杂度 O(1)）。

示例：
```
输入：matrix = [[1,2,3],
               [4,5,6],
               [7,8,9]]

输出：[[7,4,1],
       [8,5,2],
       [9,6,3]]

旋转前后对应关系：
1(0,0) → (0,2)    3(0,2) → (2,2)
7(2,0) → (0,0)    9(2,2) → (2,0)
```

---

## 核心思路

### 关键洞察

**顺时针旋转 90 度 = 转置 + 左右翻转**

```
原矩阵          转置后           左右翻转后
1 2 3          1 4 7            7 4 1
4 5 6    →     2 5 8     →      8 5 2
7 8 9          3 6 9            9 6 3
```

### 数学原理

顺时针旋转 90 度后，元素 `(i, j)` 会移动到 `(j, n-1-i)`。

拆成两步验证：
1. **转置**：`(i, j)` → `(j, i)`
2. **左右翻转**：`(j, i)` → `(j, n-1-i)` ✅

两步组合正好完成旋转。

---

## 算法步骤

### 第一步：转置（沿主对角线翻转）

沿左上到右下的对角线交换元素：`matrix[i][j] ↔ matrix[j][i]`

```
1 2 3          1 4 7
4 5 6    →     2 5 8
7 8 9          3 6 9
```

⚠️ 内层循环 `j` 必须从 `i + 1` 开始，只遍历对角线**右上**部分：
- 若从 `0` 开始，每个元素会被交换两次（换过去又换回来），等于没转

### 第二步：左右翻转（每行 reverse）

每一行的元素左右对称交换：`matrix[i][j] ↔ matrix[i][n-1-j]`

```
1 4 7          7 4 1
2 5 8    →     8 5 2
3 6 9          9 6 3
```

⚠️ 内层循环 `j` 只需遍历到 `n / 2`（前半部分），否则同样会翻回去。

---

## 代码实现

```java
public void rotate(int[][] matrix) {
    int n = matrix.length;

    // 第一步：转置（沿主对角线交换）
    for (int i = 0; i < n; i++) {
        // 注意 j 的起始位置，应该是 i + 1
        for (int j = i + 1; j < n; j++) {
            int temp = matrix[i][j];
            matrix[i][j] = matrix[j][i];
            matrix[j][i] = temp;
        }
    }

    // 第二步：左右翻转（每行反转）
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n / 2; j++) {
            int temp = matrix[i][j];
            matrix[i][j] = matrix[i][n - 1 - j];
            matrix[i][n - 1 - j] = temp;
        }
    }
}
```

### 复杂度

| 类型 | 复杂度 | 说明 |
|------|--------|------|
| 时间 | O(n²) | 转置和翻转各遍历一半元素 |
| 空间 | O(1) | 原地交换，只用 temp 变量 |

---

## 易错点

1. **转置时 `j` 从 `0` 开始**：每个元素被交换两次，矩阵没有任何变化，必须从 `i + 1` 开始
2. **翻转时 `j` 遍历到 `n`**：同样会翻回去，只遍历到 `n / 2`
3. **忘记是顺时针**：逆时针旋转 90 度 = 转置 + **上下**翻转，方向别搞反

### 顺时针 vs 逆时针

| 旋转方向 | 拆解方法 |
|----------|----------|
| 顺时针 90° | 转置 + 左右翻转 |
| 逆时针 90° | 转置 + 上下翻转 |
| 旋转 180° | 左右翻转 + 上下翻转 |
