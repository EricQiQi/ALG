# 算法笔记：移动零（力扣 283 题）

## 题目描述
给定一个数组 `nums`，将所有 `0` 移动到数组末尾，同时**保持非零元素的相对顺序**。必须**原地**操作，不能拷贝额外数组。

```
输入: nums = [0,1,0,3,12]
输出: [1,3,12,0,0]
```

---

## 核心思想

> **快慢双指针：慢指针守住"下一个非零该放的位置"，快指针负责找非零元素往前搬，最后尾部补零。**

- **慢指针 `s`**：指向结果中下一个非零元素应该落的坑位，初始 0；
- **快指针 `i`**：从头扫到尾，遇到非零就把它**覆盖**写到 `s`，然后 `s++`；
- 扫完后，`[0, s)` 是所有非零元素（保持原顺序），`[s, n)` 全部补 0。

---

## 图解：覆盖 + 补零

```
nums = [0, 1, 0, 3, 12]    s=0

i=0: nums[0]=0  → 跳过，s 不动
i=1: nums[1]=1  → nums[s=0]=1, s=1   [1, 1, 0, 3, 12]
i=2: nums[2]=0  → 跳过
i=3: nums[3]=3  → nums[s=1]=3, s=2   [1, 3, 0, 3, 12]
i=4: nums[4]=12 → nums[s=2]=12, s=3  [1, 3, 12, 3, 12]

补零：s=3 起全部置 0 → [1, 3, 12, 0, 0] ✅
```

---

## 代码实现 (Java)

```java
public void moveZeroes(int[] nums) {
    if (nums == null || nums.length == 0) return;

    int s = 0;                              // 慢指针：下一个非零的落点
    for (int i = 0; i < nums.length; i++) { // 快指针：找非零
        if (nums[i] != 0) {
            nums[s++] = nums[i];            // 覆盖写入，s 前进
        }
    }
    while (s < nums.length) {               // 尾部补零
        nums[s++] = 0;
    }
}
```

---

## ❗关键易错点

**1. 慢指针 `s` 只在"放非零"时才前进**
遇到 0 时 `s` 原地不动，这样 0 就被后面的非零"盖掉"，最终非零元素紧凑排在前面。

**2. 别忘了最后补零**
覆盖法只搬了非零元素，`[s, n)` 这段残留的旧值必须显式清成 0，否则尾部是脏数据。

**3. 另一种写法：交换而非覆盖**
也可以 `if (nums[i] != 0) swap(nums, s++, i)`，一趟完成不用补零。本实现用的是"覆盖 + 补零"，逻辑更直白。

---

## 复杂度分析

* **时间复杂度**：$O(n)$。快指针一趟 + 补零一趟，都是线性。
* **空间复杂度**：$O(1)$。原地操作，只用了常数个指针。
