## 1. 快速排序（Quick Sort）

### 核心思想
分治思想：每次选一个基准（pivot），把小于基准的放左边，大于基准的放右边，然后递归处理左右两部分。

### 标准代码（数组版）

```java
public class QuickSort {
    public void quickSort(int[] arr, int left, int right) {
        if (left >= right) return;
        
        int pivotIndex = partition(arr, left, right);
        quickSort(arr, left, pivotIndex - 1);
        quickSort(arr, pivotIndex + 1, right);
    }
    
    // 分区函数（核心）
    private int partition(int[] arr, int left, int right) {
        // 选择最右边元素作为基准
        int pivot = arr[right];
        int i = left - 1; // i指向小于pivot的最后一个位置
        
        for (int j = left; j < right; j++) {
            if (arr[j] <= pivot) {
                i++;
                swap(arr, i, j);
            }
        }
        // 将pivot放到正确位置
        swap(arr, i + 1, right);
        return i + 1;
    }
    
    private void swap(int[] arr, int i, int j) {
        int temp = arr[i];
        arr[i] = arr[j];
        arr[j] = temp;
    }
}
```

### 复杂度分析
| 指标 | 复杂度 | 说明 |
|------|--------|------|
| 平均时间 | O(n log n) | 每次partition遍历n个元素，递归深度log n |
| 最好时间 | O(n log n) | 每次pivot恰好是中位数 |
| 最坏时间 | O(n²) | 每次pivot是最大/最小值（如数据已经有序） |
| 空间复杂度 | O(log n) | 递归调用栈（原地排序，不占额外数组） |
| 稳定性 | ❌ 不稳定 | 交换操作会打乱相等元素的顺序 |

### 优化手段（面试必问）
```java
// 优化1：三数取中法选pivot（避免最坏情况）
private int medianOfThree(int[] arr, int left, int right) {
    int mid = left + (right - left) / 2;
    if (arr[left] > arr[mid]) swap(arr, left, mid);
    if (arr[left] > arr[right]) swap(arr, left, right);
    if (arr[mid] > arr[right]) swap(arr, mid, right);
    return mid; // 返回中位数的索引
}

// 优化2：数据量小时改用插入排序（减少递归开销）
public void quickSortOptimized(int[] arr, int left, int right) {
    if (right - left <= 15) { // 阈值通常设为10-20
        insertionSort(arr, left, right);
        return;
    }
    // ... 正常快排逻辑
}

// 优化3：随机选取pivot（概率上避免最坏情况）
private int randomPartition(int[] arr, int left, int right) {
    int randomIndex = left + (int)(Math.random() * (right - left + 1));
    swap(arr, randomIndex, right);
    return partition(arr, left, right);
}
```

### 工程应用
- **Java的Arrays.sort()**：对基本类型（int[]， long[]等）使用**双轴快速排序**（Dual-Pivot QuickSort）
- 为什么对基本类型用快排？因为基本类型不需要稳定性，快排常数小、速度快

### 常见追问
**Q：快排什么时候会退化成O(n²)？**
A：每次选中的pivot都是当前子数组的最大或最小值时，比如数据已经有序，且每次选最左或最右做pivot。

**Q：怎么避免退化？**
A：三种方法：①三数取中 ②随机选pivot ③数据量小时换插入排序。

## 2. 归并排序（Merge Sort）

### 核心思想
分治思想：将数组一分为二，分别排序，再将两个有序数组合并成一个有序数组。

### 标准代码（数组版）

```java
public class MergeSort {
    public void mergeSort(int[] arr, int left, int right) {
        if (left >= right) return;
        
        int mid = left + (right - left) / 2;
        mergeSort(arr, left, mid);
        mergeSort(arr, mid + 1, right);
        merge(arr, left, mid, right);
    }
    
    // 合并两个有序数组
    private void merge(int[] arr, int left, int mid, int right) {
        // 临时数组存合并结果
        int[] temp = new int[right - left + 1];
        int i = left, j = mid + 1, k = 0;
        
        while (i <= mid && j <= right) {
            if (arr[i] <= arr[j]) {
                temp[k++] = arr[i++];
            } else {
                temp[k++] = arr[j++];
            }
        }
        // 处理剩余元素
        while (i <= mid) temp[k++] = arr[i++];
        while (j <= right) temp[k++] = arr[j++];
        
        // 拷贝回原数组
        for (i = 0; i < temp.length; i++) {
            arr[left + i] = temp[i];
        }
    }
}
```

### 链表版归并排序（LeetCode 148 标准答案）

```java
public class ListNode {
    int val;
    ListNode next;
    ListNode(int val) { this.val = val; }
}

public class Solution {
    public ListNode sortList(ListNode head) {
        if (head == null || head.next == null) return head;
        
        // 快慢指针找中点
        ListNode slow = head, fast = head, prev = null;
        while (fast != null && fast.next != null) {
            prev = slow;
            slow = slow.next;
            fast = fast.next.next;
        }
        prev.next = null; // 断开链表
        
        ListNode left = sortList(head);
        ListNode right = sortList(slow);
        return merge(left, right);
    }
    
    // 合并两个有序链表
    private ListNode merge(ListNode l1, ListNode l2) {
        ListNode dummy = new ListNode(0);
        ListNode curr = dummy;
        
        while (l1 != null && l2 != null) {
            if (l1.val <= l2.val) {
                curr.next = l1;
                l1 = l1.next;
            } else {
                curr.next = l2;
                l2 = l2.next;
            }
            curr = curr.next;
        }
        curr.next = (l1 != null) ? l1 : l2;
        return dummy.next;
    }
}
```

### 复杂度分析
| 指标 | 复杂度 | 说明 |
|------|--------|------|
| 时间 | O(n log n) | 每次合并遍历n个元素，递归深度log n，稳定 |
| 空间复杂度 | O(n) | 需要临时数组存放合并结果 |
| 稳定性 | ✅ 稳定 | 合并时相等元素先取左边的，保持顺序 |

### 优化手段
```java
// 优化1：数据量小时改用插入排序
public void mergeSortOptimized(int[] arr, int left, int right) {
    if (right - left <= 15) {
        insertionSort(arr, left, right);
        return;
    }
    // ... 正常归并逻辑
}

// 优化2：复用临时数组（避免频繁创建）
private int[] temp; // 作为成员变量
public void mergeSort(int[] arr) {
    temp = new int[arr.length];
    mergeSort(arr, 0, arr.length - 1);
}
// 在merge中直接使用temp数组
```

### 工程应用
- **Java的Collections.sort()**：底层是**TimSort**（优化版归并排序）
- 为什么对对象用归并？因为对象排序需要**稳定性**（保证相等元素的原始顺序）
- **外部排序**：大数据排序的基础（100亿个数，内存1G，用多路归并）

### 常见追问
**Q：快排和归并哪个快？**
A：快排常数更小，实际更快。但归并稳定，适合对象排序。

**Q：归并排序为什么空间复杂度是O(n)？**
A：因为合并时需要额外数组存放结果，不能像快排那样原地交换。

**Q：链表归并排序的空间复杂度是多少？**
A：O(log n)（递归栈）或O(1)（迭代版），因为链表不需要额外数组存储合并结果，只需要改指针。

## 3. 堆排序（Heap Sort）

### 核心思想
利用堆（完全二叉树）这种数据结构：每次将堆顶（最大/最小）元素取出，放到数组末尾，然后调整堆。

### 标准代码

```java
public class HeapSort {
    public void heapSort(int[] arr) {
        // 1. 建大根堆（升序用大根堆，降序用小根堆）
        for (int i = arr.length / 2 - 1; i >= 0; i--) {
            heapify(arr, i, arr.length);
        }
        
        // 2. 排序：每次把堆顶换到最后，再调整堆
        for (int i = arr.length - 1; i > 0; i--) {
            swap(arr, 0, i);           // 堆顶放到末尾
            heapify(arr, 0, i);        // 调整剩余元素成堆
        }
    }
    
    // 向下调整堆（维护大根堆性质）
    private void heapify(int[] arr, int i, int heapSize) {
        int largest = i;
        int left = 2 * i + 1;
        int right = 2 * i + 2;
        
        if (left < heapSize && arr[left] > arr[largest]) {
            largest = left;
        }
        if (right < heapSize && arr[right] > arr[largest]) {
            largest = right;
        }
        if (largest != i) {
            swap(arr, i, largest);
            heapify(arr, largest, heapSize); // 递归调整子树
        }
    }
    
    private void swap(int[] arr, int i, int j) {
        int temp = arr[i];
        arr[i] = arr[j];
        arr[j] = temp;
    }
}
```

### 复杂度分析
| 指标 | 复杂度 | 说明 |
|------|--------|------|
| 时间 | O(n log n) | 建堆O(n) + 调整n次 × O(log n) |
| 空间复杂度 | O(1) | 原地排序，不需要额外空间 |
| 稳定性 | ❌ 不稳定 | 堆顶与末尾交换会打乱顺序 |

### 优化手段
```java
// 迭代版heapify（避免递归开销）
private void heapifyIterative(int[] arr, int i, int heapSize) {
    while (true) {
        int largest = i;
        int left = 2 * i + 1;
        int right = 2 * i + 2;
        if (left < heapSize && arr[left] > arr[largest]) largest = left;
        if (right < heapSize && arr[right] > arr[largest]) largest = right;
        if (largest == i) break;
        swap(arr, i, largest);
        i = largest;
    }
}
```

### 工程应用
- **PriorityQueue（优先队列）**：底层就是堆，默认小根堆
- **TopK问题**：找最大的K个元素 → 用小根堆，维护K个元素
- **定时器/任务调度**：按优先级执行任务

### 常见追问
**Q：堆排序为什么没有快排常用？**
A：①堆排序的常数大（交换次数多，缓存不友好） ②不稳定 ③实际性能不如快排。

**Q：建堆的时间复杂度真的是O(n)吗？**
A：是的！从最后一个非叶子节点开始调整，逐层累加，总时间复杂度是O(n)，不是O(n log n)。

**Q：PriorityQueue的remove()方法的时间复杂度？**
A：O(log n)，因为删除堆顶后需要下滤调整。

**Q：为什么堆排序空间O(1)但面试问得相对少？**
A：因为堆排序实现相对复杂（要理解堆的数组表示和父子关系），且工程中通常直接用PriorityQueue，手写场景较少。但TopK问题必问，所以必须掌握。

## 4. 三巨头对比总结

### 核心区别速览表

| 对比维度 | 快速排序 | 归并排序 | 堆排序 |
|---------|---------|---------|--------|
| **核心思想** | 分区（partition） | 分治 + 合并 | 堆的调整 |
| **平均时间复杂度** | O(n log n) | O(n log n) | O(n log n) |
| **最坏时间复杂度** | O(n²) | O(n log n) | O(n log n) |
| **空间复杂度** | O(log n) | O(n) | O(1) |
| **稳定性** | ❌ 不稳定 | ✅ 稳定 | ❌ 不稳定 |
| **实际速度** | 最快 | 中等 | 最慢 |
| **工程使用** | Arrays.sort()（基本类型） | Collections.sort()（对象） | PriorityQueue底层 |

### 选型指南（面试答题套路）

| 场景 | 推荐算法 | 理由 |
|------|---------|------|
| 排基本类型数组 | 快速排序 | 常数小，速度快，不需要稳定 |
| 排对象数组/集合 | 归并排序 | 需要稳定性，TimSort还优化了部分有序数据 |
| 找TopK | 堆排序 | 时间复杂度O(n log k)，空间O(k)，最优 |
| 排链表 | 归并排序 | 链表归并O(1)额外空间，快排不适合链表 |
| 内存不够，排大文件 | 归并排序 | 外部排序的基础 |
| 数据量极小（<20） | 插入排序 | 常数最小，最实用 |

## 5. 面试高频追问（套题演练）

### Q1：Arrays.sort()和Collections.sort()底层分别用什么排序？
- **Arrays.sort()**：基本类型用双轴快排（Dual-Pivot QuickSort），对象类型用TimSort（优化归并）
- **Collections.sort()**：统一用TimSort

### Q2：为什么基本类型用快排，对象用归并？
- 基本类型排序**不需要稳定性**（int 1就是1，没有额外信息）
- 对象排序**需要稳定性**（保证相等对象的原始顺序不变，比如先按姓名再按年龄排序）
- 归并稳定，快排不稳定

### Q3：100亿个数，内存1G，怎么排序？
- ① 外部排序，每次读一部分进内存排序
- ② 多路归并，将多个有序小文件合并成一个大文件
- ③ 核心就是**归并排序的分治思想**

### Q4：10万个数找最大的100个，怎么做最快？
- ① 建一个大小为100的小根堆
- ② 遍历数据，比堆顶大就替换并调整堆
- ③ 时间复杂度O(n log k)，空间O(k)
- ④ 如果数据量极大（100亿），用这个内存友好

### Q5：快排和归并排序的区别（最经典问题）

| 区别点 | 快排 | 归并 |
|-------|------|------|
| 处理顺序 | 先分区再递归 | 先递归再合并 |
| 空间 | 原地排序（O(log n)） | 需要O(n)额外空间 |
| 稳定性 | 不稳定 | 稳定 |
| 最坏情况 | O(n²)（可优化） | 始终O(n log n) |
| 适用场景 | 内存排序，基本类型 | 外部排序，对象排序 |

### Q6：排序算法的稳定性在实际中有什么意义？
- 比如先按**部门**排序，再按**工资**排序，稳定算法能保证部门相同的员工工资有序
- 比如电商订单按时间排序，再按金额排序，稳定算法能保证相同金额的订单时间有序

### Q7：有没有时间复杂度O(n)的排序？
- 有，但有限制：计数排序、桶排序、基数排序
- 它们都是**非比较排序**，利用数据本身的特性
- 适用条件：整数、数据范围不大、分布均匀等
