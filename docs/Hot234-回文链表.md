# 回文链表（Palindrome Linked List）

## 题目描述

给定一个单链表的头节点 `head`，判断它是否为回文链表。

示例：
```
输入：1 → 2 → 2 → 1 → null
输出：true

输入：1 → 2 → null
输出：false
```

---

## 核心思路

回文 = 正着读和反着读一样。链表的天然弱点是不能从后往前遍历，所以两种解法都是**绕开这个弱点**：

| 解法 | 怎么绕开 | 空间 |
|------|---------|------|
| 数组法 | 把链表倒进数组，用双指针两头夹 | O(n) |
| 快慢指针 + 反转 | 把后半段原地反转，然后两头对读 | **O(1)** |

---

## 解法一：数组法

### 原理图解

```text
链表：1 → 2 → 2 → 1         数组：[1, 2, 2, 1]
                                    ↑        ↑
                                   left    right

两头向中间夹，值不等就不是回文
```

### 算法步骤

1. 遍历链表求长度 `len`
2. 再遍历一遍，把值灌进 `int[len]`
3. 双指针 `left`/`right` 从两端向中间夹，值不等直接返回 false

### 代码实现

```java
public boolean isPalindrome_1(ListNode head) {
    int len = 0;
    for (ListNode curr = head; curr != null; curr = curr.next) {
        len++;
    }

    int[] arr = new int[len];
    int i = 0;
    for (ListNode curr = head; curr != null; curr = curr.next) {
        arr[i++] = curr.val;
    }

    int left = 0;
    int right = len - 1;
    while (left < right) {
        if (arr[left] == arr[right]) {
            left++;
            right--;
        } else {
            return false;
        }
    }
    return true;
}
```

### 复杂度

| 类型 | 复杂度 | 说明 |
|------|--------|------|
| 时间 | O(n) | 遍历两遍 + 夹一遍 |
| 空间 | O(n) | 数组存所有值 |

## 解法二：快慢指针 + 反转后半段（最优）

### 原理图解

三步走：**找中点 → 反转后半段 → 两头对读**

**偶数长度**：`1 → 2 → 2 → 1`，节点记作 ① ② ③ ④

- slow：指向③
- 后半部分反转之后为 right：1 -> 2 -> null
- 前半部分为：1 -> 2 -> 2 -> null
- <mark>所以前半部分长</mark>

**奇数长度**：`1 → 2 → 3 → 2 → 1`，节点记作 ① ② ③ ④ ⑤

```text
找中点：
  第1轮   slow ①→②    fast ①→③
  第2轮   slow ②→③    fast ③→⑤
  第3轮   fast.next == null，循环停
  ⇒ slow = ③，落在【正中间那个节点】

反转 slow 起的后半段（③ ④ ⑤）：
  head  链：① → ② → ③ → null      长 3
  right 链：⑤ → ④ → ③ → null      长 3
                       ↑
            两条链等长，末节点是同一个 ③（中间节点自己跟自己比，必然相等）
```

| 长度 | slow 落点 | head 链长 | right 链长 |
|------|-----------|-----------|------------|
| 偶数 n | 第 n/2+1 个节点（后半段第 1 个） | n/2 + 1 | n/2 |
| 奇数 n | 第 (n+1)/2 个节点（正中间） | (n+1)/2 | (n+1)/2 |

<mark>**结论**：反转只改 `slow` 及之后的 next，`slow` 前一个节点仍指向 `slow`，所以偶数时 head 链比 right 链**多 1 个节点**。两头对读必须以走完 **right 链（短的那条）** 为终止条件，即 `while (p2 != null)`；写成 `while (p1 != null)` 时，偶数回文（如 `1→2→2→1`、`1→1`）会在最后一次比较时因 `p2 == null` 抛 NPE。</mark>

### 算法步骤

1. **找中点**：慢指针走 1 步、快指针走 2 步，快指针到末尾时慢指针正好在中间
2. **反转后半段**：用迭代法反转 `slow` 之后的部分（复用 206 题）
3. **两头对读**：`p1` 从 head、`p2` 从反转后的后半段头，同步比较

### 代码实现

```java
public boolean isPalindrome_2(ListNode head) {
    if (head == null) return true;

    // 1. 找中点：慢走1步，快走2步，快指针到末尾时慢指针在中间
    ListNode slow = head;
    ListNode fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }

    // 2. 反转后半段
    ListNode right = reverseList(slow);

    // 3. 两头对读
    ListNode p1 = head;
    ListNode p2 = right;
    while (p2 != null) {
        if (p1.val == p2.val) {
            p1 = p1.next;
            p2 = p2.next;
        } else {
            return false;
        }
    }
    return true;
}

public ListNode reverseList(ListNode head) {
    ListNode prev = null;
    ListNode curr = head;
    while (curr != null) {
        ListNode temp = curr.next;
        curr.next = prev;
        prev = curr;
        curr = temp;
    }
    return prev;
}
```

### 复杂度

| 类型 | 复杂度 | 说明 |
|------|--------|------|
| 时间 | O(n) | 找中点 n/2 + 反转 n/2 + 比较 n/2 |
| 空间 | O(1) | 只用了几个指针 |

---

## 两种解法对比

| 维度 | 数组法 | 快慢指针 + 反转 |
|------|--------|----------------|
| 时间 | O(n) | O(n) |
| 空间 | O(n) | **O(1)** |
| 难度 | 简单直接 | 需要组合两个技巧 |
| 适用 | 快速写出 | 面试最优解 |

**为什么快慢指针能省掉数组？**
数组法的核心诉求是"能从后往前读"。反转后半段之后，从后往前读 = 从反转段的头往后读，一个原地反转就替代了整个数组，空间从 O(n) 降到 O(1)。

---

## 易错点

1. **快慢指针循环条件写错**：`while (fast != null && fast.next != null)` 两个条件缺一不可，否则 `fast.next.next` 会 NPE
2. **中点找偏**：奇数长度链表（如 1→2→1），slow 会停在正中间（2），反转后半段后比较逻辑依然正确，但要想清楚慢指针停的位置
3. **反转时忘记先存 `temp`**：断链后找不回下一个节点（206 题的老坑）
4. **对读循环必须以 `p2 != null` 为条件，不能以 `p1 != null`**：接缝未断，偶数长度时 head 链比 right 链多 1 个节点，`p1` 会多走一步撞上 `p2 == null` 抛 NPE（`1→2→2→1`、`1→1` 都会中招）；奇数长度两条链等长，谁做条件都行
