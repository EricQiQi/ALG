# 算法笔记：二叉树的右视图（力扣 199 题）

## 题目描述
给定一个二叉树的**根节点** `root`，想象自己站在它的**右侧**，按照从顶部到底部的顺序，返回从右侧所能看到的节点值。

```
输入:
        1
       / \
      2   3
       \   \
        5   4
输出: [1,3,4]   （每层最右边的节点）
```

> 右视图 = **每一层最右边的节点**。注意不是"一路往右走"，某层右边为空时要看左边（如第 2 层的 5 在左子树里）。

---

## 核心思想

两种思路：

### 方法一：BFS 层序遍历
标准层序遍历，每层用 `size` 锁定当前层节点数，取**每层最后一个**（`i == size - 1`）即为右视图节点。

### 方法二：DFS（根 → 右 → 左）
按"**根、右、左**"的顺序深度优先。因为先走右边，每层**第一个被访问到**的节点就是该层最右节点。用 `depth > res.size()` 判断"这一层还没记录过"，是首次到达该深度就记录。

---

## 图解

```
        1            ← 第1层最右 = 1
       / \
      2   3          ← 第2层最右 = 3
       \   \
        5   4        ← 第3层最右 = 4

右视图 = [1, 3, 4]

DFS(根→右→左) 访问顺序：1 → 3 → 4 → 2 → 5
  depth=1 记录 1；depth=2 先遇到 3 记录；depth=3 先遇到 4 记录；
  之后到 2(depth2)、5(depth3) 时 depth 不再 > res.size()，跳过。
```

---

## 代码实现 (Java)

### 方法一：BFS

```java
public static List<Integer> rightSideView_1(TreeNode root) {
    List<Integer> res = new ArrayList<>();
    if (root == null) return res;

    Deque<TreeNode> queue = new ArrayDeque<>();
    queue.offer(root);
    while (!queue.isEmpty()) {
        int size = queue.size();               // 锁定当前层
        for (int i = 0; i < size; i++) {
            TreeNode node = queue.poll();
            if (node.left != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
            if (i == size - 1) res.add(node.val); // 每层最后一个
        }
    }
    return res;
}
```

### 方法二：DFS（根→右→左）

```java
public static List<Integer> rightSideView_2(TreeNode root) {
    List<Integer> res = new ArrayList<>();
    rightOrder(root, res, 1);
    return res;
}

private static void rightOrder(TreeNode root, List<Integer> res, int depth) {
    if (root == null) return;
    if (depth > res.size()) {          // 这一层还没记录 → 当前是首次到达（最右）
        res.add(root.val);
    }
    rightOrder(root.right, res, depth + 1);  // 先右
    rightOrder(root.left, res, depth + 1);   // 后左
}
```

## ❗关键易错点

**1. 右视图 ≠ 一路向右走**
不能只顺着 `root.right` 往下，否则左子树更深时会漏掉节点（如上面的 5 若在更深层）。必须"每层取最右"。

**2. BFS 里用 `size` 锁层，取 `i == size - 1`**
`size` 要在 for 循环前固定下来，否则循环中 offer 会改变 queue 大小导致层混乱。

**3. DFS 必须先右后左，且用 `depth > res.size()` 去重**
先访问右边保证每层第一个到达的是最右节点；`depth > res.size()` 确保每层只记录一次。

---

## 复杂度分析

* **时间复杂度**：$O(n)$。每个节点访问一次。
* **空间复杂度**：BFS 为 $O(w)$（w 为最大层宽）；DFS 为 $O(h)$（h 为树高，递归栈）。
