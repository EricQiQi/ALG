# 排序算法

## 归并排序 (Merge Sort)

### 核心思想

> **拆到底，再合并：分治法，先递归拆成单个元素，再两两合并成有序区间**

与快排相反：快排是"先排好基准位置，再递归两边"；归并是"先递归拆分，回来时才合并排序"。

---

### 图像记忆法：两队合并报数

把合并（merge）想象成**两列已经各自排好队的士兵**要合成一列：

**左队 `[left, mid]`** 和 **右队 `[mid+1, right]`** 都是有序的。

**双指针 i、j** — 分别站在两队队头，比较谁小，谁小谁先出列，进入临时数组 `temp`。

**走完一队** — 某一队全部出列后，另一队剩下的直接原样搬进 `temp`（因为它们本来就有序）。

**回写** — `temp` 是合并好的有序结果，最后拷贝回原数组 `[left, right]`。

---

### 递归分解全景图

```
原始: [3, 4, 1, 2, 5]
              ↓ 拆分
      [3,4,1]     [2,5]
        ↓            ↓
    [3] [4,1]     [2] [5]
         ↓
      [4] [1]
         ↓ 合并
    [3] [1,4]     [2] [5]
       ↓             ↓
   [1,3,4]        [2,5]
       ↓_____________↓ merge
   [1, 2, 3, 4, 5]
```

**拆分只负责"切"，真正的排序发生在"合并"回来的路上。**

---

### 一句话记住 Merge

```
两队比头，小的先走，一队走完，另一队全搬，最后回写
```

---

### 代码结构速记

```
mergeSort(arr, left, right)
├── 终止条件: left >= right → return
├── mid = (left + right) / 2
├── mergeSort(left, mid)        ← 排左半
├── mergeSort(mid + 1, right)   ← 排右半
└── merge(arr, left, mid, right)
    ├── temp[right - left + 1]
    ├── i=left, j=mid+1, k=0
    ├── while (i <= mid && j <= right)   ← 两队都比完
    │   └── 小的放 temp[k++]
    ├── while (i <= mid)   ← 左队剩余
    ├── while (j <= right) ← 右队剩余
    └── temp 拷贝回 arr[left..right]
```

---

### 关键易错点

**1. 区间是闭区间 `[left, right]`，循环一定带等号**

端点元素（`mid`、`right` 位置）都要被处理，所以是 `i <= mid`、`j <= right`，写成 `<` 会丢元素。
判断口诀：*端点这个元素要不要处理？要 → 带等号。*

**2. 两个"收尾 while"不能省**

主循环退出时，只有一队走完，另一队还剩一段。因为剩余段本身有序，直接整段搬进 `temp` 即可。

**3. 回写下标 `temp[i - left]`**

`temp` 从 0 开始存，原数组从 `left` 开始，拷贝时用 `i - left` 做偏移，别写成 `arr[i] = temp[i]`。

**4. `if (arr[i] < arr[j])` 用 `<` 而非 `<=` 影响稳定性**

相等时优先取左队元素（`else` 分支取右队），保证归并排序是**稳定排序**。

---

### 复杂度

| | 平均 | 最坏 | 最好 |
|---|---|---|---|
| 时间 | O(n log n) | O(n log n) | O(n log n) |
| 空间 | O(n) | O(n) | O(n) |

> 时间复杂度恒定 O(n log n)，不受初始顺序影响（比快排更稳）；代价是需要 O(n) 的额外空间 temp。

> **记忆口诀**：归并分治拆到底，两队比头小先走，一队走完另一队搬，回写偏移别忘 left
