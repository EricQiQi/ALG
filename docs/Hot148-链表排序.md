# 链表排序（Sort List）

## 题目描述

给你链表的头节点 `head`，将其**升序**排列并返回排序后的链表。

要求：O(n log n) 时间复杂度，O(1) 空间复杂度（进阶）。

```
输入：4 -> 2 -> 1 -> 3
输出：1 -> 2 -> 3 -> 4
```

---

## 核心思路

**链表排序 = 归并排序。** 数组用下标二分，链表用快慢指针找中点。

归并排序三步：
1. **分**：找中点，断开成两半
2. **治**：递归排序两半
3. **合**：合并两个有序链表

---

## 方法1：自顶向下（递归）

### 代码

```java
public ListNode sortList(ListNode head) {
    if (head == null || head.next == null) return head;

    // 1. 快慢指针找中点
    ListNode slow = head;
    ListNode fast = head.next;  // fast 先走一步，偶数时 slow 停在前半段
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }

    // 2. 断开链表
    ListNode mid = slow.next;
    slow.next = null;

    // 3. 递归排序两半
    ListNode left = sortList(head);
    ListNode right = sortList(mid);

    // 4. 合并
    return merge(left, right);
}
```

### 复杂度

| 类型 | 复杂度 | 说明 |
|------|--------|------|
| 时间 | O(n log n) | 每层合并 O(n)，共 log n 层 |
| 空间 | O(log n) | 递归栈深度 |

---

## 方法2：自底向上（迭代）

### 思路

不用递归，而是**从小段到大**逐步合并：

```
步长 step = 1 → 2 → 4 → 8 → ...

step=1: 每1个节点一组，两两合并
  4|2|1|3  →  [2,4] [1,3]  →  2->4->1->3

step=2: 每2个节点一组，两两合并
  [2,4] [1,3]  →  [1,2,3,4]

step=4 >= len=4，结束
```

### 代码

```java
public ListNode sortList(ListNode head) {
    if (head == null || head.next == null) return head;

    int len = 0;
    for (ListNode p = head; p != null; p = p.next) len++;

    ListNode dummy = new ListNode(0);
    dummy.next = head;

    for (int step = 1; step < len; step <<= 1) {
        ListNode prev = dummy;
        ListNode curr = dummy.next;

        while (curr != null) {
            ListNode left = curr;
            ListNode right = split(left, step);
            curr = split(right, step);
            prev.next = merge(left, right);
            while (prev.next != null) prev = prev.next;
        }
    }
    return dummy.next;
}

// 走 step 步断开，返回下一段头
ListNode split(ListNode head, int step) {
    for (int i = 1; head != null && i < step; i++) head = head.next;
    if (head == null) return null;
    ListNode next = head.next;
    head.next = null;
    return next;
}
```

### 复杂度

| 类型 | 复杂度 | 说明 |
|------|--------|------|
| 时间 | O(n log n) | 每轮合并 O(n)，共 log n 轮 |
| 空间 | **O(1)** | 没有递归栈，纯迭代 |

---

## 两种方法对比

| | 自顶向下（递归） | 自底向上（迭代） |
|--|----------------|----------------|
| 思路 | 先拆到最小，再合并回来 | 从小段开始，逐步扩大 |
| 空间 | O(log n) 递归栈 | O(1) |
| 代码 | 更简洁直观 | 稍复杂，需要 split + prev 拼接 |
| 面试建议 | **必须会** | 加分项，面试官追问 O(1) 空间时写 |

---

## 关键设计点

### 快慢指针找中点

```java
ListNode slow = head;
ListNode fast = head.next;  // 注意：fast 先走一步
```

`fast = head.next` 而不是 `head`，是为了偶数长度时 slow 停在**前半段末尾**，断开后前半段 ≤ 后半段。

### merge 模板

合并两个有序链表是通用模板，Hot21（合并两个有序链表）也是这个：

```java
ListNode merge(ListNode l1, ListNode l2) {
    ListNode dummy = new ListNode(0), curr = dummy;
    while (l1 != null && l2 != null) {
        curr.next = (l1.val < l2.val) ? l1 : l2;
        // 小的走一步
        if (l1.val < l2.val) l1 = l1.next; else l2 = l2.next;
        curr = curr.next;
    }
    curr.next = (l1 != null) ? l1 : l2;
    return dummy.next;
}
```

---

## 易错点

1. **fast 初始值**：`fast = head.next`（不是 head），否则偶数长度时中点偏后，可能无限递归
2. **断开链表**：`slow.next = null` 别忘了，否则递归不会终止
3. **自底向上的 prev 拼接**：每轮合并后，`prev` 要走到合并结果的末尾，才能接下一段
4. **链表不能像数组那样随机访问**：所以不能用堆排序或快排（快排需要随机访问），归并排序是最适合的
