int mid = left + (right-left)/2;
int mid = (left + right) / 2;
int mid = (left + right + 1) / 2;
int mid = (left + right + rand.nextInt(2)) / 2;

## 对比总结

| 写法 | 取值偏向 | 溢出风险 | 适用场景 |
|------|---------|---------|----------|
| `left + (right-left)/2` | 左中位数 ⌊(l+r)/2⌋ | 无 | **通用首选**，二分查找标准写法 |
| `(left+right)/2` | 左中位数 ⌊(l+r)/2⌋ | 有（l+r 可能越界） | 理论正确但不实用，生产环境不推荐 |
| `(left+right+1)/2` | 右中位数 ⌈(l+r)/2⌉ | 有 | 二分答案中需要向上取整时（如 `l==r-1` 防死循环） |
| `(left+right+rand.nextInt(2))/2` | 随机取左中或右中 | 有 | 快排随机 pivot，避免有序数组退化为 O(n²) |

### 关键点

1. **防溢出**：`left + (right-left)/2` 是唯一不会溢出的写法，因为 `right-left` 一定 ≤ `Integer.MAX_VALUE`
2. **左中 vs 右中**：
   - 向下取整（左中）：当区间长度为偶数时，mid 偏左，如 `[0,3]` → mid=1
   - 向上取整（右中）：当区间长度为偶数时，mid 偏右，如 `[0,3]` → mid=2
3. **防死循环**：二分模板中若 `l = mid`（左边界右移），必须用**右中**，否则 `l==r-1` 时 mid=l 导致死循环；反之若 `r = mid`，用**左中**
4. **快排优化**：随机选 pivot 可将期望时间稳定在 O(n log n)，避免最坏情况
