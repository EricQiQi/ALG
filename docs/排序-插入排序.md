# 排序算法

## 插入排序 (Insertion Sort)

### 核心思想

> **摸牌插牌：把每个新元素插入到左边已排好区的正确位置**

像抓扑克牌：左手边的牌始终保持有序，每摸一张新牌，就从右往左比，比它大的往后挪一位，找到合适位置插进去。

---

### 图像记忆法：左边有序，逐个插入

```
竖线左边是已排好的牌，每次摸右边第一张插进左边

[3] | 1, 4, 1, 5
  ↓ 摸到 1：3 比它大→后移，插到最前
[1, 3] | 4, 1, 5
  ↓ 摸到 4：都比它小，原地不动
[1, 3, 4] | 1, 5
  ↓ 摸到 1：4、3、1 逐个后移，插到 1 后面（相等就停 → 稳定）
[1, 1, 3, 4] | 5
  ↓ 摸到 5：不动
[1, 1, 3, 4, 5]

每轮把已排好区的边界向右扩一格
```

---

### 一句话记住

```
外层从 1 起摸牌，先存 key，左边比它大的往后挪，挪完在空位插 key
```

---

### 代码结构速记

```
insertionSort(arr)
├── n = arr.length
├── for (i=1; i<n; i++)            ← 从第 2 个开始摸牌（第 0 个天然有序）
│   ├── key = arr[i]               ← 先暂存当前要插入的牌
│   ├── j = i - 1
│   ├── while (j >= 0 && arr[j] > key)   ← 左边大的逐个后移
│   │   ├── arr[j+1] = arr[j]
│   │   └── j--
│   └── arr[j+1] = key             ← 落到找到的空位
└── 结束
```

---

### 关键易错点

**1. 必须先 `key = arr[i]` 暂存**

后移操作 `arr[j+1] = arr[j]` 会覆盖掉 `arr[i]`，不先存起来，最后就没牌可插了。

**2. 后移是赋值，不是 swap**

`arr[j+1] = arr[j]` 只把大牌往右挪一格，空位一路左移，最后 `arr[j+1] = key` 填进去。别写成两两交换。

**3. 落位下标是 `j+1` 而不是 `j`**

循环退出时 `j` 已经多减了一次（停在"比 key 小的位置"或 `-1`），真正该插的位置是它的右边 `j+1`。

**4. `arr[j] > key` 用 `>` 而非 `>=`，保证稳定**

遇到相等的牌就停下、不越过它，相同元素的相对顺序不变，所以插入排序是**稳定排序**。

**5. `while (j >= 0 && arr[j] > key)` 的顺序**

先判 `j >= 0` 再访问 `arr[j]`，短路求值防止 `arr[-1]` 越界，两个条件不能颠倒。

---

### 复杂度

| | 平均 | 最坏 | 最好 |
|---|---|---|---|
| 时间 | O(n²) | O(n²) | O(n)（已有序）|
| 空间 | O(1) | O(1) | O(1) |

> 最好情况 O(n)：数组本就有序，每个新元素比一眼就停，内层 while 一次都不进。所以它对**近乎有序**的数据特别快，常数也小——这正是快排、归并在小区间、TimSort 底层都改用插入排序的原因。

> **记忆口诀**：插入摸牌插左边，先存 key 再后移，相等就停保稳定，基本有序快如飞
