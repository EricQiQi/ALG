# LeetCode 78. 子集

对应源码：[Hot78_permute.java](../src/s10_backTracking/Hot78_permute.java)

## 题目描述

给定一个**不含重复元素**的整数数组 `nums`，返回该数组所有可能的子集（幂集）。

例：`nums = {1, 2, 3}` → `[[], [1], [1,2], [1,2,3], [1,3], [2], [2,3], [3]]`，共 2^3 = 8 个。

## 💡 大白话解析（start 索引法回溯）

子集就是"从数组里挑几个数，挑谁都不挑都行"。回溯的做法是**沿着一条"只能往后挑"的路走，走到的每个状态都是一个子集**：

1. 每进入一个节点，**先收割**当前已挑的组合（包括什么都不挑的空集）；
2. 然后从 `start` 开始，逐个尝试"把 `nums[i]` 挑进来"，递归下去（下一层只能从 `i+1` 往后挑）；
3. 递归返回后把 `nums[i]` 撤销，换下一个数试。

**为什么不会重复？** `start` 保证了只挑下标递增的元素——`[1,2]` 只会以"先 1 后 2"这一种顺序被挑出来，`[2,1]` 根本不存在。这和全排列（每个顺序都算不同答案）是本质区别。

```
决策树（每条边 = 挑/不挑某个数，节点 = 收割的子集）：
              []                    ← 进入就收（空集）
        ┌─────┼─────┐
       挑1   挑2   挑3
        │     │     │
       [1]  [2]   [3]              ← 每个节点都收
       ┌┴┐   └┐
     挑2 挑3  挑3
      │   │    │
    [1,2][1,3][2,3]
      │
    挑3
      │
   [1,2,3]

收割顺序：[], [1], [1,2], [1,2,3], [1,3], [2], [2,3], [3] —— 恰好 2^n 个
```

## 💻 Java 代码实现

```java
private List<List<Integer>> res = new ArrayList<>();
private List<Integer> output = new ArrayList<>();   // 当前正在构造的子集

public List<List<Integer>> subsets(int[] nums) {
    backTrack(nums, 0);
    return res;
}

public void backTrack(int[] nums, int start) {
    // 进入每个节点就收割：子集问题是"每个节点都是答案"，不用等钻满
    // 必须拷贝！output 后续还会被增删，直接 add 会让所有结果指向同一个对象
    res.add(new ArrayList<>(output));

    for (int i = start; i < nums.length; i++) {
        output.add(nums[i]);              // 做选择：挑 nums[i]
        backTrack(nums, i + 1);           // 递归：只能从 i 之后挑，不回头
        output.remove(output.size() - 1); // 撤销选择：恢复现场
    }
}
```

## 复杂度分析

| 项 | 复杂度 | 说明 |
| :--- | :---: | :--- |
| 时间 | O(n × 2^n) | 共 2^n 个子集，每个收割时拷贝要 O(n) |
| 空间 | O(n) 递归栈 | 不计输出数组 |

## ⚠️ 易错点

1. **收割时忘记拷贝**：和全排列同理，`res.add(output)` 会让所有结果指向同一个 list，最后全部变成空集（撤销操作会清空它）。必须 `new ArrayList<>(output)`。
2. **递归传 `i+1` 写成 `start+1`**：`start+1` 会回头重选前面的元素，产生大量重复且遗漏；必须是**当前选中的 `i`** 的下一个。
3. **收割位置写在循环里**：子集是"每个节点都收"，收割必须在 for 循环**之前**（一进节点就收）；写成循环里会漏掉空集和中间子集。
4. **含重复元素时此模板不够**：本题保证无重复；Hot90（子集 II）输入含重复，需先排序，再用 `i > start && nums[i] == nums[i-1]` 跳过同层重复分支。

## 🆚 和全排列（Hot46）的对比

| | 全排列 Hot46 | 子集 Hot78 |
| :--- | :--- | :--- |
| 答案数量 | n! | 2^n |
| 去重手段 | 交换法：候选池 `[first, len)` | start 索引：只往后挑 |
| 收割时机 | 钻满才收（`first == len`） | 每个节点都收（一进来就收） |
| 顺序要求 | 不保证字典序 | 输出天然按"先挑谁"分组 |

## 🧠 记忆口诀

> **一进门就收（连空集都不放过），从 start 往后挑，挑了就撤。**
