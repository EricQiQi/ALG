# 二叉树的最近公共祖先

## 题目描述

给定二叉树中两个节点 `p` 和 `q`，找到它们的**最近公共祖先**（LCA）。

```
         3
        / \
       5   1
      / \ / \
     6  2 0  8
       / \
      7   4

p=5, q=1 → LCA=3（p、q 分列根节点两侧）
p=5, q=4 → LCA=5（p 本身就是 q 的祖先）
```

---

## 后序遍历递归

### 思路

从根节点出发，后序遍历（左 → 右 → 根），每棵子树返回"是否找到了 p 或 q"：

```
        root
       /    \
   left    right
  找到p?    找到q?
```

三种情况：
- **left 和 right 都非空** → p、q 分别在两侧，当前 root 就是 LCA
- **只有一侧非空** → p、q 都在那一侧，把那一侧的结果往上传
- **都为空** → 这棵子树里没有 p 也没有 q，返回 null

**关键洞察**：不需要知道 p 和 q 具体在哪一层，递归返回值自然会把"找到的节点"向上传递。当 p 和 q 第一次从不同侧汇合时，汇合点就是 LCA。

### 代码

```java
public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
    // 终止条件：遇到 null / p / q 就返回
    if (root == null || root == p || root == q) return root;

    TreeNode left = lowestCommonAncestor(root.left, p, q);
    TreeNode right = lowestCommonAncestor(root.right, p, q);

    // 两侧都有 → 当前节点就是 LCA
    if (left != null && right != null) return root;
    // 只有一侧有 → 把那一侧的结果往上传
    return left != null ? left : right;
}
```

### 复杂度

| 类型 | 复杂度 | 说明 |
|------|--------|------|
| 时间 | O(n) | 每个节点访问一次 |
| 空间 | O(h) | 递归栈深度 = 树高 |

## 核心逻辑图解

```
场景1：p、q 分列两侧
         3 ← left=5, right=1，两侧都非空 → 3 就是 LCA
        / \
       5   1

场景2：p 是 q 的祖先
         5 ← left=null, right=4（或反过来），只有一侧非空 → 返回 5
        / \
       .   4

场景3：p、q 在同一侧
         3 ← left=5, right=null → 返回 left=5
        / \
       5   .
      / \
     p   q
```

---

## 易错点

1. **终止条件三合一**：`root == null || root == p || root == q`，缺一不可。遇到 p 或 q 就返回，不是等到找到 LCA 才返回
2. **比较用 `==` 不是 `.val`**：LCA 找的是同一个节点对象（引用），不是值相等
3. **不需要额外判断 p 是 q 的祖先**：场景2 自然被"只有一侧非空"覆盖，不需要特殊处理
