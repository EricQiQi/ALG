# Arrays.sort 原理详解

Java 的 `Arrays.sort()` 是**分而治之**思想的典型应用。它会根据数据类型和数组规模，自动选择最优的排序算法。

---

## 一、基础：快速排序（QuickSort）

要理解 `Arrays.sort`，必须先懂快速排序。

### 核心思想

1. 从数组中选一个元素作为**基准值（pivot）**
2. 把数组分成两部分：**比 pivot 小的放左边，比 pivot 大的放右边**
3. 对左右两部分**递归**执行同样的操作
4. 当所有子区间都排好序时，整个数组就有序了

### 示例

```
数组: [5, 3, 8, 1, 9, 2]，选 pivot = 5

第一轮划分:
[3, 1, 2]   [5]   [8, 9]
   ↓         ↓       ↓
递归排序   基准就位  递归排序

结果: [1, 2, 3, 5, 8, 9] ✅
```

### 复杂度

| 情况 | 时间复杂度 |
|------|-----------|
| 最好/平均 | O(n log n) |
| 最坏（已排序数组） | O(n²) |

## 二、Java 的实际实现（分情况讨论）

`Arrays.sort()` 并不是一种算法，而是**多种算法的智能组合**：

### 1️⃣ 基本类型数组（int[]、char[] 等）

使用 **双轴快速排序（Dual-Pivot QuickSort）**

```
选取两个基准值 pivot1 和 pivot2（pivot1 ≤ pivot2）
把数组分成三段：
   [ < pivot1 ] [ pivot1 ~ pivot2 ] [ > pivot2 ]
对三段分别递归排序
```

**为什么用双轴？** 比普通快排多一次划分，递归深度更浅，实际运行更快。

### 2️⃣ 对象数组（String[]、Integer[] 等）

使用 **TimSort**（归并排序的优化版），因为对象排序需要**稳定性**（相等的元素保持原顺序）。

### 3️⃣ 小数组优化（元素个数 < 47）

直接使用**插入排序**，因为小数组插入排序的常数因子更小，比快排更快。

## 三、在字母异位词题目中的实际执行过程

回到 S1_hash.Hot2 这道题，`s = "eat"` 时：

```java
char[] arr = s.toCharArray();   // arr = ['e', 'a', 't']
Arrays.sort(arr);               // 对字符数组排序
```

执行步骤：

```
['e', 'a', 't']
   ↓ 双轴快排（3个元素，实际走插入排序）
比较 'e' 和 'a' → 交换 → ['a', 'e', 't']
比较 'e' 和 't' → 不交换
   ↓
['a', 'e', 't'] ✅
```

**时间复杂度：O(k log k)**，k 是字符串长度。

---

## 四、一张图总结

```
Arrays.sort(arr)
    │
    ├── 基本类型? ──→ 双轴快速排序（不稳定，快）
    │                    │
    │                    └── 小数组（<47）→ 插入排序
    │
    └── 对象类型? ──→ TimSort（稳定，归并优化）
```

---

## 五、稳定性对比

| 算法 | 稳定性 | 时间复杂度 | 空间复杂度 |
|------|--------|-----------|-----------|
| 双轴快速排序 | ❌ 不稳定 | O(n log n) | O(log n) |
| TimSort | ✅ 稳定 | O(n log n) | O(n) |
| 插入排序 | ✅ 稳定 | O(n²) | O(1) |

> **稳定性**：相等的元素在排序后保持原来的相对顺序。

---

## 💡 一句话记忆

> **Arrays.sort = 大数组用快排/TimSort + 小数组用插入排序，自动选最优。**

理解了"分而治之"的思想，就掌握了它的核心。
