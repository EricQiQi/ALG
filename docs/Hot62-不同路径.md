# 算法笔记：不同路径（力扣 62 题）

## 题目描述
一个机器人位于 `m x n` 网格的**左上角**（起点 `(0, 0)`）。

机器人每次只能向**下**或者向**右**移动一步，目标是到达网格的**右下角**（终点 `(m-1, n-1)`）。

问总共有多少条**不同的路径**？

```
输入：m = 3, n = 7
输出：28

输入：m = 3, n = 2
输出：3
解释：从左上角到右下角一共有 3 条路径：
     下下右、下右下、右下下。
```

> 📌 关键理解：只能向下或向右走，意味着到达任意格子 `(i, j)` 的**最后一步**只有两种来源——从上方 `(i-1, j)` 走下来，或从左方 `(i, j-1)` 走过来。所以「到 `(i,j)` 的路径数 = 到上方的路径数 + 到左方的路径数」，这正是二维的斐波那契式递推（DP）。

---

## 解法：多维动态规划（二维 DP 网格）

### 1. 核心思想
把「从起点走到某个格子的路径数」定义为状态，用「最后一步从哪来」推出转移方程。

* **状态定义**：`dp[i][j]` 表示从起点 `(0, 0)` 走到格子 `(i, j)` 的不同路径数。
* **状态转移**：走到 `(i, j)` 的最后一步要么来自上方，要么来自左方，二者相加：
  $$dp[i][j] = dp[i-1][j] + dp[i][j-1]$$
* **边界（初始条件）**：
  * 第一列 `dp[i][0] = 1`：只能一路向下，路径唯一。
  * 第一行 `dp[0][j] = 1`：只能一路向右，路径唯一。
* **返回**：`dp[m-1][n-1]`。

> 递推顺序是「从上到下、从左到右」，保证计算 `dp[i][j]` 时它依赖的上方 `dp[i-1][j]` 和左方 `dp[i][j-1]` 都已算好。

### 2. 代码实现 (Java)

```java
class Solution {
    public int uniquePaths(int m, int n) {
        int[][] dp = new int[m][n];

        // 边界：第一列、第一行都只有一条路径
        for (int i = 0; i < m; i++) dp[i][0] = 1;
        for (int j = 0; j < n; j++) dp[0][j] = 1;

        // 从上到下、从左到右逐格递推
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                // 最后一步：从上方 (i-1,j) 下来，或从左方 (i,j-1) 过来
                dp[i][j] = dp[i - 1][j] + dp[i][j - 1];
            }
        }
        return dp[m - 1][n - 1];
    }
}
```

### 3. 复杂度分析
* **时间复杂度**：$O(m \times n)$。每个格子只被计算一次，双重循环遍历整个网格。
* **空间复杂度**：$O(m \times n)$。开了 `m x n` 的二维 DP 数组。（可优化到 $O(n)$，见总结）

### 4. 递推过程图解
以 `m = 3, n = 3` 为例，第一行、第一列先填 1，其余格子 = 上方 + 左方：

```text
        j=0   j=1   j=2
i=0      1     1     1        ← 第一行全 1
i=1      1     2     3        ← 2=1+1, 3=1+2
i=2      1     3     6        ← 3=1+2, 6=3+3
        ↑
     第一列全 1
返回 dp[2][2] = 6
```

> 直观记忆：网格里的每个数就像杨辉三角「斜着摆」的样子——每个格子 = 上格 + 左格，起点那条边（首行首列）恒为 1。

---

## 💡 总结
不同路径是**二维线性 DP 的入门模板**：状态 `dp[i][j]` 只依赖上方和左方两个相邻格子，边界（首行首列）单独置 1，然后从上到下、从左到右铺满整张网格即可。它与杨辉三角、爬楼梯同源——都是「每个位置 = 有限个前驱之和」。

| 特性 | 说明 |
| :--- | :--- |
| **思维出发点** | 只能向下/向右，最后一步必来自上方或左方，故 `dp[i][j]=dp[i-1][j]+dp[i][j-1]`。 |
| **边界** | 首行 `dp[0][j]=1`、首列 `dp[i][0]=1`（只有一条直线路径）。 |
| **时间 / 空间** | $O(mn)$ / $O(mn)$。 |

> 🔧 空间优化思路：由于 `dp[i][j]` 只用到「本行左方」和「上一行同列」，可把二维压成一维 `dp[j]`，每行更新时 `dp[j] += dp[j-1]`（`dp[j]` 是上一行的旧值=上方，`dp[j-1]` 是本行已更新的新值=左方），空间降到 $O(n)$。这与爬楼梯的滚动变量是同一套思想。

> ⚠️ 易错点：
> 1. **边界必须先初始化**——若首行首列没填 1，递推会全从 0 累加，结果恒为 0。
> 2. **循环从 `i=1`、`j=1` 起步**，因为第 0 行第 0 列已是边界，重复参与递推会算错。
> 3. **返回下标是 `dp[m-1][n-1]` 而非 `dp[m][n]`**，注意 `m` 是行数、`n` 是列数，别把网格尺寸和下标混用导致越界。
