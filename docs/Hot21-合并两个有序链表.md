# 算法笔记：合并两个有序链表（力扣 21 题）

## 题目描述
将两个**升序**链表合并为一个新的**升序**链表并返回。新链表由给定的两个链表所有节点组成。

```
输入: list1 = 1→2→4, list2 = 1→3→4
输出: 1→1→2→3→4→4
```

---

## 核心思想

> **哑节点 + 双指针比大小，谁小接谁，剩下一段直接拼。**

- `dummy` 哑节点起手，`curr` 指向结果链表的当前末尾；
- 两指针 `l1`、`l2` 同时比较，把**较小**的节点接到 `curr.next`，并推进对应指针；
- 某一条走完后，**另一条剩余部分已经有序**，一次性拼接上去即可。

---

## 图解：双指针归并

```
l1: 1→2→4      l2: 1→3→4      dummy → ?

比 1 vs 1 → 接 l1 的 1   dummy→1
比 2 vs 1 → 接 l2 的 1   dummy→1→1
比 2 vs 3 → 接 l1 的 2   dummy→1→1→2
比 4 vs 3 → 接 l2 的 3   dummy→1→1→2→3
比 4 vs 4 → 接 l1 的 4   dummy→1→1→2→3→4   (l1 空)
l1 走完 → 剩余 l2: 4 直接拼   dummy→1→1→2→3→4→4 ✅
```

这正是**归并排序 merge 步骤**在链表上的应用。

---

## 代码实现 (Java)

```java
public ListNode mergeTwoLists(ListNode list1, ListNode list2) {
    ListNode dummy = new ListNode(0);   // 哑节点，避免处理头部特例
    ListNode curr = dummy;

    ListNode l1 = list1, l2 = list2;
    while (l1 != null && l2 != null) {
        if (l1.val <= l2.val) {         // 谁小接谁（<= 保证稳定）
            curr.next = l1;
            l1 = l1.next;
        } else {
            curr.next = l2;
            l2 = l2.next;
        }
        curr = curr.next;
    }
    curr.next = (l1 == null) ? l2 : l1; // 剩余部分整体拼接
    return dummy.next;
}
```

---

## ❗关键易错点

**1. 剩余部分一行拼接，不用再循环**
`curr.next = l1 == null ? l2 : l1;`——因为剩余链表本身已经有序且都大于已接部分，直接挂上去即可。

**2. 用 `<=` 而非 `<`（稳定性）**
相等时优先接 `l1`，保持相同值节点的相对顺序，是稳定合并。

**3. 返回 `dummy.next`，不是 `dummy`**
哑节点是占位的哨兵，真正的头是它的下一个。

---

## 复杂度分析

* **时间复杂度**：$O(m + n)$。两个链表各遍历一次。
* **空间复杂度**：$O(1)$。只用了常数个指针，复用原有节点（未新建）。
