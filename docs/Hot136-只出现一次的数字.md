# 算法笔记：只出现一次的数字（力扣 136 题）

## 题目描述
给定一个**非空**整数数组，除了某个元素只出现一次以外，其余每个元素均出现**两次**。找出那个只出现了一次的元素。

**进阶**：设计并实现时间复杂度为 $O(n)$、空间复杂度为 $O(1)$ 的算法解决此问题。

```
输入：nums = [2,2,1]
输出：1

输入：nums = [4,1,2,1,2]
输出：4

输入：nums = [0,1]
输出：1
```

> 📌 关键理解：题目承诺"其余元素都出现两次"——这个成对性质就是解题钥匙。不需要真的统计次数，只需要一种运算让**相同的数两两自动抵消归零**，异或（XOR）恰好天生如此。

---

## 解法：位运算（异或消对）

### 1. 核心思想
按位异或：相同为 0，不同为 1。由此得到三条性质：

* $x \oplus x = 0$（自己消自己）
* $x \oplus 0 = x$（0 是单位元，谁都不消）
* 满足**交换律和结合律**（可以任意打乱顺序两两配对）

把整个数组连异或一遍，顺序被打乱也无所谓：所有成对的数两两抵消为 0，最后只剩下那个落单的数。

$$res = nums[0] \oplus nums[1] \oplus \cdots \oplus nums[n-1] = \underbrace{(a \oplus a)}_{0} \oplus \underbrace{(b \oplus b)}_{0} \oplus \cdots \oplus x = x$$

* **初始值**：`res = 0`（0 是异或单位元，从第一个数开始异或或先置 0 效果相同，置 0 还能天然处理写法统一）。
* **返回**：全部异或完的 `res`。

### 2. 代码实现 (Java)

```java
class Solution {
    public int singleNumber(int[] nums) {
        int res = 0;  // 0 是异或单位元：x ^ 0 = x
        for (int num : nums) {
            res ^= num;  // 成对的数异或后互相抵消为 0，落单者幸存
        }
        return res;
    }
}
```

### 3. 复杂度分析
* **时间复杂度**：$O(n)$。一次遍历。
* **空间复杂度**：$O(1)$。只用一个变量，无需任何辅助容器——这正是它优于哈希统计之处。
---

## 💡 总结
本题是**位运算技巧题的模板**：看见"成对出现 + 找一个落单"就直接条件反射连异或，$O(n)/O(1)$ 一步到位。它的精髓在于把"统计次数"这个哈希表问题，利用题目给的"其余都出现两次"弱化成"抵消"问题——算法复杂度骤降的关键往往是对**题目承诺性质的利用**。

| 特性 | 说明 |
| :--- | :--- |
| **思维出发点** | 成对出现 → 找一种两两自消的运算 → 异或（相同为 0）。 |
| **初始值** | `res = 0`（异或单位元）。 |
| **时间 / 空间** | $O(n)$ / $O(1)$，碾压哈希统计的 $O(n)$ 空间。 |
