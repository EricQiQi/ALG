# 算法笔记：除自身以外数组的乘积（力扣 238 题）

## 题目描述
给你一个整数数组 `nums`，返回数组 `answer`，其中 `answer[i]` 等于 `nums` 中除 `nums[i]` 之外其余各元素的乘积。

**要求**：不能使用除法，且在 $O(n)$ 时间复杂度内完成。

```
输入: nums = [1,2,3,4]
输出: [24,12,8,6]
解释: answer[0]=2×3×4=24, answer[1]=1×3×4=12, ...
```

---

## 核心思想

> **某个位置的答案 = 它左边所有数的乘积 × 它右边所有数的乘积。**

不能用除法（否则一步 `总积 / nums[i]` 就搞定，但题目禁止且有 0 的隐患），所以拆成**左积**和**右积**两趟分别算。

```
nums   = [ 1,   2,   3,   4 ]
左积 L  = [ 1,   1,   2,   6 ]   ← L[i] = i 左边所有数的乘积（L[0] 无左边 = 1）
右积 R  = [ 24,  12,  4,   1 ]   ← R[i] = i 右边所有数的乘积（R[n-1] 无右边 = 1）
答案    = [ 24,  12,  8,   6 ]   ← L[i] × R[i]
```

---

## 解法一：前缀积 + 后缀积（双数组）

### 思路
开 `left`、`right` 两个数组分别存左积和右积，最后对应位置相乘。

```java
public int[] productExceptSelf_1(int[] nums) {
    int n = nums.length;
    int[] res = new int[n], left = new int[n], right = new int[n];

    left[0] = 1;                       // 最左边没有元素，积为 1
    for (int i = 1; i < n; i++) {
        left[i] = left[i - 1] * nums[i - 1];
    }

    right[n - 1] = 1;                  // 最右边没有元素，积为 1
    for (int i = n - 2; i >= 0; i--) {
        right[i] = right[i + 1] * nums[i + 1];
    }

    for (int i = 0; i < n; i++) {
        res[i] = left[i] * right[i];
    }
    return res;
}
```

- **时间 O(n)**，**空间 O(n)**（额外用了 left、right 两个数组）

---

## 解法二：双指针（空间优化到 O(1)）

### 思路
既然左右两趟互不干扰，就用**两个指针 i、j 从两端同步向中间走**，把左积和右积**直接累乘进同一个结果数组 `res`**，省掉 left/right 两个数组。

```java
public int[] productExceptSelf_2(int[] nums) {
    int n = nums.length;
    int[] res = new int[n];
    for (int i = 0; i < n; i++) res[i] = 1;   // 关键：先全置 1（乘积的单位元）

    int leftProduct = 1;   // 从左往右的累乘值
    int rightProduct = 1;  // 从右往左的累乘值
    int i = 0, j = n - 1;

    while (i < n) {
        res[i] = res[i] * leftProduct;    // 左指针位置灌入左积
        leftProduct = leftProduct * nums[i];

        res[j] = res[j] * rightProduct;   // 右指针位置灌入右积
        rightProduct = rightProduct * nums[j];

        i++;
        j--;
    }
    return res;
}
```

- **时间 O(n)**，**空间 O(1)**（输出数组不计入，只用了几个变量）

---

## ❗关键易错点

**1. `res` 必须先初始化为 1，不能是默认的 0**
乘积的单位元是 1。若不初始化（默认 0），任何数乘 0 都是 0，结果全错。

**2. 双指针灌值必须"累乘" `res[i] = res[i] * leftProduct`，不能"覆盖" `res[i] = leftProduct`**

这是解法二最容易翻车的地方。因为 `res` 的同一个位置会被**访问两次**：
- 一次被**左指针 i** 灌入左积
- 一次被**右指针 j** 灌入右积

```
以 nums=[1,2,3,4] 为例，看 res[1] 的两次遭遇：
  左指针 i=1 时：res[1] = 1 × leftProduct(1) = 1     ← 先存左积
  右指针 j=1 时：res[1] = 1 × rightProduct(12) = 12  ← 再乘右积（累乘才对）

若第二次写成覆盖 res[1] = rightProduct(12)，
  就会把之前存的左积冲掉 → 只剩单边，结果错误。
```

所以两处都必须用 `*=`（累乘），让左右两积在同一个格子里相乘叠加。

---

## 💡 两种解法对比

| | 解法一 双数组 | 解法二 双指针 |
| :--- | :--- | :--- |
| **额外空间** | O(n)（left + right）| O(1)（复用 res）|
| **思路难度** | 直观好懂 | 需理解"同格累乘两次" |
| **易错点** | 边界 L[0]=R[n-1]=1 | res 初始化为 1 + 必须累乘 |

**结论**：解法一好理解、适合先讲清"左积×右积"的本质；解法二是面试进阶答案，把空间压到 $O(1)$，核心在于**双指针复用同一个结果数组、每格累乘两次**。

> **记忆口诀**：左积右积分开算，双指针同步往回灌；结果先置 1，累乘别覆盖，一格挨两次（左一次右一次）。
