# 排序算法

## 选择排序 (Selection Sort)

### 核心思想

> **每轮从未排序部分挑出最小的，放到已排序部分的末尾**

像打扑克理牌：每一趟从剩下的牌里翻遍全场找到最小的一张，抽出来摆到前面。找的过程只记录"最小牌的位置"，一趟走完才动手换一次。

---

### 图像记忆法：每轮选一个最小

```
每一轮在"竖线右边"里找最小，找到后换到竖线左边第一个空位

[64, 34, 25, 12]
  ↓ 第 1 轮：全场最小 12，换到位置 0
[12 | 34, 25, 64]
  ↓ 第 2 轮：剩余最小 25，换到位置 1
[12, 25 | 64, 34]
  ↓ 第 3 轮：剩余最小 34，换到位置 2
[12, 25, 34 | 64]

竖线左边是已选好的"最小队列"，每轮向右扩一格
```

---

### 一句话记住

```
外层管位置，内层找最小下标，一趟走完只换一次
```

---

### 代码结构速记

```
selectionSort(arr)
├── n = arr.length
├── for (i=0; i<n-1; i++)           ← 共 n-1 轮，最后一个自动归位
│   ├── min = i                      ← 先假设当前位置最小
│   ├── for (j=i+1; j<n; j++)        ← 在未排区 [i+1, n) 找更小的
│   │   └── if (arr[j] < arr[min]) min = j   ← 只记下标，不急着换
│   └── if (min != i) swap(i, min)   ← 一趟结束才换一次
└── 结束
```

---

### 关键易错点

**1. `min` 存的是"下标"不是"值"**

比较要写 `arr[j] < arr[min]`，更新写 `min = j`。若误把 min 当值来存，最后就没法 swap 了。

**2. 内层 `j` 从 `i+1` 开始**

`[0, i)` 已经选好、不用再管，只在未排区 `[i+1, n)` 里找最小。

**3. 外层是 `i < n-1` 而非 `i < n`**

前 n-1 个归位后，最后剩下的那个必然就在正确位置，最后一轮多余。

**4. 每轮只交换一次，这是它和冒泡的本质区别**

冒泡一趟可能换很多次（相邻不断往后冒），选择排序一趟只找最小、只在末尾换一次，**交换次数更少**（最多 n-1 次），但比较次数仍是 O(n²)。

**5. 选择排序不稳定**

`swap(arr, i, min)` 会把 `arr[i]` 直接甩到后面 `min` 的位置，可能打乱相同元素的先后顺序。

反例：`[5a, 5b, 2]`，第 1 轮最小是 `2`（下标 2），交换位置 0 和 2 → `[2, 5b, 5a]`，两个 5 的相对顺序被换反了。

---

### 复杂度

| | 平均 | 最坏 | 最好 |
|---|---|---|---|
| 时间 | O(n²) | O(n²) | O(n²) |
| 空间 | O(1) | O(1) | O(1) |

> 无论数据是否有序，比较次数固定是 `n(n-1)/2`，所以**没有 swapFlag 早退优化**，最好也是 O(n²)。优点是交换次数少且原地排序，适合"交换代价高、比较代价低"的场景。

> **记忆口诀**：选择每轮挑最小，记下标不记值，一趟只换一次，稳定谈不上
