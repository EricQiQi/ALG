## 147. 对链表进行插入排序

### 题目描述

使用插入排序对链表进行排序，返回排序后的链表头节点。

示例：
```
输入：4 → 2 → 1 → 3
输出：1 → 2 → 3 → 4
```

---

### 核心思路

插入排序的本质：**维护一个已排序部分，逐个将未排序节点插入到合适位置**。

链表插入排序的特殊之处：数组可以从后往前扫（因为可以随机访问），链表只能**从头往后**找插入位置。

```text
已排序部分          未排序部分
[4]              2 → 1 → 3
                  ↑
                 curr

取出 2，从头找插入位置：
dummy → 4        curr = 2
        ↑
      prev（4 > 2，停在这里）

插入：2 插到 4 前面
已排序部分          未排序部分
[2 → 4]           1 → 3
                   ↑
                  curr
```

---

### 优化：利用 lastSorted 快速判断

如果 `curr >= lastSorted`（已排序部分的末尾），说明 curr 已经在正确位置，不需要移动：

```text
已排序部分          未排序部分
[1 → 2 → 4]       3
                   ↑
                 curr

lastSorted = 4, curr = 3
4 > 3 → 需要找插入位置

但如果 curr = 5：
[1 → 2 → 4]       5 → 3
                   ↑
                 curr

lastSorted = 4, curr = 5
4 <= 5 → curr 已在正确位置，直接 lastSorted 后移！
```

---

### 代码实现

```java
public ListNode insertionSortList(ListNode head) {
    if (head == null) return head;

    // dummyHead 是虚拟头，简化插入到首位的逻辑
    ListNode dummyHead = new ListNode(0);
    dummyHead.next = head;

    // lastSorted: 已排序部分的最后一个节点
    // curr: 当前待处理的节点
    ListNode lastSorted = head, curr = head.next;

    while (curr != null) {
        if (lastSorted.val <= curr.val) {
            // curr 已经在正确位置（>= 已排序末尾），不用移动
            lastSorted = lastSorted.next;
        } else {
            // curr 比已排序末尾小，需要找插入位置
            ListNode prev = dummyHead;
            // 找到第一个 > curr.val 的节点前面
            while (prev.next.val <= curr.val) {
                prev = prev.next;
            }
            // 将 curr 从原位置摘除，插入到 prev 后面
            lastSorted.next = curr.next;  // 摘除 curr
            curr.next = prev.next;        // curr 指向 prev 的下一个
            prev.next = curr;             // prev 指向 curr
        }
        // 处理下一个节点（lastSorted 的下一个就是未处理的第一个）
        curr = lastSorted.next;
    }
    return dummyHead.next;
}
```

---

### 复杂度

| 类型 | 复杂度 | 说明 |
|------|--------|------|
| 时间 | O(n²) 最坏，O(n) 最好 | 最好情况（已排序）每轮只需 O(1) 判断 |
| 空间 | O(1) | 原地排序 |

---

### 易错点

1. **`lastSorted.next = curr.next` 必须先摘除 curr**：如果不先断开，插入操作会把 curr 后面的节点也带走
2. **`prev` 从 `dummyHead` 开始，不是从 `head` 开始**：curr 可能比所有已排序节点都小，需要插入到首位
3. **`prev.next.val <= curr.val` 用 `<=` 保证稳定性**：相等时不移动，保持原顺序
4. **`curr = lastSorted.next` 而不是 `curr = curr.next`**：curr 已经被移到前面去了，下一个待处理节点是 lastSorted 的下一个

---

### 记忆口诀

```
插入排序链表版：
虚拟头省特判，lastSorted 记末尾
curr 大就后移，curr 小就前找
摘除再插入，next 接 last 后
```
