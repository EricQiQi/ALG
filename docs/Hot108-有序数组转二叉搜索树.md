# 有序数组转二叉搜索树（Convert Sorted Array to BST）

## 题目描述

给你一个升序排列的整数数组 `nums`，将其转换为一棵**高度平衡**的二叉搜索树。

高度平衡：每个节点的左右子树高度差的绝对值不超过 1。

```
输入：[-10, -3, 0, 5, 9]

输出：
        0
       / \
    -10   5
      \    \
      -3    9
```

---

## 核心思路

**有序数组 → BST，关键：中间元素做根，左半建左树，右半建右树。**

为什么取中间？
- BST 要求左 < 根 < 右 → 有序数组天然满足
- 平衡要求左右节点数接近 → 中间元素做根，左右各分一半

```
[-10, -3, 0, 5, 9]
          ↑mid=0         → 根节点

[-10, -3]   [5, 9]
   ↑mid=-3    ↑mid=5     → 左右子树的根
```

---

## 代码实现

```java
public TreeNode sortedArrayToBST(int[] nums) {
    return build(nums, 0, nums.length - 1);
}

public TreeNode build(int[] nums, int left, int right) {
    if (left > right) return null;

    int mid = left + (right - left) / 2;   // 防溢出，取左中位数
    TreeNode root = new TreeNode(nums[mid]);

    root.left = build(nums, left, mid - 1);
    root.right = build(nums, mid + 1, right);
    return root;
}
```

### 复杂度

| 类型 | 复杂度 | 说明 |
|------|--------|------|
| 时间 | O(n) | 每个元素恰好访问一次，创建 n 个节点 |
| 空间 | O(log n) | 递归栈深度 = 树高，平衡树高 = log n |

## 取中间值的选择

`mid = left + (right - left) / 2` 取的是**左中位数**。也可以用**右中位数** `(left + right + 1) / 2`，两种都能通过，只是生成的树结构略有不同。

```
数组长度偶数时（如 4 个元素 [0,3]）：

左中位数 mid = ⌊(0+3)/2⌋ = 1    右中位数 mid = ⌈(0+3)/2⌉ = 2
     0  1  2  3                      0  1  2  3
        ↑mid                           ↑mid
     左右各 1~2 个元素，仍然平衡     左右各 1~2 个元素，仍然平衡
```

> 本题不要求唯一答案，只要满足 BST + 平衡即可。

---

## 易错点

1. **递归终止条件写反**：应该是 `left > right` 返回 null，不是 `left >= right`（`left == right` 时还有最后一个元素要处理）
2. **mid 溢出问题**：`(left + right)` 可能超过 `Integer.MAX_VALUE`，应写成 `left + (right - left) / 2`
3. **忘记数组有序的前提**：能取中间元素做根，正是因为数组已经升序排列
