# 二叉树展开为链表（Flatten Binary Tree to Linked List）

## 题目描述

给定一个二叉树，原地将它展开为一个单链表（沿 `right` 指针），顺序与前序遍历一致。

```
         1                  1
        / \                  \
       2   5        →        2
      / \   \                 \
     3   4   6                3
                               \
                                4
                                 \
                                  5
                                   \
                                    6
```

---

## 核心思路

**展开的本质 = 前序遍历的顺序，把所有节点的 left 置空，right 指向下一个节点。**

两种方法的区别：
- **方法1**：先收集前序序列，再依次连接 → 直观，但用了 O(n) 额外空间
- **方法2**：边遍历边调整指针，不用额外空间 → 关键是"找左子树最右节点"

---

## 方法1：前序遍历收集

前序遍历把所有节点存入列表，然后顺序串联。

```
前序结果：[1, 2, 3, 4, 5, 6]
依次连接：1→2→3→4→5→6，每个节点 left = null
```

| 类型 | 复杂度 | 说明 |
|------|--------|------|
| 时间 | O(n) | 遍历一次 + 连接一次 |
| 空间 | O(n) | 列表存储所有节点 |

---

## 方法2：迭代找前驱（O(1) 空间）

**核心操作**：对每个有左子树的节点 `curr`：
1. 找到左子树的最右节点 `preNode`
2. 把 `curr.right` 接到 `preNode.right`
3. 把 `curr.left` 移到 `curr.right`，`curr.left = null`
4. `curr = curr.right` 继续

```
curr=1，左子树最右节点=4
  → 把 5 接到 4 右边，左子树移到右边
         1
          \
           2
          / \
         3   4
              \
               5
                \
                 6

curr=2，左子树最右节点=3
  → 把 4 接到 3 右边，左子树移到右边
  1 → 2 → 3 → 4 → 5 → 6  ✓
```

| 类型 | 复杂度 | 说明 |
|------|--------|------|
| 时间 | O(n) | 每个节点最多被访问两次 |
| 空间 | O(1) | 原地修改，无额外空间 |

---

## 两种方法对比

```
方法1（前序收集）：
  思路简单，先存后连，适合理解题意
  缺点：需要 O(n) 空间

方法2（找前驱）：
  原地操作，O(1) 空间，面试加分项
  关键：左子树最右节点 = 前驱节点（前序遍历中左子树最后一个访问的节点）
```

---

## 易错点

1. **`curr.left = null` 不能忘**：展开后所有节点的 left 必须为空
2. **先接右子树再移左子树**：`preNode.right = curr.right` 要在 `curr.right = next` 之前，否则右子树丢了
3. **`curr = curr.right` 不是 `curr.left`**：左子树已经移到右边了，下一步沿右走

---

## 记忆口诀

```
前序收集最简单，存完再连；
原地操作找前驱，左树最右接右边。
```
