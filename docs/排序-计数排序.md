# 排序算法

## 计数排序 (Counting Sort)

### 核心思想

> **不比较大小，只数个数：统计每个值出现几次，再按值从小到大把个数"倒"回数组**

像清点一堆编号 0~k 的小球：不用两两比大小，只要准备 k+1 个格子，每看到一个编号就在对应格子里画一道"正"，最后从 0 号格子开始，格子里有几道就把这个数写进结果几次。

---

### 图像记忆法：格子计数

```
原始: [4, 2, 2, 8, 3, 3, 1]        max = 8，开 9 个格子（下标 0..8）

第 1 步 数个数（值当格子号，出现一次 +1）：
下标  0  1  2  3  4  5  6  7  8
计数  0  1  2  2  1  0  0  0  1
         ↑  ↑  ↑     ↑              ↑
         1  2  3     4              8

第 2 步 从下标 0 扫到 8，格子里是几就写几个"下标本身"：
结果  [1, 2, 2, 3, 3, 4, 8]
```

**扫描顺序天然从小到大，所以根本不用比较就已经有序了。**

---

### 一句话记住

```
先找最大值开格子，值当号数一遍几，从小号到大号按次数倒回去
```

---

### 代码结构速记

```
countingSort(arr)
├── if (arr 长度 < 2) return          ← 空/单元素直接有序
├── max = 扫描求最大值
├── count = new int[max + 1]          ← 格子数 = max+1（下标要覆盖到 max）
├── for num in arr: count[num]++      ← 数每个值出现几次
└── index = 0
    └── for i in 0..count.length      ← 从小到大扫格子
        └── while (count[i] > 0): arr[index++] = i; count[i]--
```

---

### 关键易错点

**1. 只能排"非负整数"，且有上限**

代码用 `count[num]` 直接把值当下标，一旦有负数就数组越界；值域太大也会撑爆 count 数组。要排带负数的数据，得先整体平移让最小值变 0。

**2. count 长度是 `max + 1` 而不是 `max`**

最大值 `max` 自己也要占一个格子（下标就是 max），长度少 1 会在 `count[max]++` 时越界。

**3. 时间和空间都跟 max 挂钩，不是纯 O(n)**

数一遍 O(n)、扫格子 O(max)，合起来 **O(n + max)**；额外空间 O(max)。当数据范围 max 远大于元素个数 n（比如 10 个数却最大到 100 万）时，格子大量空转，反而不如快排。

**4. 这是"非比较排序"，靠的是值域有限**

它绕开了"比较排序 O(n log n) 下界"，代价是必须能用一个不太大的整数当数组下标。所以它适合年龄、成绩、颜色编号这类范围有限的整数。

---

### 复杂度

| | 平均 | 最坏 | 最好 |
|---|---|---|---|
| 时间 | O(n + max) | O(n + max) | O(n + max) |
| 空间 | O(max) | O(max) | O(max) |

> 时间不受初始顺序影响，是**稳定的线性排序**，但前提是值域 max 要和 n 同量级；否则退化成"看着 O(n) 实则被 max 拖累"。

> **记忆口诀**：计数不比大小，开 max+1 个格子数个数，小号到大号按次数倒回去
