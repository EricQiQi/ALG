# 二叉树中的最大路径和

## 题目描述

给定二叉树的根节点 `root`，返回其**最大路径和**。

路径被定义为从任意节点出发，沿父子连接到达任意节点的序列，同一节点最多出现一次。

```
       -10
       /  \
      9   20
         /  \
        15   7

最大路径：15 → 20 → 7 = 42（不经过根节点 -10）
```

---

## 后序遍历 + 最大贡献值

### 思路

每个节点做一次"拐点"（路径的最高点），计算经过它的路径和，取全局最大值。

**核心概念：最大贡献值** — 节点能向上提供的最大单侧路径和。

```
以节点 20 为拐点：
  左贡献 = max(15的贡献, 0) = 15
  右贡献 = max(7的贡献, 0) = 7
  经过20的路径 = 15 + 20 + 7 = 42 ← 更新 maxSum
  20的贡献值 = 20 + max(15, 7) = 35 ← 往上传
```

**两个值要分清**：
- **路径和**（更新答案）：`左贡献 + 节点值 + 右贡献`，路径可以左右都走
- **贡献值**（往上传）：`节点值 + max(左贡献, 右贡献)`，只能选一侧往上走

```
路径和 = 左 + 根 + 右   ← 当拐点，更新 maxSum
贡献值 = 根 + max(左, 右) ← 只能选一边，往上传
```

### 代码

```java
private int maxSum = Integer.MIN_VALUE;

public int maxPathSum(TreeNode root) {
    maxGain(root);
    return maxSum;
}

public int maxGain(TreeNode node) {
    if (node == null) return 0;

    int leftPath = Math.max(maxGain(node.left), 0);   // 负贡献不如不选
    int rightPath = Math.max(maxGain(node.right), 0);

    maxSum = Math.max(maxSum, node.val + leftPath + rightPath);  // 当拐点

    return node.val + Math.max(leftPath, rightPath);             // 往上传
}
```

### 复杂度

| 类型 | 复杂度 | 说明 |
|------|--------|------|
| 时间 | O(n) | 每个节点访问一次 |
| 空间 | O(h) | 递归栈深度 = 树高 |

## 核心逻辑图解

```
节点 9（叶子）：
  左=0, 右=0
  路径和 = 9         → maxSum = 9
  贡献值 = 9

节点 15（叶子）：
  路径和 = 15        → maxSum = 15
  贡献值 = 15

节点 7（叶子）：
  路径和 = 7         → maxSum 仍 15
  贡献值 = 7

节点 20（拐点）：
  左=15, 右=7
  路径和 = 15+20+7 = 42  → maxSum = 42 ✓
  贡献值 = 20+15 = 35

节点 -10（根）：
  左=9, 右=35
  路径和 = 9+(-10)+35 = 34  → maxSum 仍 42
  贡献值 = -10+35 = 25
```

---

## 易错点

1. **maxSum 初始化为 `Integer.MIN_VALUE`**：不能初始化为 0，因为全负数树的最大路径是某个负数节点本身
2. **负贡献要丢弃**：`Math.max(maxGain, 0)`，子树贡献为负时不如不选（路径可以不包括该子树）
3. **路径和 vs 贡献值不要搞混**：路径和可以走两侧（更新答案），贡献值只能走一侧（往上传）

