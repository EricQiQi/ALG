# 算法笔记：最长有效括号（力扣 32 题）

## 题目描述
给你一个只包含 `'('` 和 `')'` 的字符串 `s`，找出最长**有效（格式正确且连续）括号子串**的长度。

```
输入：s = "(()"
输出：2
解释：最长有效括号子串是 "()"。

输入：s = ")()())"
输出：4
解释：最长有效括号子串是 "()()"。

输入：s = ""
输出：0
```

> 📌 关键理解：有效子串必须**连续**，所以不仅要判断「配对合法」，还要知道每段合法区间**从哪里开始**。栈里存**下标**而非字符，栈底常驻一个「隔板」（最后一个未匹配的右括号位置），配对成功时用 `i - 栈顶` 直接量出当前连续有效段长度。

---

## 解法：栈 + 哨兵（存下标）

### 1. 核心思想
维护一个存**下标**的栈，栈底恒为「最后一个未匹配的右括号」（哨兵），其上为等待配对的 `'('` 下标。
* **初始化**：压入哨兵 `-1`，相当于在串首之前放一个虚拟隔板，使第一个有效段长度能算成 `i - (-1)`。
* **遇 `'('`**：下标入栈，等待配对。
* **遇 `')'`**：弹栈配对，随后分两种情况：
  * **栈非空**：配对成功，`i - stack.peek()` 就是当前连续有效长度（栈顶是这段起点的前一个位置），打擂台更新答案。
  * **栈为空**：说明弹掉的是哨兵，当前 `')'` 是**多余右括号**——任何有效子串都不能跨过它，于是把 `i` 压栈成为**新隔板**，后续长度从它之后起算。
* **返回**：`maxLen`。

> 为什么栈顶减一减就是长度？哨兵（或上一段结尾的未配对右括号）把字符串切成若干「互不相连的合法区域」，每个区域内配对成功时，栈顶恰好是「该区域起点的前一格」，相减即得连续长度——多段相邻合法区间（如 `"()()"`）也因此能被**自动拼接**计入。

### 2. 代码实现 (Java)

```java
class Solution {
    public int longestValidParentheses(String s) {
        Deque<Integer> stack = new ArrayDeque<>();
        stack.push(-1);  // 哨兵：虚拟的「最后一个未匹配右括号」，让首个有效段长度 = i - (-1)

        int maxLen = 0;
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (c == '(') {
                stack.push(i);  // 未匹配的 '(' 下标入栈等待配对
            } else {
                stack.pop();    // 配对：弹出一个 '('（或哨兵，表示该右括号多余）

                if (stack.isEmpty()) {
                    stack.push(i);  // 多余右括号：它成为新隔板，有效段不能跨过它
                } else {
                    // 栈顶是配对成功的「起点前一个位置」，i - 栈顶即连续有效长度
                    maxLen = Math.max(maxLen, i - stack.peek());
                }
            }
        }
        return maxLen;
    }
}
```

### 3. 复杂度分析
* **时间复杂度**：$O(n)$。每个字符最多入栈、出栈各一次。
* **空间复杂度**：$O(n)$。最坏情况全是 `'('`，栈深度为 $n$。

### 4. 执行过程图解
以 `s = "()(()"` 为例：

```text
i   字符   操作              栈(底→顶)      maxLen
-   ——    哨兵入栈          [-1]            0
0   (     入栈              [-1, 0]         0
1   )     弹出 0，栈非空     [-1]            1-(-1)=2
2   (     入栈              [-1, 2]         2
3   (     入栈              [-1, 2, 3]      2
4   )     弹出 3，栈非空     [-1, 2]         max(2, 4-2)=2
返回 maxLen = 2（最长有效子串 "()"）
```

再看哨兵「换新」的情形，以 `s = "())()"` 为例：

```text
i   字符   操作                    栈(底→顶)   maxLen
-   ——    哨兵入栈                [-1]         0
0   (     入栈                    [-1, 0]      0
1   )     弹出 0，栈非空           [-1]         2
2   )     弹出哨兵 -1，栈空 → 换新  [2]          2   ← 多余右括号成新隔板
3   (     入栈                    [2, 3]       2
4   )     弹出 3，栈非空           [2]          max(2, 4-2)=2
返回 maxLen = 2
```

> 第 2 步若忘记换新哨兵，后续 `i - 栈顶` 就没有基准可减，会漏算或错算长度。 **「弹空必补哨兵」** 是本解法最关键的一步。

---

## 💡 总结
最长有效括号是 **「栈存下标 + 哨兵隔板」** 的模板：下标入栈才能量长度，哨兵 `-1` 提供初始基准；每弹出一对就用 `i - 栈顶` 结算当前连续有效段，弹空则说明遇到多余右括号，立刻把它压栈换新隔板，保证有效段不跨界。

| 特性 | 说明 |
| :--- | :--- |
| **栈内元素** | 下标（哨兵 = 最后一个未匹配右括号，其余 = 未配对 `'('`） |
| **结算时机** | 遇 `')'` 弹栈后栈非空：`i - stack.peek()` 打擂台 |
| **哨兵作用** | 提供长度起算基准；弹空后换当前 `i` 为新哨兵 |
| **时间/空间** | $O(n)$ / $O(n)$ |

> ⚠️ 易错点：① **初始哨兵 `-1` 必压**，否则第一个有效段长度无从算起；② **弹空后必须压入当前 `i`** 换新哨兵，否则后续结算丢失基准；③ 栈存的是**下标不是字符**，长度靠下标差算出；④ `')'` 的 pop 是**先弹再判空**，顺序反了逻辑全错。
