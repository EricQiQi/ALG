# 算法笔记：最长有效括号（力扣 32 题）

## 题目描述
给你一个只包含 `'('` 和 `')'` 的字符串 `s`，找出最长**有效（格式正确且连续）括号子串**的长度。

```
输入：s = "(()"
输出：2
解释：最长有效括号子串是 "()"。

输入：s = ")()())"
输出：4
解释：最长有效括号子串是 "()()"。

输入：s = ""
输出：0
```

> 📌 关键理解：有效子串必须**连续**，所以不仅要判断「配对合法」，还要知道每段合法区间**从哪里开始**。三种解法都围绕这一点：栈靠**存下标**量长度、DP 靠**以 i 结尾**接前缀、双向扫描靠**计数器归零**划隔板。

---

## 解法一：栈 + 哨兵（存下标）

### 1. 核心思想
维护一个存**下标**的栈，栈底恒为「最后一个未匹配的右括号」（哨兵），其上为等待配对的 `'('` 下标。
* **初始化**：压入哨兵 `-1`，相当于在串首之前放一个虚拟隔板，使第一个有效段长度能算成 `i - (-1)`。
* **遇 `'('`**：下标入栈，等待配对。
* **遇 `')'`**：弹栈配对，随后分两种情况：
  * **栈非空**：配对成功，`i - stack.peek()` 就是当前连续有效长度（栈顶是这段起点的前一个位置），打擂台更新答案。
  * **栈为空**：说明弹掉的是哨兵，当前 `')'` 是**多余右括号**——任何有效子串都不能跨过它，于是把 `i` 压栈成为**新隔板**，后续长度从它之后起算。
* **返回**：`maxLen`。

> 为什么栈顶相减就是长度？哨兵（或上一段结尾的未配对右括号）把字符串切成若干「互不相连的合法区域」，每个区域内配对成功时，栈顶恰好是「该区域起点的前一格」，相减即得连续长度——多段相邻合法区间（如 `"()()"`）也因此能被**自动拼接**计入。

### 2. 代码实现 (Java)

```java
class Solution {
    public int longestValidParentheses(String s) {
        Deque<Integer> stack = new ArrayDeque<>();
        stack.push(-1);  // 哨兵：虚拟的「最后一个未匹配右括号」，让首个有效段长度 = i - (-1)

        int maxLen = 0;
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (c == '(') {
                stack.push(i);  // 未匹配的 '(' 下标入栈等待配对
            } else {
                stack.pop();    // 配对：弹出一个 '('（或哨兵，表示该右括号多余）

                if (stack.isEmpty()) {
                    stack.push(i);  // 多余右括号：它成为新隔板，有效段不能跨过它
                } else {
                    // 栈顶是配对成功的「起点前一个位置」，i - 栈顶即连续有效长度
                    maxLen = Math.max(maxLen, i - stack.peek());
                }
            }
        }
        return maxLen;
    }
}
```

### 3. 复杂度分析
* **时间复杂度**：$O(n)$。每个字符最多入栈、出栈各一次。
* **空间复杂度**：$O(n)$。最坏情况全是 `'('`，栈深度为 $n$。

### 4. 执行过程图解
以 `s = "()(()"` 为例：

```text
i   字符   操作              栈(底→顶)      maxLen
-   ——    哨兵入栈          [-1]            0
0   (     入栈              [-1, 0]         0
1   )     弹出 0，栈非空     [-1]            1-(-1)=2
2   (     入栈              [-1, 2]         2
3   (     入栈              [-1, 2, 3]      2
4   )     弹出 3，栈非空     [-1, 2]         max(2, 4-2)=2
返回 maxLen = 2（最长有效子串 "()"）
```

再看哨兵「换新」的情形，以 `s = "())()"` 为例：

```text
i   字符   操作                    栈(底→顶)   maxLen
-   ——    哨兵入栈                [-1]         0
0   (     入栈                    [-1, 0]      0
1   )     弹出 0，栈非空           [-1]         2
2   )     弹出哨兵 -1，栈空 → 换新  [2]          2   ← 多余右括号成新隔板
3   (     入栈                    [2, 3]       2
4   )     弹出 3，栈非空           [2]          max(2, 4-2)=2
返回 maxLen = 2
```

> 第 2 步若忘记换新哨兵，后续 `i - 栈顶` 就没有基准可减，会漏算或错算长度。**「弹空必补哨兵」**是本解法最关键的一步。

## 解法二：动态规划（以 i 结尾）

### 1. 核心思想
定义状态：`dp[i]` 表示**以 `s[i]` 结尾**的最长有效括号子串长度。
* **只处理 `s[i] == ')'`**：以 `'('` 结尾的子串必定无效，故那些位置的 `dp[i]` 恒为 0（数组默认值）。
* **情况 1：`"...()"`**——`s[i-1]` 是 `'('`，直接与它配对，再接上更早的有效段：
  $$dp[i] = dp[i-2] + 2$$
* **情况 2：`"...))"`**——`s[i-1]` 也是 `')'`，跳过以 `i-1` 结尾的整段有效区（长度 `dp[i-1]`），令 `j = i - dp[i-1] - 1`：
  * 若 `j < 0` 或 `s[j] == ')'`：当前 `')'` 配不上，`dp[i] = 0`。
  * 若 `s[j] == '('`：这一对把中间的有效段整个包住，还能再往前拼接：
    $$dp[i] = dp[i-1] + 2 + dp[j-1]$$
* **返回**：`max(dp)`——打擂台跟踪全局最大。

> `dp[j-1]` 那一项是「情况 2」最易漏的地方：配对成功后，`j` **之前**可能还有一段紧邻的有效区（如 `"()(())"` 中 `j-1` 指向的 `"()"`），要一并拼接进来。

### 2. 代码实现 (Java)

```java
class Solution {
    public int longestValidParentheses(String s) {
        int n = s.length();
        int[] dp = new int[n];  // 默认全 0，以 '(' 结尾的位置自然为 0
        int maxLen = 0;

        for (int i = 1; i < n; i++) {          // i=0 无法成对，dp[0] 恒为 0
            if (s.charAt(i) == ')') {          // 只有右括号可能作为有效段结尾
                if (s.charAt(i - 1) == '(') {
                    // 情况1：...()，接上 i-2 结尾的有效段
                    dp[i] = (i >= 2 ? dp[i - 2] : 0) + 2;
                } else if (i - dp[i - 1] > 0 && s.charAt(i - dp[i - 1] - 1) == '(') {
                    // 情况2：...))，先确保 j = i-dp[i-1]-1 不越界，再看 j 处是否为配对的左括号
                    // dp[i] = 内层已有效长度 + 新配上的 2 + j 之前还能拼接的有效长度
                    dp[i] = dp[i - 1] + (i - dp[i - 1] >= 2 ? dp[i - dp[i - 1] - 2] : 0) + 2;
                }
                maxLen = Math.max(maxLen, dp[i]);
            }
        }
        return maxLen;
    }
}
```

### 3. 复杂度分析
* **时间复杂度**：$O(n)$。单趟遍历，每步 $O(1)$。
* **空间复杂度**：$O(n)$。`dp` 数组。

### 4. 递推过程图解
以 `s = "()(())"`（含两种情况）为例：

```text
i   s[i]   s[i-1]   情况   计算                                 dp[i]   maxLen
0    (      ——      ——     以 '(' 结尾，恒 0                      0       0
1    )      (       1      dp[-1→0] + 2 = 2                      2       2
2    (      )       ——     以 '(' 结尾，恒 0                      0       2
3    (      (       ——     以 '(' 结尾，恒 0                      0       2
4    )      (       1      dp[2] + 2 = 0 + 2                     2       2
5    )      )       2      j = 5 - dp[4] - 1 = 2，s[2]='('        6       6
                           dp[5] = dp[4] + dp[j-1] + 2 = 2+2+2
返回 maxLen = 6
```

> 第 5 步把「内层 `()` 的长度 2」+「新配对的一对 2」+「外层之前紧邻的 `()` 的长度 2」拼成 6，正好是整个 `"()(())"`。三项缺一不可。

## 解法三：双向扫描（$O(1)$ 空间）

### 1. 核心思想
不用栈也不用 dp，只维护 `left` / `right` 两个计数器（左、右括号出现次数）：
* `left == right`：说明这一段左右配平，结算长度 `2 * left`，打擂台。
* 括号失衡：把计数**归零**（多余的括号当隔板），从下一个位置重新起算。
* **两个方向缺一不可**，因为单向扫描会漏掉一种不对称情况：
  * **左 → 右**：`right > left`（多余右括号）时归零。
  * **右 → 左**：`left > right`（多余左括号）时归零。

> 为什么必须双向？考虑 `"(()"`：左→右扫时 `left` 始终 ≥ `right` 且从未相等，得 0；右→左扫时 `right` 先为 1，遇 `'('` 后 `left=right=1` 才结算出 2。反过来 `")()())"` 这类「多余右括号在前」的串则只有左→右能正确处理。两趟各取所长，合并打擂台即为答案。

### 2. 代码实现 (Java)

```java
class Solution {
    public int longestValidParentheses(String s) {
        int n = s.length();
        int maxLen = 0;

        // 第一趟：从左到右扫
        int left = 0, right = 0;
        for (int i = 0; i < n; i++) {
            if (s.charAt(i) == '(') left++;
            else right++;

            if (left == right) {
                maxLen = Math.max(maxLen, 2 * left);   // 左右括手数相等：这一段完整配对
            } else if (right > left) {
                left = right = 0;                      // 多余右括号当隔板，计数归零
            }
        }

        left = right = 0;  // 第二趟前重置计数器

        // 第二趟：从右到左扫（兼容左括号一直多于右括号的情形）
        for (int i = n - 1; i >= 0; i--) {
            if (s.charAt(i) == '(') left++;
            else right++;

            if (left == right) {
                maxLen = Math.max(maxLen, 2 * left);
            } else if (left > right) {
                left = right = 0;                      // 多余左括号当隔板，计数归零
            }
        }
        return maxLen;
    }
}
```

### 3. 复杂度分析
* **时间复杂度**：$O(n)$。两趟线性扫描。
* **空间复杂度**：$O(1)$。只用常数个计数器，三种解法中最优。

### 4. 执行过程图解
以 `s = "()(()"` 为例：

```text
【左 → 右】
i   字符   left  right   动作                    maxLen
0    (      1     0      left > right，不结算      0
1    )      1     1      相等 → 2*1               2
2    (      2     1      不结算                   2
3    (      3     1      不结算                   2
4    )      3     2      不结算                   2

【右 → 左】（计数器已重置）
i   字符   left  right   动作                    maxLen
4    )      0     1      不结算                   2
3    (      1     1      相等 → 2*1               2
2    (      2     1      left > right → 归零      2
1    )      0     1      不结算                   2
0    (      1     1      相等 → 2*1               2
返回 maxLen = 2
```

> 右→左那趟在 `i=2` 处**及时归零**是关键：若不归零，走到 `i=1` 时 `left=2, right=2` 会误结算出 4（把中间断开的 `"("` 也算进去了）。归零条件与扫描方向相反——**左扫判 `right > left`，右扫判 `left > right`**，别写串。

---

## 💡 总结
最长有效括号的三种解法本质都在解决同一件事：**如何度量「连续」的有效段**。栈用哨兵当隔板量下标差；DP 用「以 i 结尾」的状态把前缀长度接力拼接；双向扫描用计数器配平结算、失衡归零划段。

| 特性 | 解法一：栈 + 哨兵 | 解法二：动态规划 | 解法三：双向扫描 |
| :--- | :--- | :--- | :--- |
| **思维出发点** | 下标入栈，`i - 栈顶` 量长度 | `dp[i]` = 以 i 结尾的有效长度 | 计数器配平即结算，失衡即归零 |
| **代码表现** | 哨兵 `-1` 压底，弹空换新隔板 | 情况1 `dp[i-2]+2`、情况2 `dp[i-1]+2+dp[j-1]` | 两趟扫描，判空方向相反 |
| **时间** | $O(n)$ | $O(n)$ | $O(n)$ |
| **空间** | $O(n)$ | $O(n)$ | $O(1)$（最优） |
| **推荐场景** | 直观易讲、面试首选 | 练「以 i 结尾」型 DP 思维 | 要求空间最优时 |

> ⚠️ 易错点：
> **解法一** ① 初始哨兵 `-1` 必压；② **弹空后必须压入当前 `i`** 换新哨兵；③ 栈存**下标**不是字符；④ 先 pop 再判空，顺序不能反。
> **解法二** ⑤ `dp[i]` 只在 `s[i] == ')'` 时计算，`'('` 结尾恒为 0；⑥ 情况 2 别忘了 `+ dp[j-1]`（外层前紧邻的有效段）；⑦ 下标 `j = i - dp[i-1] - 1` 要先判 `> 0` 防越界；⑧ 循环从 `i = 1` 起。
> **解法三** ⑨ 两趟扫描**都要做**，缺一不可；⑩ 第二趟前**重置计数器**；⑪ 归零方向相反：左扫判 `right > left`、右扫判 `left > right`。
