# 算法笔记：杨辉三角（力扣 118 题）

## 题目描述
给定一个非负整数 `numRows` ，生成「杨辉三角」的前 `numRows` 行。

在杨辉三角中，每个数是它 **左上方和右上方** 两数之和，每行首尾都是 `1`。

```
输入: numRows = 5
输出:
[
     [1],
    [1,1],
   [1,2,1],
  [1,3,3,1],
 [1,4,6,4,1]
]
```

> 📌 关键理解：把第 `i` 行第 `j` 个数记为 `dp[i][j]`（下标均从 0 开始），它由**正上方偏左** `dp[i-1][j-1]` 与**正上方** `dp[i-1][j]` 相加得到；每行首尾（`j == 0` 或 `j == i`）恒为 `1`。这正是二维的递推（DP）。

---

## 解法：动态规划（逐行递推）

### 1. 核心思想
杨辉三角的每个数只依赖**上一行**的两个数，是典型的二维递推。
* **状态**：`dp[i][j]` 表示第 `i` 行第 `j` 个数（`0 <= j <= i`）。
* **状态转移**：
  $$dp[i][j] = \begin{cases} 1, & j = 0 \text{ 或 } j = i \\ dp[i-1][j-1] + dp[i-1][j], & \text{其他} \end{cases}$$
* **实现技巧**：不必真的开二维数组，直接用一个 `List<List<Integer>>` 装结果，边生成边把**上一行**（`res.get(i-1)`）当作递推来源即可。

> 生成第 `i` 行时，它恰好有 `i + 1` 个数（`j` 从 `0` 到 `i`）；内层只处理 `j == 0 || j == i` 的“边界 1”，其余交给“肩上加和”。

### 2. 代码实现 (Java)

```java
class Solution {
    public List<List<Integer>> generate(int numRows) {
        List<List<Integer>> res = new ArrayList<>();

        for (int i = 0; i < numRows; i++) {   // i：行号，从 0 开始
            List<Integer> level = new ArrayList<>();
            for (int j = 0; j <= i; j++) {    // j：行内下标，第 i 行共 i+1 个数
                if (j == 0 || j == i) {
                    level.add(1);                                          // 首尾恒为 1
                } else {
                    // 肩上加和：上一行的 j-1 与 j
                    level.add(res.get(i - 1).get(j - 1) + res.get(i - 1).get(j));
                }
            }
            res.add(level);
        }
        return res;
    }
}
```

### 3. 复杂度分析
* **时间复杂度**：$O(n^2)$。第 `i` 行生成 `i+1` 个数，总计 $1+2+\dots+n = \frac{n(n+1)}{2}$ 次赋值。
* **空间复杂度**：$O(1)$（不计返回值本身）。只使用了常数个辅助变量；结果集本身占 $O(n^2)$。

### 4. 递推过程图解
以生成第 4 行（`i = 4`，即 `[1,4,6,4,1]`）为例，此时上一行（`res.get(3)`）为 `[1,3,3,1]`：

```text
j   是否边界   计算                             level
0    j==0      边界 → 1                          [1]
1    否        上行[0] + 上行[1] = 1+3 = 4       [1,4]
2    否        上行[1] + 上行[2] = 3+3 = 6       [1,4,6]
3    否        上行[2] + 上行[3] = 3+1 = 4       [1,4,6,4]
4    j==i      边界 → 1                          [1,4,6,4,1]
```

> 直观记忆：除首尾外，每个数 = 它“左肩 + 右肩”两个数之和。上一行就是递推的“上一状态”。

---

## 💡 总结
杨辉三角是**二维 DP 的最简形态**：状态 `dp[i][j]` 只依赖上一行相邻两项，边界（首尾）单独置 1。实现上用结果集 `res.get(i-1)` 直接充当“上一行”，免去了显式开二维数组。

| 特性 | 说明 |
| :--- | :--- |
| **思维出发点** | 每个数 = 左肩 + 右肩；首尾恒为 1。 |
| **代码表现** | 行号 `i`、行内下标 `j` 都从 0 起；`j==0||j==i` 填 1，否则 `res.get(i-1).get(j-1)+res.get(i-1).get(j)`。 |
| **时间 / 空间** | $O(n^2)$ / $O(1)$（不计返回值）。 |

> ⚠️ 易错点：**行号与行内下标务必统一从 0 开始**，且“上一行”就是 `res.get(i-1)`。若像旧实现那样引入“全局展平下标” `index = n(n+1)/2` 再反推行内位置，极易把全局下标误当行内下标去取单行 `List`，导致越界（旧版 `generate` 正是因此崩溃）。
