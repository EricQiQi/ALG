# 二叉树的层序遍历（Binary Tree Level Order Traversal）

## 题目描述

给你二叉树的根节点 `root`，返回其节点值的层序遍历结果（逐层从左到右）。

```
       3
      / \
     9   20
        /  \
       15   7

输出：[[3], [9, 20], [15, 7]]
```

---

## 核心思路

**用队列做 BFS，每轮用 `size` 锁定当前层的节点数，逐个弹出并收集。**

```
队列：[3]
第1轮：size=1，弹出3，收集[3]，入队 9, 20
队列：[9, 20]

第2轮：size=2，弹出9收集9入队null跳过，弹出20收集20入队15,7
收集[9, 20]
队列：[15, 7]

第3轮：size=2，弹出15收集，弹出7收集
收集[15, 7]
```

> **关键**：`int size = queue.size()` 必须在 for 循环之前锁定，因为循环中 queue 会变化。

---

## 代码实现

### 方法1：Queue + LinkedList

```java
public List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> res = new ArrayList<>();
    if (root == null) return res;

    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);
    while (!queue.isEmpty()) {
        List<Integer> level = new ArrayList<>();
        int size = queue.size();          // 锁定当前层节点数
        for (int i = 0; i < size; i++) {
            TreeNode node = queue.poll();
            level.add(node.val);
            if (node.left != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }
        res.add(level);
    }
    return res;
}
```

### 方法2：Deque + ArrayDeque

只换容器和三个方法名，`size` 锁层的骨架完全一致：

```java
public List<List<Integer>> levelOrder_2(TreeNode root) {
    List<List<Integer>> res = new ArrayList<>();
    if (root == null) return res;

    Deque<TreeNode> queue = new ArrayDeque<>();
    queue.offerLast(root);                       // 尾部入队
    while (!queue.isEmpty()) {
        List<Integer> level = new ArrayList<>();
        int size = queue.size();                 // 锁定当前层节点数
        for (int i = 0; i < size; i++) {
            TreeNode node = queue.pollFirst();    // 头部出队
            level.add(node.val);
            // ArrayDeque 不允许存 null，入队前必须先判空
            if (node.left != null) queue.offerLast(node.left);
            if (node.right != null) queue.offerLast(node.right);
        }
        res.add(level);
    }
    return res;
}
```

**Queue → Deque 方法对照**

| 语义 | Queue（LinkedList） | Deque（ArrayDeque） |
|------|--------------------|---------------------|
| 入队（尾部） | `offer(e)` | `offerLast(e)` |
| 出队（头部） | `poll()` | `pollFirst()` |
| 查看队头 | `peek()` | `peekFirst()` |
| 能否存 null | 允许 | **不允许，`offer(null)` 抛 NPE** |

**为什么更推荐 ArrayDeque**

| 对比项 | LinkedList | ArrayDeque |
|--------|-----------|------------|
| 底层结构 | 双向链表，每个元素一个节点对象 | 循环数组，无节点开销 |
| 性能 | 频繁创建节点 + GC 压力 | 更快 |
| null 元素 | 允许 | 不允许 |
| 官方态度 | — | ✅ 推荐用它替代 `Queue`/`Stack` |

> 关联：[Hot104 二叉树的最大深度](Hot104-二叉树的最大深度.md) 的方法2 用的是同一套 Deque BFS 骨架，只是把「收集每层的值」换成「层数 +1」。

### 复杂度（两种方法相同）

| 类型 | 复杂度 | 说明 |
|------|--------|------|
| 时间 | O(n) | 每个节点入队出队各一次 |
| 空间 | O(n) | 队列最多存一层的节点数，最坏 O(n) |

## 图解

```
       3
      / \
     9   20
        /  \
       15   7

队列状态           size    level
─────────────────────────────────
[3]                1       [3]
[9, 20]            2       [9, 20]
[15, 7]            2       [15, 7]
[]                 结束

res = [[3], [9, 20], [15, 7]]
```

---

## 易错点

1. **size 必须提前锁定**：`int size = queue.size()` 在 for 之前，不能在 for 条件里写 `i < queue.size()`（因为循环中 queue 在不断变化）
2. **null 不入队**：只有非空子节点才 offer，否则队列会无限膨胀
3. **和 DFS 的区别**：层序用队列（BFS），前/中/后序用栈（DFS）— 两种不同的遍历策略
4. **ArrayDeque 不能存 null**：换成 Deque 实现后，子节点入队前的判空从「优化」变成「必需」，漏判会直接抛 NullPointerException（LinkedList 版漏判只是队列里多几个 null）
