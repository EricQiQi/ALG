# 排序算法

## 快速排序 (Quick Sort)

### 核心思想

> **选基准，小左大右，递归两边**

---

### 图像记忆法：特工"找内鬼"

如果你容易记混两个指针怎么移动，可以脑补这个画面：

**基准数（Pivot）** — 是长官。长官挑中了排在最左边的那个人出来当标杆。

**右指针 j** — 是左派特工。它的任务是"从最右边开始往左找，揪出所有比长官小的内鬼"。

**左指针 i** — 是右派特工。它的任务是"从最左边开始往右找，揪出所有比长官大的内鬼"。

**交替前进** — 左派特工先走，找到了大的，停下；右派特工再走，找到了小的，停下。两人互相交换手里揪出来的内鬼（swap）。

**合体** — 当两个特工走到同一个位置相遇了，说明全员排查完毕。长官（基准数）直接走到这个相遇的位置坐下。此时，左边全是小兵（≤ 基准），右边全是大将（≥ 基准）。

---

### 一句话记住 Partition

```
基准站左边，j 先走找小的，i 再走找大的，相遇就停，基准归位
```

### 递归分解全景图

```
原始: [3, 6, 8, 10, 1, 2, 1]
                    ↓ partition
         [1, 1] | 3 | [10, 6, 2, 8]
           ↓              ↓ partition
         [1] 1       [2] 6 [8, 10]
        排好了!       ↓         ↓
                   排好了!   [8] 10
                              ↓
                           排好了!

最终: [1, 1, 2, 3, 6, 8, 10]
```

### 代码结构速记

```
quickSort(arr, low, high)
├── 终止条件: low >= high → return
├── partition(arr, low, high) → pivotIndex
│   ├── 随机选基准，换到 left
│   ├── i=left, j=right
│   ├── 外层 while(i < j)
│   │   ├── j 先走: while(i<j && arr[j]>=pivot) j--
│   │   ├── i 再走: while(i<j && arr[i]<=pivot) i++
│   │   └── swap(i, j)
│   └── swap(left, i)  ← 基准归位
├── quickSort(low, pivotIndex - 1)
└── quickSort(pivotIndex + 1, high)
```

### 复杂度

| | 平均 | 最坏 | 最好 |
|---|---|---|---|
| 时间 | O(n log n) | O(n²) | O(n log n) |
| 空间 | O(log n) | O(n) | O(log n) |

> **记忆口诀**：快排选基准，j 找小 i 找大，交换后基准归位，左小右大递归夸
