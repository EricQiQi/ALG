# 算法笔记：打家劫舍（力扣 198 题）

## 题目描述
你是一个专业的小偷，计划偷窃沿街的房屋。每间房内都藏有一定的现金，影响你偷窃的**唯一制约因素**是：**相邻**的房屋装有相互连通的防盗系统，**如果两间相邻的房屋在同一晚上被小偷闯入，系统会自动报警**。

给定一个代表每个房屋存放金额的非负整数数组 `nums` ，计算你**在不触动警报的情况下**，一夜之内能够偷窃到的**最高金额**。

```
输入：nums = [1,2,3,1]
输出：4
解释：偷第 1 间（1）和第 3 间（3），共 1 + 3 = 4。

输入：nums = [2,7,9,3,1]
输出：12
解释：偷第 1 间（2）、第 3 间（9）、第 5 间（1），共 2 + 9 + 1 = 12。
```

> 📌 关键理解：对每一间房，小偷只有**两种选择**——「偷」或「不偷」。若偷第 `i` 间，就不能偷第 `i-1` 间，只能接着 `i-2` 的最优结果；若不偷第 `i` 间，则直接沿用 `i-1` 的最优结果。这是典型的**选/不选**型 DP。

---

## 解法：动态规划（选 / 不选）

### 1. 核心思想
定义状态：`dp[i]` 表示**前 `i` 间（下标 0..i）** 能偷到的**最高金额**。对第 `i` 间房做决策：
* **偷第 `i` 间**：金额 = `dp[i-2] + nums[i]`（前一间不能偷，只能接 `i-2` 的结果）。
* **不偷第 `i` 间**：金额 = `dp[i-1]`（沿用到 `i-1` 为止的最优）。

取两者较大者，得**状态转移方程**：
$$dp[i] = \max(dp[i-1],\ \ dp[i-2] + nums[i])$$

* **边界**：`dp[0] = nums[0]`（只有一间就偷它）；`dp[1] = max(nums[0], nums[1])`（两间挑钱多的偷）。
* **返回**：`dp[n-1]`。

> 本质是「带不相邻约束的最大子集和」：每个位置的最优只由前两个位置推出，递推方向从小到大。

### 2. 代码实现 (Java)

```java
class Solution {
    public int rob(int[] nums) {
        if (nums.length == 1) return nums[0];

        int[] dp = new int[nums.length];
        dp[0] = nums[0];                          // 只有一间：偷它
        dp[1] = Math.max(nums[0], nums[1]);       // 两间：挑钱多的

        for (int i = 2; i < nums.length; i++) {
            // 偷 i：dp[i-2] + nums[i]；不偷 i：dp[i-1]
            dp[i] = Math.max(dp[i - 1], dp[i - 2] + nums[i]);
        }
        return dp[nums.length - 1];
    }
}
```

### 3. 复杂度分析
* **时间复杂度**：$O(n)$。从 2 递推到 n-1，一次线性循环。
* **空间复杂度**：$O(n)$。开了长度为 `n` 的 DP 数组（因只依赖前两项，可优化为 $O(1)$，见总结）。

### 4. 递推过程图解
以 `nums = [2,7,9,3,1]` 为例：

```text
i   nums[i]   dp[i-1]   dp[i-2]+nums[i]   dp[i]=max(二者)   决策
0      2         -            -              2            偷 0
1      7         -            -              7            偷 1（7>2）
2      9         7          2+9=11           11           偷 2
3      3        11          7+3=10           11           不偷 3
4      1        11          11+1=12          12           偷 4
返回 dp[4] = 12
```

> 看决策列就懂了：`i=3` 时「不偷」（11 > 10）反而更优，因为 `nums[3]=3` 太少，不值得为它放弃前两间的累积。

---

## 💡 总结
打家劫舍是 **「选 / 不选」型一维 DP** 的模板：状态 `dp[i]` 表示前 i 间的最优收益，用「偷就接 i-2、不偷就沿用 i-1」的二选一推出转移方程，边界单独初始化。

| 特性 | 说明 |
| :--- | :--- |
| **思维出发点** | 每间房二选一：偷（接 `i-2`）或不偷（沿用 `i-1`）。 |
| **代码表现** | `dp[i]=max(dp[i-1], dp[i-2]+nums[i])`，边界 `dp[0]`、`dp[1]` 先填。 |
| **时间 / 空间** | $O(n)$ / $O(n)$（可滚动变量优化到 $O(1)$）。 |

> ⚠️ 与[爬楼梯](Hot70-爬楼梯.md)对比：两者状态都只依赖前两项，**都能用两个变量滚动把空间压到 $O(1)$**（如 `prev2/prev1` 交替更新）。区别在于爬楼梯是「求方案数求和」（`f(i-1)+f(i-2)`），本题是「求最优取 max」（`max(f(i-1), f(i-2)+nums[i])`）。
