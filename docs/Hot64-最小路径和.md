# 算法笔记：最小路径和（力扣 64 题）

## 题目描述
给定一个包含非负整数的 `m x n` 网格 `grid`，请找出一条从**左上角** `(0, 0)` 到**右下角** `(m-1, n-1)` 的路径，使得路径上的数字总和**最小**。

每次只能向**下**或者向**右**移动一步。

```
输入：grid = [[1,3,1],
             [1,5,1],
             [4,2,1]]
输出：7
解释：路径 1→3→1→1→1 的总和最小。

输入：grid = [[1,2,3],
             [4,5,6]]
输出：12
```

> 📌 关键理解：与「不同路径」同源——到达格子 `(i, j)` 的**最后一步**只能来自上方 `(i-1, j)` 或左方 `(i, j-1)`。区别在于：不同路径数「相加」（求方案数），最小路径和「取较小者再累加当前格」（求最优值）。

---

## 解法一：多维动态规划（二维 DP 网格）

### 1. 核心思想
把「从起点走到某格的最小路径和」定义为状态，用「最后一步从哪来」推出转移方程。

* **状态定义**：`dp[i][j]` 表示从起点 `(0, 0)` 走到格子 `(i, j)` 的最小路径和。
* **状态转移**：最后一步只能来自上方或左方，取二者较小值再加上当前格的代价：
  $$dp[i][j] = grid[i][j] + \min(dp[i-1][j],\ dp[i][j-1])$$
* **边界（初始条件）**：
  * 起点 `dp[0][0] = grid[0][0]`。
  * 第一列 `dp[i][0] = dp[i-1][0] + grid[i][0]`：只能一路向下，无选择。
  * 第一行 `dp[0][j] = dp[0][j-1] + grid[0][j]`：只能一路向右，无选择。
* **返回**：`dp[m-1][n-1]`。

### 2. 代码实现 (Java)

```java
class Solution {
    public int minPathSum(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int[][] dp = new int[m][n];
        dp[0][0] = grid[0][0];

        // 边界：第一列只能从上方来，第一行只能从左方来
        for (int i = 1; i < m; i++) dp[i][0] = dp[i - 1][0] + grid[i][0];
        for (int j = 1; j < n; j++) dp[0][j] = dp[0][j - 1] + grid[0][j];

        // 从上到下、从左到右逐格递推
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                dp[i][j] = grid[i][j] + Math.min(dp[i - 1][j], dp[i][j - 1]);
            }
        }
        return dp[m - 1][n - 1];
    }
}
```

### 3. 复杂度分析
* **时间复杂度**：$O(m \times n)$。每个格子只被计算一次。
* **空间复杂度**：$O(m \times n)$。开了 `m x n` 的二维 DP 数组。

### 4. 递推过程图解
以示例 `grid = [[1,3,1],[1,5,1],[4,2,1]]` 为例，首行首列先累加，其余格子 = 当前值 + min(上, 左)：

```text
grid:              dp:
1  3  1            1  4  5        ← 首行：1, 1+3, 4+1
1  5  1            2  7  6        ← 2=1+1；7=5+min(4,2)；6=1+min(5,4)
4  2  1            6  8  7        ← 6=2+4；8=2+min(7,6)；7=1+min(8,6)
返回 dp[2][2] = 7
```

## 解法二：动态规划 + 空间优化（一维滚动数组）

### 1. 核心思想
由于 `dp[i][j]` 只依赖「本行左方 `dp[i][j-1]`」和「上一行同列 `dp[i][j]`」，可将二维压成一维 `dp[j]`：更新到第 `i` 行时，`dp[j]` 还是上一行的旧值（=上方），`dp[j-1]` 已是本行更新后的新值（=左方）。

* **转移**：`dp[j] = grid[i][j] + min(dp[j-1], dp[j])`。
* **每行开头**：`dp[0] += grid[i][0]`（第一列只能从上方来，直接累加）。

### 2. 代码实现 (Java)

```java
class Solution {
    public int minPathSum(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int[] dp = new int[n];
        dp[0] = grid[0][0];

        // 初始化首行
        for (int j = 1; j < n; j++) dp[j] = dp[j - 1] + grid[0][j];

        // 逐行滚动更新
        for (int i = 1; i < m; i++) {
            dp[0] += grid[i][0];                       // 每行第一列只能从上方来
            for (int j = 1; j < n; j++) {
                dp[j] = grid[i][j] + Math.min(dp[j - 1], dp[j]); // 左方 vs 上方
            }
        }
        return dp[n - 1];
    }
}
```

### 3. 复杂度分析
* **时间复杂度**：$O(m \times n)$。
* **空间复杂度**：$O(n)$。只用一维数组，与爬楼梯的滚动变量同一套思想。

---

## 💡 总结
最小路径和是**二维线性 DP 求最优值**的模板：状态只依赖上方和左方，边界（首行首列）单独累加，然后从上到下、从左到右铺满网格。它与「不同路径」是孪生题——把「相加求方案数」换成「取 min 求最小和」即可。

| 特性 | 说明 |
| :--- | :--- |
| **思维出发点** | 最后一步必来自上方或左方，故 `dp[i][j]=grid[i][j]+min(dp[i-1][j], dp[i][j-1])`。 |
| **边界** | 起点 = `grid[0][0]`；首行、首列无选择，只能沿直线累加。 |
| **两种解法** | 二维 DP 直观易想；一维滚动数组把空间从 $O(mn)$ 降到 $O(n)$。 |
| **时间 / 空间** | 均为 $O(mn)$ 时间；空间 $O(mn)$（二维）或 $O(n)$（一维）。 |

> ⚠️ 易错点：
> 1. **首行首列必须先初始化**——它们没有「上方/左方」两个来源，只能沿边累加，若不预处理会漏算或用 0 参与 min 得到错误结果。
> 2. **是「取 min 再加当前格」而非「先加再 min」**——`grid[i][j]` 是当前格代价，必须加在两个前驱的较小值之上。
> 3. **一维版每行开头要单独更新 `dp[0]`**（`dp[0] += grid[i][0]`），因为第一列没有左方可比较。
> 4. **与「不同路径」区分**：那题是求方案数用 `+`，本题求最小和用 `min`，别把转移方程记混。
