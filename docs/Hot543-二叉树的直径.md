# 二叉树的直径（Diameter of Binary Tree）

## 题目描述

给定一棵二叉树，计算它的**直径长度**。直径是任意两个节点之间最长路径的长度（边数），这条路径可能穿过根节点，也可能不穿过。

示例：
```
       1
      / \
     2   3
    / \
   4   5

最长路径：4 → 2 → 1 → 3，直径 = 3
```

> 注意：直径不一定要经过根节点。

---

## 核心思路

**直径 = 某个节点为「拐点」时，左子树深度 + 右子树深度的最大值**。

```text
对每个节点，经过它的最长路径 = 左子树深度 + 右子树深度

       1
      / \
     2   3        以节点 1 为拐点：左深 2 + 右深 1 = 3
    / \
   4   5          以节点 2 为拐点：左深 1 + 右深 1 = 2

全局最大 = 3 ✅
```

一句话：**求深度的过程中，顺便更新直径**。

---

## 代码实现

```java
int ans;  // 记录最大节点数，直径 = 节点数 - 1

public int diameterOfBinaryTree(TreeNode root) {
    ans = 1;
    depth(root);
    return ans - 1;  // 节点数 - 1 = 边数
}

public int depth(TreeNode node) {
    if (node == null) return 0;

    int L = depth(node.left);   // 左子树深度
    int R = depth(node.right);  // 右子树深度

    // 经过当前节点的路径长度 = L + R + 1（节点数）
    ans = Math.max(ans, L + R + 1);

    // 返回当前子树的深度
    return Math.max(L, R) + 1;
}
```

### 复杂度

| 类型 | 复杂度 | 说明 |
|------|--------|------|
| 时间 | O(n) | 每个节点访问一次 |
| 空间 | O(h) | 递归栈深度，h 为树高 |

---

## 执行过程图解

```text
depth(4): L=0, R=0 → ans=max(1, 1)=1, return 1
depth(5): L=0, R=0 → ans=max(1, 1)=1, return 1
depth(2): L=1, R=1 → ans=max(1, 3)=3, return 2   ← 拐点在 2
depth(3): L=0, R=0 → ans=max(3, 1)=3, return 1
depth(1): L=2, R=1 → ans=max(3, 4)=4, return 3   ← 拐点在 1

diameter = ans - 1 = 4 - 1 = 3 ✅
```

---

## 易错点

1. **直径 vs 深度搞混**：深度是从根到叶子的长度，直径是任意两节点间的最长路径，不一定过根
2. **`ans` 初始化为 1 而非 0**：`ans` 记录的是**节点数**（不是边数），单个节点的节点数 = 1，最后 `ans - 1` 才是边数
3. **`ans` 忘记重置**：`ans` 是实例变量，多次调用 `diameterOfBinaryTree` 前需要在方法开头 `ans = 1` 重置
