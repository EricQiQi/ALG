# 二叉树的直径（Diameter of Binary Tree）

## 题目描述

给定一棵二叉树，你需要计算它的直径长度。直径是任意两个节点之间最长路径的边数。这条路径可能穿过根节点，也可能不穿过。

```
       1
      / \
     2   3
    / \
   4   5

最长路径：4→2→1→3，直径 = 3（3条边）
```

---

## 核心思路

**每个节点都可能是路径的"拐点"（最高点），经过它的最长路径 = 左子树深度 + 右子树深度。**

→ 递归求每个节点的深度时，顺便用 `左深度 + 右深度` 更新最大直径。

```
       1
      / \
     2   3
    / \
   4   5

以节点2为拐点：左深度1 + 右深度1 = 2（路径 4→2→5）
以节点1为拐点：左深度2 + 右深度1 = 3（路径 4→2→1→3）← 最大
```

> **注意**：代码中 `ans` 记录的是**节点数**，直径 = 节点数 - 1（边数）。

---

## 代码实现

```java
int ans;

public int diameterOfBinaryTree(TreeNode root) {
    ans = 1;       // 至少1个节点
    depth(root);
    return ans - 1; // 节点数 - 1 = 边数
}

public int depth(TreeNode node) {
    if (node == null) return 0;
    int L = depth(node.left);    // 左子树深度
    int R = depth(node.right);   // 右子树深度
    ans = Math.max(ans, L + R + 1); // 更新最大节点数
    return Math.max(L, R) + 1;      // 返回当前节点深度
}
```

### 复杂度

| 类型 | 复杂度 | 说明 |
|------|--------|------|
| 时间 | O(n) | 每个节点访问一次 |
| 空间 | O(h) | 递归栈深度 = 树高 |

---

## 图解

```
       1
      / \
     2   3
    / \
   4   5

递归过程（从底向上返回深度）：

  depth(4) = 0+0+1 = 1,  ans = max(1, 0+0+1) = 1
  depth(5) = 0+0+1 = 1,  ans = max(1, 0+0+1) = 1
  depth(2) = 1+1+1 = 3,  ans = max(1, 1+1+1) = 3  ← 以2为拐点，路径 4→2→5
  depth(3) = 0+0+1 = 1,  ans = max(3, 0+0+1) = 3
  depth(1) = 2+1+1 = 4,  ans = max(3, 2+1+1) = 4  ← 以1为拐点，路径 4→2→1→3

返回 ans - 1 = 4 - 1 = 3
```

---

## 易错点

1. **直径 vs 节点数**：`ans` 记录的是路径上的节点数，最终返回 `ans - 1` 才是边数（直径）
2. **不一定经过根节点**：最长路径可能在任意子树内部，所以每个节点都要尝试更新 `ans`
3. **ans 初始化为 1**：至少有一个节点（根），节点数最少为 1
