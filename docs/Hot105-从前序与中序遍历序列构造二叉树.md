# 从前序与中序遍历序列构造二叉树

## 题目描述

给定前序遍历 `preorder` 和中序遍历 `inorder`，构造二叉树。

```
前序：[3, 9, 20, 15, 7]    （根 → 左 → 右）
中序：[9, 3, 15, 20, 7]    （左 → 根 → 右）

         3
        / \
       9  20
         /  \
        15   7
```

**核心突破口**：前序的第一个元素是根，在中序中找到根的位置，左边是左子树，右边是右子树。

---

## 方法1：HashMap + 显式边界（分治）

### 思路

1. 先用 HashMap 建立 **中序遍历值 → 索引** 的映射
2. 每次从前序取根节点，通过 HashMap O(1) 查到根在中序中的位置
3. 算出左子树节点数 `leftSize = rootIndex - inLeft`，显式切分左右子树的边界递归

```
前序：[3 | 9 | 20 15 7]      根=3, 中序索引=1
中序：[9 | 3 | 15 20 7]
       左   根    右
      leftSize = 1 - 0 = 1
```

### 代码

```java
public TreeNode buildTree(int[] preorder, int[] inorder) {
    indexMap = new HashMap<>();
    for (int i = 0; i < inorder.length; i++)
        indexMap.put(inorder[i], i);
    return build(preorder, 0, n - 1, inorder, 0, n - 1);
}

TreeNode build(int[] pre, int pL, int pR, int[] in, int iL, int iR) {
    if (pL > pR) return null;
    int rootVal = pre[pL];
    int rootIdx = indexMap.get(rootVal);
    int leftSize = rootIdx - iL;

    TreeNode root = new TreeNode(rootVal);
    root.left  = build(pre, pL + 1, pL + leftSize, in, iL, rootIdx - 1);
    root.right = build(pre, pL + leftSize + 1, pR, in, rootIdx + 1, iR);
    return root;
}
```

### 复杂度

| 类型 | 复杂度 | 说明 |
|------|--------|------|
| 时间 | O(n) | HashMap 建表 O(n) + 每个节点访问一次 |
| 空间 | O(n) | HashMap + 递归栈 |

## 方法2：全局指针 + stop 值（隐式边界）

### 思路

不需要 HashMap，不需要传左右边界。用两个全局指针 `pre`、`in` 和一个 `stop` 参数：

- **`stop`** = 当前子树在中序遍历中的右边界值
- 当 `inorder[in] == stop` 时，说明当前子树建完了，返回 null
- 建左子树时，`stop = root.val`（根节点就是左子树的右边界）
- 建右子树时，`stop` 继承父级的值

```
dfs(stop=MAX) → 根=3
  左 dfs(stop=3)  → 根=9, 左=null, 右=null
  in++  → 跳过中序中的 3
  右 dfs(stop=MAX) → 根=20
    左 dfs(stop=20) → 根=15, 左=null, 右=null
    in++ → 跳过中序中的 20
    右 dfs(stop=MAX) → 根=7, 左=null, 右=null
```

**本质**：`in` 指针天然跟着中序遍历走，`stop` 值代替了显式的边界参数，遇到 stop 就"撞墙回头"。

### 代码

```java
public TreeNode buildTree(int[] preorder, int[] inorder) {
    pre = 0; in = 0;
    return dfs(preorder, inorder, Integer.MAX_VALUE);
}

TreeNode dfs(int[] pre, int[] in, int stop) {
    if (pre >= pre.length) return null;
    if (in[in] == stop) return null;

    TreeNode root = new TreeNode(pre[pre++]);
    root.left  = dfs(pre, in, root.val);   // 左子树：stop = 根的值
    in++;                                   // 跳过中序中的根节点
    root.right = dfs(pre, in, stop);        // 右子树：stop 继承父级
    return root;
}
```

### 复杂度

| 类型 | 复杂度 | 说明 |
|------|--------|------|
| 时间 | O(n) | 每个节点创建一次 |
| 空间 | O(h) | 递归栈深度 = 树高，无额外数据结构 |

---

## 两种方法对比

| | 方法1（HashMap 分治） | 方法2（全局指针 + stop） |
|--|----------------------|------------------------|
| 找根在中序的位置 | HashMap 查 O(1) | `inorder[in] == stop` 隐式判断 |
| 子树边界 | 显式传 4 个边界参数 | `stop` 值自动传递 |
| 额外空间 | O(n) HashMap | 无，只用两个 int |
| 理解难度 | 直观，容易想到 | 巧妙，需要理解 stop 的传递规则 |

---

## 易错点

1. **方法1 的 leftSize 计算**：`leftSize = rootIndex - inLeft`，不是 `rootIndex - preLeft`
2. **方法2 的 in++ 时机**：必须在左子树递归返回之后、右子树递归之前执行，对应中序遍历"左→根→右"中跳过根节点那一步
3. **方法2 的 stop 传递**：左子树 stop = `root.val`，右子树 stop = 父级的 `stop`，不要传反
