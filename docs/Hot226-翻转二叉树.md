# 翻转二叉树（Invert Binary Tree）

## 题目描述

给你一棵二叉树的根节点 `root`，翻转这棵二叉树（左右镜像），并返回根节点。

```
翻转前：          翻转后：
     4                4
    / \              / \
   2   7     →     7   2
  / \ / \        / \ / \
 1  3 6  9      9  6 3  1
```

---

## 核心思路

**每个节点的左右子树交换位置，递归地对所有节点都这样做。**

```
invertTree(node)：
  ① 递归翻转左子树 → 拿到翻转后的 left
  ② 递归翻转右子树 → 拿到翻转后的 right
  ③ node.left = right, node.right = left  ← 交换
  ④ 返回 node
```

---

## 代码实现

```java
public TreeNode invertTree(TreeNode root) {
    if (root == null) return null;
    TreeNode left = invertTree(root.left);
    TreeNode right = invertTree(root.right);
    root.left = right;
    root.right = left;
    return root;
}
```

### 复杂度

| 类型 | 复杂度 | 说明 |
|------|--------|------|
| 时间 | O(n) | 每个节点访问一次 |
| 空间 | O(h) | 递归栈深度 = 树高 |

---

## 图解

```
       4
      / \
     2   7
    / \   \
   1   3   9

递归到底，从叶子开始返回：

   1→null, 3→null  →  2的左右交换  →  2: left=3, right=1
   9→null, null    →  7的左右交换  →  7: left=null, right=9

   2和7都翻好了  →  4的左右交换  →  4: left=7, right=2

最终：
       4
      / \
     7   2
    /   / \
   9   3   1
```

---

## 易错点

1. **必须先存再交换**：`TreeNode left = invertTree(root.left)` 先保存递归结果，再赋值交换。不能写成 `root.left = invertTree(root.right)` 然后再 `root.right = invertTree(root.left)` — 此时 `root.left` 已经被改过了
2. **递归终止条件**：`root == null` 返回 null，别忘了
