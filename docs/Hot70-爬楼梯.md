# 算法笔记：爬楼梯（力扣 70 题）

## 题目描述
假设你正在爬楼梯。需要 `n` 阶你才能到达楼顶。

每次你可以爬 **1 或 2** 个台阶。你有多少种 **不同的方法** 可以爬到楼顶呢？

```
输入：n = 3
输出：3
解释：1+1+1、1+2、2+1，共 3 种。

输入：n = 4
输出：5
解释：1+1+1+1、1+1+2、1+2+1、2+1+1、2+2，共 5 种。
```

> 📌 关键理解：到达第 `i` 阶的**最后一步**只有两种——从第 `i-1` 阶迈 1 步、或从第 `i-2` 阶迈 2 步。因此 `f(i) = f(i-1) + f(i-2)`，正是**斐波那契数列**。

---

## 解法一：动态规划（DP 数组）

### 1. 核心思想
定义状态：`dp[i]` 表示到达第 `i` 阶的**方法总数**。
* **状态转移**：最后一步要么迈 1 阶（来自 `dp[i-1]`），要么迈 2 阶（来自 `dp[i-2]`），二者相加。
  $$dp[i] = dp[i-1] + dp[i-2]$$
* **边界（初始条件）**：`dp[1] = 1`（只有一种走法），`dp[2] = 2`（`1+1` 或 `2`）。
* **返回**：`dp[n]`。

> 贪心点不适用于本题，这是标准的**一维线性 DP**：每个状态只依赖前两个状态，递推方向从小到大。

### 2. 代码实现 (Java)

```java
class Solution {
    public int climbStairs(int n) {
        if (n <= 2) return n;

        int[] dp = new int[n + 1]; // 下标 0..n，直接用 i 对应第 i 阶
        dp[1] = 1;
        dp[2] = 2;

        for (int i = 3; i <= n; i++) {
            // 最后一步：从 i-1 迈 1 阶，或从 i-2 迈 2 阶
            dp[i] = dp[i - 1] + dp[i - 2];
        }
        return dp[n];
    }
}
```

### 3. 复杂度分析
* **时间复杂度**：$O(n)$。从 3 递推到 n，一次线性循环。
* **空间复杂度**：$O(n)$。开了长度为 `n + 1` 的 DP 数组。

---

## 解法二：滚动变量法（空间优化）

### 1. 核心思想
观察状态转移：`dp[i]` 只用到 `dp[i-1]` 和 `dp[i-2]`，更早的历史根本用不上。因此**不必开整个数组**，只用两个变量**滚动**记录前两阶即可。
* `prev2`：相当于 `dp[i-2]`（前两阶）。
* `prev1`：相当于 `dp[i-1]`（前一阶）。
* 每步算 `curr = prev1 + prev2`，然后**整体向前滚动**：`prev2 ← prev1`，`prev1 ← curr`。

> 这是 DP **滚动数组**思想的极简版：当状态只依赖固定有限个前驱时，用常数个变量替代数组，把空间从 $O(n)$ 压到 $O(1)$。

### 2. 代码实现 (Java)

```java
class Solution {
    public int climbStairs(int n) {
        if (n <= 2) return n;

        int prev2 = 1; // 前两阶（相当于 dp[i-2]）
        int prev1 = 2; // 前一阶（相当于 dp[i-1]）

        for (int i = 3; i <= n; i++) {
            int curr = prev1 + prev2; // 当前阶 = 前两项之和
            prev2 = prev1;            // 整体向前滚动
            prev1 = curr;
        }
        return prev1;
    }
}
```

### 3. 复杂度分析
* **时间复杂度**：$O(n)$。同样线性递推。
* **空间复杂度**：$O(1)$。只用了 `prev1`、`prev2`、`curr` 三个变量。

### 4. 递推过程图解
以 `n = 5` 为例：

```text
i      prev2   prev1   curr=prev1+prev2   （含义：f(i)=f(i-1)+f(i-2)）
起始     1       2          -              f(1)=1, f(2)=2
3        1→2    2→3         3              f(3)=3
4        2→3    3→5         5              f(4)=5
5        3→5    5→8         8              f(5)=8
返回 prev1 = 8
```

> 本质是斐波那契：`1, 2, 3, 5, 8, ...`，`prev1` 每轮“接管”新的 `curr`，`prev2` 紧随其后。

---

## 💡 总结
爬楼梯是**一维 DP 的入门模板**：把「到达第 i 阶的方法数」定义为状态，用「最后一步从哪来」推出转移方程，再由「状态只依赖前两项」自然引出滚动变量空间优化。

| 特性 | DP 数组法 | 滚动变量法 |
| :--- | :--- | :--- |
| **核心** | 开 `dp[n+1]` 存所有状态 | 只用 `prev1`/`prev2` 滚动 |
| **转移** | `dp[i]=dp[i-1]+dp[i-2]` | `curr=prev1+prev2` 后整体前移 |
| **时间** | $O(n)$ | $O(n)$ |
| **空间** | $O(n)$ | $O(1)$ |

> ⚠️ 易错点：递推是 `dp[i] = dp[i-1] + dp[i-2]`（依赖**前两项**），若误写成 `dp[1] + dp[2]` 会得到恒为 3 的常数结果——这是对“依赖前驱”理解不到位导致的笔误。两法答案一致时才说明递推写对。
