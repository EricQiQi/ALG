# 算法笔记：分割等和子集（力扣 416 题）

## 题目描述
给你一个**只包含正整数**的**非空**数组 `nums`。请你判断是否可以将这个数组分割成两个子集，使得两个子集的元素和相等。

```
输入：nums = [1,5,11,5]
输出：true
解释：数组可以分割成 [1, 5, 5] 和 [11]，和均为 11。

输入：nums = [1,2,3,5]
输出：false
解释：数组不能分割成两个元素和相等的子集。
```

> 📌 关键理解：「分成两个等和子集」等价于「**能否从数组中选出若干个数，使其和恰好为 sum/2**」——选出来的一半凑齐了，剩下的一半自然相等。这正是 **0/1 背包的可行性版本**：每个数字（物品）只能选一次，问能否恰好装满容量为 `sum/2` 的背包。

---

## 解法：0/1 背包（可行性，一维滚动数组）

### 1. 核心思想
先做两个前置判断，再套 0/1 背包模板：
* **剪枝**：总和 `sum` 为奇数时不可能平分，直接返回 `false`；背包容量定为 `target = sum / 2`。
* **状态定义**：`dp[i]` 表示能否从已遍历的数字中选出若干个，使和**恰好**为 `i`。
* **状态转移**（选 / 不选 num 两种决策取或）：
  $$dp[i] = dp[i]\ \|\|\ dp[i - num]$$
* **边界（初始化）**：`dp[0] = true`——什么都不选即可凑出 0，其余默认 `false`。
* **遍历顺序**：外层物品、内层容量**倒序**（从 `target` 扫到 `num`）。倒序保证 `dp[i-num]` 取到的是「上一轮」的旧值，每个 num 只被用一次——这是 0/1 背包与完全背包（正序）的关键区别。
* **返回**：`dp[target]`。

### 2. 代码实现 (Java)

```java
class Solution {
    public boolean canPartition(int[] nums) {
        int sum = 0;
        for (int num : nums) sum += num;
        // 奇数无法平分
        if (sum % 2 == 1) return false;

        int target = sum / 2;  // 背包容量：只需凑出总和的一半，另一半自然相等

        boolean[] dp = new boolean[target + 1];  // 默认值为 false，表示「凑不出」
        dp[0] = true;  // 边界：什么都不选即可凑出 0

        // 外层物品：每个数字只能用一次（0/1 背包）
        for (int num : nums) {
            // 内层容量倒序：从 target 往下扫到 num，防止本轮 num 被自己重复使用
            for (int i = target; i >= num; i--) {
                dp[i] = dp[i] || dp[i - num];
            }
        }

        return dp[target];
    }
}
```

### 3. 复杂度分析
* **时间复杂度**：$O(n \times sum)$。$n$ 个物品，每个扫一遍 $O(target)$ 的容量轴。
* **空间复杂度**：$O(sum)$。一维滚动数组。

### 4. 递推过程图解
以 `nums = [1,5,11,5]` 为例，`sum = 22`，`target = 11`。跟踪每一步「能凑出的和」的集合：

```text
初始:      {0}                      ← dp[0]=true，其余 false
加入 1:    {0, 1}                   ← 0+1
加入 5:    {0, 1, 5, 6}             ← 旧集合各 +5
加入 11:   {0, 1, 5, 6, 11, ...}    ← 0+11 命中 target，dp[11]=true
加入 5:    dp[11] 保持 true          ← dp[11] || dp[6]，两个来源都为 true
返回 dp[11] = true
```

> 倒序的直观含义：加入 `num` 时从大到小扫容量，`dp[i-num]` 还没被本轮更新过，相当于「在不含 num 的旧集合基础上 +num」。若正序，`dp[i-num]` 可能已经是「本轮装了 num」的新值，num 就会被装第二次——那就变成完全背包了。

---

## 💡 总结
分割等和子集是 **0/1 背包可行性问题**的模板题：等和 ⇒ 目标和为 `sum/2` ⇒ 恰好装满型背包。`dp[i]` 用 boolean 记账「能否凑出 i」，转移取或（不选维持 / 选看 `i-num`），内层倒序保证每件物品只用一次。

| 特性 | 说明 |
| :--- | :--- |
| **问题转化** | 等和子集 ⇒ 凑出 `sum/2` ⇒ 0/1 背包可行性 |
| **状态** | `dp[i]` = 能否恰好凑出和 `i` |
| **转移** | `dp[i] = dp[i] \|\| dp[i-num]`（选/不选取或） |
| **遍历** | 外层物品，内层容量**倒序**（0/1 背包标志） |
| **时间/空间** | $O(n \times sum)$ / $O(sum)$ |

> ⚠️ 易错点：① **`sum` 为奇数先剪枝**；② **`dp[0] = true` 不能忘**，否则整个递推失去「起点」；③ **内层必须倒序**，正序会把 0/1 背包写成完全背包（物品被重复使用）；④ 内层循环下界是 `i >= num`，防止 `dp[i-num]` 越界；⑤ 本题为可行性问题用 `||`，若是「方案数」则改成 `+=`（见零钱兑换 II），若是「最少个数」用 `min`（见零钱兑换）。
