# 算法笔记：划分字母区间（力扣 763 题）

## 题目描述
给你一个由小写字母组成的字符串 `s` 。我们要把这个字符串划分成 **尽可能多** 的片段，使得 **同一个字母只出现在其中的一个片段** 。

返回一个表示每个片段 **长度** 的列表。

```
输入：s = "ababcbacadefegdehijhklij"
输出：[9,7,8]
解释：划分结果为 "ababcbaca", "defegde", "hijhklij"。
```

> 📌 关键理解：“同一字母只出现在一个片段”意味着——只要某字母在某处出现，它的**最后一次出现**也必须在同一片段里。因此一个片段至少要覆盖到“片段内所有字母的最晚结束位置”。

---

## 解法：贪心（最远结束位置 + 边界收缩）

### 1. 核心思想
同一个字母不能跨片段，等价于：当前片段必须一路延伸到“片段内每个字母的**最后出现位置**”中最远的那个。于是先预处理出每个字母的**最后下标**，再用一次遍历贪心地切分。
* `last[c]`：字母 `c` 在字符串中**最后一次出现的下标**（第一遍预处理）。
* `end`：当前片段必须延伸到的**最远结束下标**，遍历中不断取 `max(end, last[s[i]])`。
* `start`：当前片段的起始下标。
* 当遍历指针 `i == end`：说明当前片段内所有字母的最后出现位置都被覆盖，这里可以**安全切一刀**，记录长度 `end - start + 1`，并把 `start` 推到 `i + 1` 开始新片段。

> 贪心点：每个片段都**尽早结束**——一旦 `i` 追上了当前必须延伸到的最远处 `end`，就立刻切分。每个片段都取到“能满足约束的最短长度”，自然得到**片段数最多**的划分。

### 2. 代码实现 (Java)

```java
class Solution {
    public List<Integer> partitionLabels(String s) {
        // 预处理：记录每个字母最后一次出现的下标
        int[] last = new int[26];
        for (int i = 0; i < s.length(); i++) {
            last[s.charAt(i) - 'a'] = i;
        }

        List<Integer> res = new ArrayList<>();
        int start = 0; // 当前片段起点
        int end = 0;   // 当前片段必须延伸到的最远结束下标

        for (int i = 0; i < s.length(); i++) {
            // 用当前字母的最后出现位置扩张片段边界
            end = Math.max(end, last[s.charAt(i) - 'a']);

            // i 追上 end：当前片段内所有字母都已收尾，可以切分
            if (i == end) {
                res.add(end - start + 1);
                start = i + 1; // 开启新片段
            }
        }
        return res;
    }
}
```

### 3. 复杂度分析
* **时间复杂度**：$O(n)$。预处理一遍 + 切分一遍，共两次线性遍历。
* **空间复杂度**：$O(1)$。`last` 数组长度固定为 26（仅小写字母），与输入规模无关。

### 4. 遍历过程图解
以 `s = "ababcbaca"`（划分出第一个片段的过程）为例，先得有最后下标 `last[a]=8, last[b]=5, last[c]=7`：

```text
i   s[i]   end=max(end, last[s[i]])    i == end?
0    a          max(0, 8) = 8            否
1    b          max(8, 5) = 8            否
2    a          max(8, 8) = 8            否
3    b          max(8, 5) = 8            否
4    c          max(8, 7) = 8            否
5    b          max(8, 5) = 8            否
6    a          max(8, 8) = 8            否
7    c          max(8, 7) = 8            否
8    a          max(8, 8) = 8            是 → 切分，长度 8-0+1 = 9，start=9
```

> 第一个片段 `"ababcbaca"` 里，字母 `a` 最后一次出现在下标 8，把 `end` 一路撑到 8；期间 `b`、`c` 的最远位置都没超过 8，所以 i=8 时才首次满足 `i==end`，切出长度 9。

### 5. 概念澄清：`end` 是“必须延伸到的最远下标”
`end` 不是“当前已经扫到多远”，而是“**至少要走多远才算收尾**”，由片段内所有字母的最后位置共同决定：

| | 本题 `end` | 若误解为“当前扫到的下标” |
| :--- | :--- | :--- |
| 含义 | 片段必须覆盖的**最远结束位置** | 只是遍历指针 `i` 本身 |
| 更新式 | `max(end, last[s[i]])` | 无从体现“最后出现”约束 |
| 切分条件 | `i == end`（追上最远收尾点） | 每个位置都切，退化成单字符 |

**为什么切分点是 `i == end` 而非 `i >= end`：** `end` 只会被 `max` 不断撑大或保持不变，`i` 每次 +1，二者必然在某一时刻**恰好相等**（而不会跳过），此时切分最干净。`==` 与 `>=` 在本题等价，但 `==` 语义更精确地表达了“追平”这一瞬间。

---

## 💡 总结
划分字母区间是**“最远结束位置”型贪心**的经典模板：把“同字母不跨段”转化为“片段必须覆盖到段内所有字母的最后出现位置”，再用一次遍历在 `i == end` 处逐段切分。它与[跳跃游戏 II](Hot45-跳跃游戏II.md)的 `end` / `maxPosition` 分层思想同源——都用“当前边界 + 下一层最远处”两个变量推进。

| 特性 | 说明 |
| :--- | :--- |
| **思维出发点** | 片段边界 = 段内所有字母最后位置的最远值，追平即切。 |
| **代码表现** | 预处理 `last[26]`；遍历 `end=max(end, last[..])`，`i==end` 时收割长度并推进 `start`。 |
| **时间 / 空间** | $O(n)$ / $O(1)$，两次遍历 + 定长 26 数组。 |

> ⚠️ 易混淆点：预处理必须存**最后一次**出现位置（不是第一次），否则片段可能在该字母尚未收尾时就提前切开，导致同一字母跨段、结果错误。
