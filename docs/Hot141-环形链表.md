# 算法笔记：环形链表（力扣 141 题）

## 题目描述
给你一个链表的头节点 `head`，判断链表中**是否有环**。有环返回 `true`，否则返回 `false`。

```
输入: head = 3→2→0→4，其中 4 的 next 指回节点 2
输出: true   （存在环）
```

---

## 核心思想

> **快慢指针（Floyd 判圈）：快指针一次走两步、慢指针一次走一步，有环必相遇。**

想象操场跑步：慢的人跑一步、快的人跑两步，如果跑道是**直线**，快的会先到终点，永远追不上慢的；但如果跑道是**环形**，快的一定会从后面"套圈"追上慢的，两者必然相遇。

```
无环：fast 先冲到 null → 结束，返回 false
有环：fast、slow 进入环后，fast 每步比 slow 多走 1，距离逐步缩小 → 必然相遇
```

---

## 图解：相遇过程

```
1 → 2 → 3 → 4 → 5
        ↑_________|   (5 的 next 指回 2，成环)

slow: 1→2→3→4→...   每步 +1
fast: 1→3→5→3→...   每步 +2
进入环后 fast 不断逼近 slow，最终在环内某点相遇 → true
```

---

## 代码实现 (Java)

```java
public boolean hasCycle(ListNode head) {
    if (head == null) return false;

    ListNode slow = head;
    ListNode fast = head;
    while (fast != null && fast.next != null) {  // 保证 fast 能走两步
        slow = slow.next;                         // 慢指针走一步
        fast = fast.next.next;                    // 快指针走两步
        if (slow == fast) return true;            // 相遇 → 有环
    }
    return false;                                 // fast 到达末尾 → 无环
}
```

---

## ❗关键易错点

**1. 循环条件必须是 `fast != null && fast.next != null`**
因为 fast 要走两步 `fast.next.next`，必须保证 `fast` 和 `fast.next` 都非空，否则 NPE。这个条件同时也是"无环"的退出出口——fast 能走到链表尾说明没有环。

**2. 判相遇用 `slow == fast`（引用相等），不是 `val` 相等**
比较的是**同一个节点**，不是值相同。

**3. 空链表直接返回 false**
边界处理。

---

## 复杂度分析

* **时间复杂度**：$O(n)$。无环时 fast 走一趟；有环时 fast 在环内最多绕常数圈就追上 slow。
* **空间复杂度**：$O(1)$。只用了两个指针（相比 HashSet 记录访问过的节点的 $O(n)$ 法更优）。

## 💡 记忆口诀

> **快走两步慢走一步，直线跑道快的先到头（无环），环形跑道快的必套圈（有环相遇）。循环条件盯紧 fast 和 fast.next 都别为空。**
