# 算法笔记：轮转数组（力扣 189 题）

## 题目描述
给定一个整数数组 `nums`，将数组中的元素向右轮转 `k` 个位置，其中 `k` 是非负数。

```
输入: nums = [1,2,3,4,5,6,7], k = 3
输出: [5,6,7,1,2,3,4]
解释: 向右轮转 3 位，末尾的 5,6,7 绕到了开头
```

---

## ⚠️ 公共前提：必须先 `k = k % n`

`k` 可能远大于数组长度 `n`（如 `k=1000, n=7`），轮转 `n` 次等于没转。所以三种方法**都要先取模**，否则越界或做无用功。

---

## 解法一：辅助数组（直接映射）

### 核心思想
新开一个数组，把每个元素**直接放到它轮转后的目标位置**：`i` 号元素的新家是 `(i + k) % n`。

```java
public static void rotate_1(int[] nums, int k) {
    int n = nums.length;
    int[] res = new int[n];
    for (int i = 0; i < n; i++) {
        res[(i + k) % n] = nums[i];   // 直接算出目标位置
    }
    System.arraycopy(res, 0, nums, 0, n);
}
```

> 映射示意：`i=4 → (4+3)%7=0`，所以 `nums[4]=5` 落到 `res[0]`，正是答案开头。

- **时间 O(n)**，**空间 O(n)**（多开一个数组）

---

## 解法二：三次翻转（最优雅）

### 核心思想
翻转有个奇妙的性质：**先整体翻，再分别翻前 k 个和剩余部分**，就等价于右轮转 k 位。

```
原始:            [1, 2, 3, 4, 5, 6, 7]   k=3
① 整体翻转:      [7, 6, 5, 4, 3, 2, 1]   ← 5,6,7 到了前面，但内部顺序反了
② 翻转前 k 个:   [5, 6, 7, 4, 3, 2, 1]   ← 把前 3 个顺序纠正回来
③ 翻转剩余:      [5, 6, 7, 1, 2, 3, 4]   ← 把后 4 个顺序纠正回来 ✅
```

```java
public static void rotate_2(int[] nums, int k) {
    int n = nums.length;
    k = k % n;
    reverse(nums, 0, n - 1);   // ① 整体翻转
    reverse(nums, 0, k - 1);   // ② 翻转前 k 个
    reverse(nums, k, n - 1);   // ③ 翻转剩余
}

private static void reverse(int[] nums, int start, int end) {
    while (start < end) {
        int temp = nums[start];
        nums[start] = nums[end];
        nums[end] = temp;
        start++;
        end--;
    }
}
```

- **时间 O(n)**（每个元素被翻转 2 次），**空间 O(1)**
- 记忆：**整体翻 → 前 k 翻 → 后段翻**

## 解法三：环状替换（搬家接力）

### 核心思想
> **每个人都要往后挪 k 个座位，但只有一只手（一个临时变量），于是玩"接力"：抱一个、放一个、再抱被顶走的那个，绕一圈回到起点；一圈没串完就换个起点再开一圈，直到 n 个人都坐好。**

### 变量对照（把代码翻译成人话）

| 变量 | 大白话 |
| :--- | :--- |
| `prev` | 手里正抱着的那个人（接力棒）|
| `current` | 手里这个人当前所在位置 |
| `next = (current+k)%n` | 他该去的位置 |
| `temp = nums[next]` | 先把目标位上被顶走的人记下来 |
| `nums[next] = prev` | 把手里的人放下 |
| `prev = temp` | 把被顶走的人抱进手里，接力继续 |
| `count` | 已安置好几个人，等于 n 就收工 |
| `start` | 本圈起点，用来判断是否绕回原地（闭环）|

### 走一遍：`nums=[1,2,3,4,5,6,7]`, `k=3`, 从 start=0

```
抱着1 → 放到位置3(顶走4) → 抱着4 → 放到位置6(顶走7) → 抱着7
→ 放到位置2(顶走3) → 抱着3 → 放到位置5(顶走6) → 抱着6
→ 放到位置1(顶走2) → 抱着2 → 放到位置4(顶走5) → 抱着5
→ 放到位置0(绕回起点，闭环！)

结果：[5,6,7,1,2,3,4]   count=7=n，收工 ✅
```

### 代码实现

```java
public static void rotate_3(int[] nums, int k) {
    int n = nums.length;
    k = k % n;
    if (k == 0) return;

    int count = 0;
    for (int start = 0; count < n; start++) {   // 一圈没串完就换起点再开一圈
        int current = start;
        int prev = nums[start];
        do {
            int next = (current + k) % n;
            int temp = nums[next];   // 暂存被顶走的人
            nums[next] = prev;       // 放下手里的人
            prev = temp;             // 抱起被顶走的人
            current = next;
            count++;
        } while (start != current);  // 绕回起点 → 本圈闭环
    }
}
```

### ❗为什么外面还要套一层 for 循环？

**一圈不一定能覆盖所有人**。当 `n` 和 `k` 有公约数时，跳跃会提前绕回起点，只串到一部分人：

```
n=6, k=2:
start=0 这圈：0 → 2 → 4 → 0   只串了 3 个人（1,3,5 号位没碰到）
start=1 这圈：1 → 3 → 5 → 1   再串剩下 3 个
count 累加到 6 = n，才真正排完
```

所以用 `count < n` 控制：**直到所有元素都被安置好为止**。（数学上，环的个数 = `gcd(n, k)`。）

- **时间 O(n)**，**空间 O(1)**

---

## 💡 三法对比总结

| 特性 | 解法一 辅助数组 | 解法二 三次翻转 | 解法三 环状替换 |
| :--- | :--- | :--- | :--- |
| **核心思想** | 直接映射到目标位 | 翻转的数学性质 | 接力搬人，绕环替换 |
| **时间复杂度** | O(n) | O(n) | O(n) |
| **空间复杂度** | O(n) | O(1) | O(1) |
| **编码难度** | 最低 | 低 | 较高（环的边界易错）|
| **易错点** | 忘记最后拷回原数组 | 翻转区间边界 | 忘记外层 for / count 计数 |

**结论**：面试首选**三次翻转**（优雅、O(1) 空间、好写）；环状替换思想最巧但边界最难写；辅助数组最直观但费空间。三者都要记得 `k %= n`。

> **记忆口诀**：轮转先取模，翻转最优雅（整体→前k→后段），接力环状替，辅助数组垫底。
