# 复制带随机指针的链表（Copy List with Random Pointer）

## 题目描述

复制一个带 `random` 指针的链表。`random` 可以指向链表中的任意节点或 null。要求**深拷贝**（全新节点，不引用原链表任何节点）。

```
原链表：  7 → 13 → 11 → 10 → 1
random：  ↓    ↓    ↓    ↓    ↓
         11    1   null   10   7

深拷贝：结构完全相同，但全是新节点
```

---

## 方法1：哈希表（最直观）

### 思路

**两遍遍历：**
- 第一遍：为每个原节点创建新节点，存入 `map(原节点 → 新节点)`
- 第二遍：通过 map 设置新节点的 next 和 random

```
map.get(curr).next = map.get(curr.next)
map.get(curr).random = map.get(curr.random)
```

### 代码

```java
public Node copyRandomList(Node head) {
    Map<Node, Node> map = new HashMap<>();
    // 第一遍：创建新节点，建立映射
    for (Node curr = head; curr != null; curr = curr.next) {
        map.put(curr, new Node(curr.val));
    }
    // 第二遍：设置 next 和 random
    for (Node curr = head; curr != null; curr = curr.next) {
        map.get(curr).next = map.get(curr.next);
        map.get(curr).random = map.get(curr.random);
    }
    return map.get(head);
}
```

### 复杂度

| 类型 | 复杂度 |
|------|--------|
| 时间 | O(n) |
| 空间 | O(n) HashMap |

## 方法2：递归 + 记忆化

### 思路

递归复制：`新节点.next = 递归复制(head.next)`，`新节点.random = 递归复制(head.random)`。
用 HashMap 缓存，避免 random 指向已复制节点时重复创建。

### 代码

```java
Map<Node, Node> cachedMap = new HashMap<>();

public Node copyRandomList(Node head) {
    if (head == null) return null;
    if (!cachedMap.containsKey(head)) {
        Node newNode = new Node(head.val);
        cachedMap.put(head, newNode);
        newNode.next = copyRandomList(head.next);
        newNode.random = copyRandomList(head.random);
    }
    return cachedMap.get(head);
}
```

> **注意**：`cachedMap` 是实例变量，多次调用需要 `clear()`。

## 方法3：原地拼接拆分（O(1) 空间）

### 思路

**三步走，不需要 HashMap：**

```
第1步：在每个原节点后面插入复制节点
  原7 → 新7 → 原13 → 新13 → 原11 → 新11 → ...

第2步：设置 random
  新节点.random = 原节点.random.next

第3步：拆分两个链表
  原：7 → 13 → 11 → ...
  新：7'→ 13'→ 11'→ ...
```

### 代码

```java
public Node copyRandomList(Node head) {
    if (head == null) return null;

    // 1. 每个节点后面插入复制节点
    Node p = head;
    while (p != null) {
        Node copy = new Node(p.val);
        copy.next = p.next;
        p.next = copy;
        p = copy.next;
    }

    // 2. 设置 random
    p = head;
    while (p != null) {
        if (p.random != null) {
            p.next.random = p.random.next;
        }
        p = p.next.next;
    }

    // 3. 拆分
    Node newHead = head.next;
    Node p1 = head, p2 = newHead;
    while (p2.next != null) {
        p1.next = p2.next;
        p2.next = p2.next.next;
        p1 = p1.next;
        p2 = p2.next;
    }
    p1.next = null;  // 原链表尾部置空
    return newHead;
}
```

### 复杂度

| 类型 | 复杂度 |
|------|--------|
| 时间 | O(n) |
| 空间 | **O(1)** |

## 三种方法对比

| | 哈希表 | 递归+记忆化 | 原地拼接拆分 |
|--|--------|-----------|------------|
| 时间 | O(n) | O(n) | O(n) |
| 空间 | O(n) | O(n) | **O(1)** |
| 代码量 | 最少，最直观 | 简洁 | 稍多 |
| 推荐度 | **推荐** | 理解递归思想 | 面试加分项 |

## 关键难点

### 为什么 random 难处理？

普通链表复制只需要跟着 next 走，但 random 可能指向**任意节点**（甚至还没创建的节点）。

解决方案的核心都一样：**先建立原节点和新节点的对应关系，再通过这个关系设置 random。**

- 哈希表：用 map 存对应关系
- 原地拼接：新节点就在原节点后面，`原节点.next` 就是对应的新节点

---

## 易错点

1. **哈希表法第二遍不能用 new Node**：必须从 map 里取已创建的新节点
2. **递归法必须用缓存**：random 可能指向已复制过的节点，没缓存会重复创建
3. **原地拆分时 p1.next = null**：最后一个原节点的 next 要手动置 null，否则原链表尾部还指向新链表节点
4. **递归法的 cachedMap 是实例变量**：多次调用需要清空

```
深拷贝带 random：

原地拼接更省空，新节点插原节点后，random 看 next。
```
