# 复制带随机指针的链表（Copy List with Random Pointer）

## 题目描述

请实现 `copyRandomList` 函数，复制一个复杂链表。在复杂链表中，每个节点除了有一个 `next` 指针指向下一个节点，还有一个 `random` 指针指向链表中的任意节点或者 `null`。

示例：
```
输入：head = [7, 13, 11, 10, 1]
      7.random = null
      13.random = 7
      11.random = 1
      10.random = 11
      1.random = 7

输出：[7, 13, 11, 10, 1] 的完整拷贝
```

> 核心难点：`random` 指针可能指向任意节点，复制时无法一次到位，必须先建立"旧节点 → 新节点"的映射关系。

---

## 核心思路

三种解法围绕同一个问题展开：**怎么让新节点的 random 指对地方？**

| 解法 | 怎么解决 | 空间 |
|------|---------|------|
| 哈希表 | 用 Map 显式存"旧→新"映射 | O(n) |
| 回溯法 | 递归 + Map 缓存，边递归边建映射 | O(n) |
| 迭代穿插 | 把新节点插在原节点后面，利用位置关系隐式建立映射 | **O(1)** |

---

## 解法一：哈希表

### 原理图解

```text
原链表：  old1 → old2 → old3 → null
           ↓       ↓       ↓
新链表：  new1 → new2 → new3 → null

第一遍：遍历原链表，创建所有新节点，存入 Map {old → new}
第二遍：再遍历原链表，通过 Map 查表给新节点接 next 和 random

old1.random = old3  →  new1.random = map.get(old3) = new3  ✅
```

### 算法步骤

1. **第一遍遍历**：为每个旧节点创建对应的新节点，存入 `Map<旧, 新>`
2. **第二遍遍历**：通过 Map 查表，给每个新节点设置 `next` 和 `random`
3. 返回 `map.get(head)` 即为新链表头

### 代码实现

```java
public Node copyRandomList_1(Node head) {
    if (head == null) return null;

    Map<Node, Node> map = new HashMap<>();
    // 第一遍：创建所有新节点，建立 旧→新 映射
    for (Node curr = head; curr != null; curr = curr.next) {
        map.put(curr, new Node(curr.val));
    }
    // 第二遍：通过 Map 查表，给新节点接 next 和 random
    for (Node curr = head; curr != null; curr = curr.next) {
        map.get(curr).next = map.get(curr.next);
        map.get(curr).random = map.get(curr.random);
    }
    return map.get(head);
}
```

### 复杂度

| 类型 | 复杂度 | 说明 |
|------|--------|------|
| 时间 | O(n) | 遍历两遍 |
| 空间 | O(n) | HashMap 存 n 个映射 |

## 解法二：回溯法

### 原理图解

```text
copyRandomList_2(old1)
  ├── 创建 new1，存入 Map {old1 → new1}
  ├── new1.next = copyRandomList_2(old2)
  │     ├── 创建 new2，存入 Map {old2 → new2}
  │     ├── new2.next = copyRandomList_2(old3) ...
  │     └── new2.random = copyRandomList_2(old3) → 命中缓存，直接返回 ✅
  └── new1.random = copyRandomList_2(old3) → 命中缓存，直接返回 ✅
```

### 算法步骤

1. 递归入口：如果 `head` 已在缓存中，直接返回对应的新节点
2. 否则创建新节点，存入缓存 `Map<旧, 新>`
3. 递归设置 `next` 和 `random`（递归过程中会自动命中缓存，避免重复创建）

### 代码实现

```java
private static Map<Node, Node> cachedMap = new HashMap<>();

public Node copyRandomList_2(Node head) {
    if (head == null) return null;
    if (!cachedMap.containsKey(head)) {
        Node newNode = new Node(head.val);
        cachedMap.put(head, newNode);
        newNode.next = copyRandomList_2(head.next);
        newNode.random = copyRandomList_2(head.random);
    }
    return cachedMap.get(head);
}
```

### 复杂度

| 类型 | 复杂度 | 说明 |
|------|--------|------|
| 时间 | O(n) | 每个节点最多访问一次 |
| 空间 | O(n) | Map + 递归栈 |

> ⚠️ 注意：`cachedMap` 是静态变量，多次调用前需要 `cachedMap.clear()` 清空。

## 解法三：迭代穿插法（最优）

### 原理图解

```text
第一步：在每个原节点后面插入它的拷贝
原：  A → B → C → null
穿插：A → A' → B → B' → C → C' → null

第二步：利用位置关系设置 random
        A.random = C  →  A'.random = C.random.next = C'

第三步：拆成两条链表
        A → B → C → null     （原链表恢复）
        A'→ B'→ C'→ null     （新链表完成）
```

### 算法步骤

1. **穿插复制**：遍历原链表，在每个节点后面插入它的拷贝
2. **设置 random**：`copy.random = old.random.next`（原节点的 random 的下一个就是拷贝的 random）
3. **拆分链表**：交替拆分，恢复原链表，提取新链表

### 代码实现

```java
public Node copyRandomList_3(Node head) {
    if (head == null) return null;

    // 1. 穿插复制：A → A' → B → B' → C → C'
    Node p = head;
    while (p != null) {
        Node copy = new Node(p.val);
        copy.next = p.next;
        p.next = copy;
        p = copy.next;
    }

    // 2. 设置 random：copy.random = old.random.next
    p = head;
    while (p != null) {
        if (p.random != null) {
            p.next.random = p.random.next;
        }
        p = p.next.next;
    }

    // 3. 拆分：恢复原链表 + 提取新链表
    Node newHead = head.next;
    Node p1 = head, p2 = newHead;
    while (p2.next != null) {
        p1.next = p2.next;       // 恢复原链表
        p2.next = p2.next.next;  // 连接新链表
        p1 = p1.next;
        p2 = p2.next;
    }
    p1.next = null;  // 最后一个原节点的 next 要指向 null
    return newHead;
}
```

### 复杂度

| 类型 | 复杂度 | 说明 |
|------|--------|------|
| 时间 | O(n) | 穿插 + 设 random + 拆分，各遍历一遍 |
| 空间 | **O(1)** | 不需要额外空间，利用原链表做中转 |

---

## 三种解法对比

| 维度 | 哈希表 | 回溯法 | 迭代穿插 |
|------|--------|--------|---------|
| 时间 | O(n) | O(n) | O(n) |
| 空间 | O(n) | O(n) | **O(1)** |
| 代码量 | 短 | 最短 | 较长 |
| 思路 | 直观（显式映射） | 巧妙（递归+缓存） | 最优（隐式映射） |
| 是否修改原链表 | 否 | 否 | 是（最后恢复） |

---

## 易错点

1. **哈希表法 `map.get(curr.next)` 不怕 null**：`HashMap.get(null)` 返回 null，恰好就是新链表尾部 `next = null` 的正确结果，不需要额外判空
2. **回溯法忘记清空缓存**：`cachedMap` 是静态变量，多次调用必须 `cachedMap.clear()`，否则第二次调用会命中第一次的缓存
3. **穿插法第二步 random 判断**：`p.random` 可能为 null，必须先判空再 `.next`，否则 NPE
4. **拆分法最后 `p1.next = null`**：循环结束时 `p1` 指向最后一个原节点，它的 `next` 还指着新节点，必须手动置 null 恢复原链表
5. **穿插法 `p = copy.next` 不是 `p = p.next`**：`p.next` 已经是新插入的拷贝节点了，要跳到下一个原节点必须走 `copy.next`
