# 算法笔记：完全平方数（力扣 279 题）

## 题目描述
给你一个整数 `n` ，返回和为 `n` 的**完全平方数的最少数量**。

**完全平方数**是一个可以写成某个整数平方的整数，即 `x = k²`（如 `1, 4, 9, 16, ...`）。

```
输入：n = 12
输出：3
解释：12 = 4 + 4 + 4，最少用 3 个完全平方数。

输入：n = 13
输出：2
解释：13 = 4 + 9，最少用 2 个。
```

> 📌 关键理解：完全平方数可以**重复使用**（`12 = 4+4+4` 用了三次 4）。这正是**完全背包**的特征——物品（平方数）无限供应，背包容量是 `n`，要求装满且「件数最少」。

---

## 解法：动态规划（完全背包模型）

### 1. 核心思想
定义状态：`dp[i]` 表示和为 `i` 所需完全平方数的**最少数量**。
* **状态转移**：枚举不超过 `i` 的每个完全平方数 `j*j`，把它当作「最后加的一项」，则问题化为「凑出 `i - j*j` 的最少个数 + 当前这一个」：
  $$dp[i] = \min_{j*j \le i}\big(dp[i - j*j] + 1\big)$$
* **边界（初始化）**：最坏情况是全用 `1`（`1` 是完全平方数）来凑，需要 `i` 个，故先把 `dp[i] = i` 作为上界；`dp[0] = 0`。
* **返回**：`dp[n]`。

> 与「爬楼梯 / 打家劫舍」的固定前驱不同，本题每个 `dp[i]` 要从**多个候选平方数**里挑最优，因此需要内层再枚举 `j`。

### 2. 代码实现 (Java)

```java
class Solution {
    public int numSquares(int n) {
        // dp[i]：组成 i 所需的最少完全平方数个数
        int[] dp = new int[n + 1];

        // 最坏情况：i 全部用 1 来凑，需要 i 个，作为初始上界
        for (int i = 1; i <= n; i++) {
            dp[i] = i;
        }

        // 从小到大递推每个目标和 i
        for (int i = 1; i <= n; i++) {
            // 枚举不超过 i 的每个完全平方数 j*j，尝试用它作为「最后加的一项」
            for (int j = 1; j * j <= i; j++) {
                // 转移：凑出 i - j*j 的最少个数 + 当前这一个平方数
                dp[i] = Math.min(dp[i], dp[i - j * j] + 1);
            }
        }
        return dp[n];
    }
}
```

### 3. 复杂度分析
* **时间复杂度**：$O(n\sqrt{n})$。外层 $n$ 次，内层 `j*j <= i` 约 $\sqrt{i}$ 次，合计约 $n\sqrt{n}$。
* **空间复杂度**：$O(n)$。开了长度为 `n + 1` 的 DP 数组。

### 4. 递推过程图解
以 `n = 12` 为例，看几个关键 `dp[i]` 的求解（候选平方数为 `1,4,9`）：

```text
i    dp[i]初值(=i)   枚举 j*j            dp[i] = min(dp[i], dp[i-j*j]+1)
1       1            1                    min(1, dp[0]+1)=1
2       2            1                    min(2, dp[1]+1)=2
3       3            1                    min(3, dp[2]+1)=3
4       4            1,4                  min(4, dp[3]+1, dp[0]+1)=1  ← 4 本身是平方数
...
12      12           1,4,9                min(12, dp[11]+1, dp[8]+1, dp[3]+1)
                                          = min(12, 4, 3, 4) = 3       ← 4+4+4
返回 dp[12] = 3
```

> 关键：`i=4` 时 `j*j=4` 命中 `dp[0]+1=1`，一步就把上界 4 压到 1；`i=12` 时最优来自 `dp[8]+1`（`8=4+4`，加 1 个 4 得 `4+4+4`）。

---

## 💡 总结
完全平方数是**完全背包 / 凑数最少件数**型 DP 的模板：状态 `dp[i]` 表示凑出 i 的最少件数，内层枚举所有可用「面额」（平方数）取 min，初始化用「全用 1」做上界。

| 特性 | 说明 |
| :--- | :--- |
| **思维出发点** | 每个 i 枚举「最后加一个平方数 j²」，接 `dp[i-j²]+1` 取最小。 |
| **代码表现** | 双重循环：外层目标 `i`，内层面额 `j*j<=i`；先 `dp[i]=i` 做上界。 |
| **时间 / 空间** | $O(n\sqrt{n})$ / $O(n)$。 |

> ⚠️ 对比[打家劫舍](Hot198-打家劫舍.md)：打家劫舍是「**前驱固定**（i-1 / i-2）的一维 DP」，单循环即可；本题是「**前驱不固定**（i-j² 有 √i 种）的完全背包」，必须内层再枚举平方数。两者初始化也不同：打家劫舍填真实边界 `dp[0]`/`dp[1]`，本题填「全用 1」的上界 `dp[i]=i`。
