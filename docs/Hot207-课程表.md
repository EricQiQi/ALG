# LeetCode 207. 课程表 (Course Schedule) - Java DFS 解法

这道题在本质上是一个**判断有向图里有没有“环”**的问题。

## 💡 大白话解析

想象一下你在大学选课，或者在游戏里点天赋树。你想学“高级魔法（课程A）”，前提是必须先学“初级魔法（课程B）”。
那如果出现了这种情况：学 A 需要先学 B，学 B 需要先学 C，而学 C 又需要先学 A。这就是个**死循环（环）**，你这辈子都毕不了业了！

所以，这道题就是让我们去查一查，给定的这些课程依赖关系里，**有没有这种“死循环”**。

**DFS（深度优先搜索）解法的核心思路：三色标记法**

我们可以顺藤摸瓜地去检查每门课。为了防止迷路或者重复检查，我们给每门课准备三种状态（就像三种颜色的标签）：

1.  **状态 0（白色/未访问）**：这门课咱们还没查过。
2.  **状态 1（黄色/正在检查）**：我们正在顺藤摸瓜检查这门课和它的后续课程。**⚠️ 核心逻辑：如果在顺藤摸瓜的过程中，又碰到了标记为“状态1”的课，说明我们绕了一圈又回来了，发现了死循环！**
3.  **状态 2（绿色/安全）**：这门课和它所有的后续课程咱们都查完了，没有死循环，绝对安全。

## 💻 Java 代码实现 (DFS)

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public boolean canFinish(int numCourses, int[][] prerequisites) {
        // 1. 把枯燥的数组转换成“图”（邻接表）
        // 比如 graph.get(1) 里面装的都是学完 1 之后才能学的后续课程
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < numCourses; i++) {
            graph.add(new ArrayList<>());
        }
        for (int[] pre : prerequisites) {
            // pre = [想要学的课, 必须先学的课] -> pre[0], pre[1]
            // 所以方向是：学完 pre[1] -> 解锁 pre[0]
            graph.get(pre[1]).add(pre[0]);
        }

        // 2. 状态数组（0: 没查过, 1: 正在查, 2: 查过且安全）
        int[] visited = new int[numCourses];

        // 3. 对每一门还没查过的课，进行顺藤摸瓜 (DFS)
        for (int i = 0; i < numCourses; i++) {
            if (visited[i] == 0) {
                // 如果在顺藤摸瓜的过程中发现了死循环（返回 false），那直接整体完蛋
                if (!dfs(graph, visited, i)) {
                    return false;
                }
            }
        }
        
        // 所有的课都查过了，都没发现死循环，恭喜，可以毕业！
        return true;
    }

    // DFS 顺藤摸瓜函数
    private boolean dfs(List<List<Integer>> graph, int[] visited, int course) {
        // 如果顺藤摸瓜碰到了一门“正在查”的课，说明绕成环了！
        if (visited[course] == 1) {
            return false;
        }
        // 如果碰到了已经确认“安全”的课，说明这条路没问题，直接放行
        if (visited[course] == 2) {
            return true;
        }

        // --- 走到这里说明是一门没查过的课 (visited[course] == 0) ---
        
        // 把当前这门课标记为“正在查”（打上黄色标签）
        visited[course] = 1;

        // 遍历所有学完这门课就能解锁的“后续课程”
        for (int nextCourse : graph.get(course)) {
            // 继续往下摸瓜，如果有任何一条路发现了死循环，直接把坏消息传回去
            if (!dfs(graph, visited, nextCourse)) {
                return false;
            }
        }

        // 这门课的所有后续之路都走通了，没有死循环。
        // 给它盖上“安全”的章（打上绿色标签）
        visited[course] = 2;
        
        return true;
    }
}
```

## 🧠 总结一下执行流程

1. 我们拿出一门没看过的课，贴上`正在查 (1)`的标签。
2. 顺着这门课去找它解锁的下一门课。
3. 如果下一门课也是`正在查 (1)`，抓到了！这就是个**死循环**，直接返回 `false`。
4. 如果下一门课没问题，就继续往下找。等顺着这门课所有的后续路线都探到底都没发现问题时，把这门课标记为`安全 (2)`，返回 `true`。
