# 算法笔记：单词拆分（力扣 139 题）

## 题目描述
给你一个字符串 `s` 和一个字符串列表 `wordDict` 作为字典。如果可以利用字典中出现的一个或多个单词**拼接**出 `s`（单词可重复使用），则返回 `true`；否则返回 `false`。

```
输入：s = "leetcode", wordDict = ["leet", "code"]
输出：true
解释："leetcode" 可由 "leet" 和 "code" 拼接而成。

输入：s = "catsandog", wordDict = ["cats", "dog", "sand", "and", "cat"]
输出：false
```

> 📌 关键理解：把字符串「长度」当背包容量、字典单词当「物品」（无限供应），问题化为**完全背包的「能否装满」**——前 `i` 个字符能否被完整拆分。与[完全平方数](Hot279-完全平方数.md)、[零钱兑换](Hot322-零钱兑换.md)同族，只是目标从「最少数」换成「可行性」。

---

## 解法：动态规划（完全背包 · 可行性）

### 1. 核心思想
定义状态：`dp[i]` 表示字符串的**前 `i` 个字符**（即 `s[0..i-1]`）能否被字典完整拆分。
* **状态转移**：枚举分割点 `j`（`0 <= j < i`），若「前 `j` 个字符可拆分（`dp[j]`）」且「子串 `s[j..i-1]` 在字典里」，则前 `i` 个字符也可拆分：
  $$dp[i] = \bigvee_{0 \le j < i}\big(dp[j]\ \land\ \text{dict.contains}(s[j..i-1])\big)$$
* **边界**：`dp[0] = true`（空串不需要任何单词，视为可拆分）。
* **返回**：`dp[n]`（整个字符串能否拆分）。

> 可行性用 **or** 语义：只要存在**一个**合法分割点 `j` 让前 `i` 个可拆，就置 `true` 并可 `break` 提前结束内层循环。

### 2. 代码实现 (Java)

```java
class Solution {
    public boolean wordBreak(String s, List<String> wordDict) {
        Set<String> set = new HashSet<>(wordDict); // 字典转 Set，contains 提速
        int n = s.length();
        boolean[] dp = new boolean[n + 1]; // dp[i]：前 i 个字符能否被拆分
        dp[0] = true; // 空串视为可拆分

        for (int i = 1; i <= n; i++) {           // 外层背包：前 i 个字符
            for (int j = 0; j < i; j++) {        // 内层枚举分割点
                // 前 j 个可拆 且 s[j..i-1] 在字典 → 前 i 个可拆
                if (dp[j] && set.contains(s.substring(j, i))) {
                    dp[i] = true;
                    break; // 找到一个可行分割即可
                }
            }
        }
        return dp[n];
    }
}
```

### 3. 复杂度分析
* **时间复杂度**：$O(n^3)$。外层 $n$、内层 $n$，内层 `substring` 取子串本身 $O(n)$（`set.contains` 的哈希比较也 $O(\text{len})$）。
* **空间复杂度**：$O(n + k)$。`dp` 数组 $O(n)$，字典 `Set` $O(k)$（$k$ 为字典字符总量）。

### 4. 递推过程图解
以 `s = "leetcode"`，字典 `["leet","code"]` 为例（下标表示前 i 个字符）：

```text
i    前缀          枚举分割点 j                          dp[i]
0    ""            ——                                    true（边界）
1-3  "l".."lee"    无合法 j（"l","le","lee" 均不在字典）  false
4    "leet"        j=0: dp[0]=true 且 "leet"∈字典         true
5-7  "leetc"..     需 dp[j]=true 且剩余在字典，均不满足    false
8    "leetcode"    j=4: dp[4]=true 且 "code"∈字典         true
返回 dp[8] = true
```

> 关键：`dp[4]=true` 是「桥」——前半段 `"leet"` 可拆，后半段 `"code"` 又在字典，拼起来整个串就可拆。

---

## 💡 总结
单词拆分是**完全背包「能否装满」型** DP：状态 `dp[i]` 表示前 i 个字符能否拆分，用「存在一个分割点 j 使 `dp[j]` 为真且剩余在字典」的 **or** 语义转移，找到一个即 `break`。

| 特性 | 说明 |
| :--- | :--- |
| **思维出发点** | 前 i 个可拆 ⇔ 存在分割点 j：前 j 可拆 且 `s[j..i-1]` 在字典。 |
| **代码表现** | 外层 i（背包）、内层 j（分割点）；`dp[0]=true` 起步，字典转 Set 提速。 |
| **时间 / 空间** | $O(n^3)$ / $O(n+k)$。 |

> ⚠️ 与背包族的对应：本题求「**能否装满**」（可行性，or 语义），与 [279/322](Tip6-背包问题分类.md) 求「**最少数**」（min 语义）互为姊妹题——状态骨架相同，只换转移运算符。三者都是完全背包（物品可重复使用）。
