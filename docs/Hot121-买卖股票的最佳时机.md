# 买卖股票的最佳时机（Best Time to Buy and Sell Stock）

## 题目描述

给定一个数组 `prices`，它的第 `i` 个元素 `prices[i]` 表示一支给定股票第 `i` 天的价格。

你只能选择**某一天**买入这只股票，并选择在**未来的某一个不同的日子**卖出该股票。设计一个算法来计算你所能获取的**最大利润**。

返回你可以从这笔交易中获取的最大利润。如果你不能获取任何利润，返回 `0`。

```
输入：prices = [7,1,5,3,6,4]
输出：5
解释：在第 2 天（价格 = 1）买入，第 5 天（价格 = 6）卖出，利润 = 6 - 1 = 5
     注意利润不能是 7 - 1 = 6，因为卖出价格需要大于买入价格

输入：prices = [7,6,4,3,1]
输出：0
解释：一直跌，没有任何交易能获得利润，返回 0
```

源码位置：[`../src/s14_greedy/Hot121_maxProfit.java`](../src/s14_greedy/Hot121_maxProfit.java)

---

## 核心思路

只买卖**一次**，本质是：对每一天，问「如果今天卖出，我最多能赚多少？」答案就是 `今天价格 - 今天之前的历史最低价`。遍历一遍，一路维护**历史最低买入价**并**打擂台记录最大利润**即可。

```
        价格
   7 ●
   6 │          ●
   5 │    ●           ● 3
   4 │                     ●
   1 │●
     └──────────────────────────► 天
       low 一路记录到此刻的最低点，每天用 price - low 试算利润
```

- `low`：遍历到当前位置为止的**历史最低价**（最佳买入点）。
- `res`：**全局最大利润**，每天用「今天价格 − 历史最低价」更新。

> 贪心点：局部每一天都做出「以历史最低价买入、今天卖出」的最优选择，全局最大值自然在其中。这也是一个只含两个状态变量的极简 **动态规划**（`low` 是「前 i 天最小值」的状态，`res` 是「前 i 天最大利润」的状态）。

---

## 方法：一次遍历（维护历史最低价）

### 代码

```java
public int maxProfit(int[] prices) {
    // low：遍历到当前位置为止的历史最低买入价
    int low = Integer.MAX_VALUE;
    // res：全局最大利润（当天卖出能赚到的最多钱）
    int res = 0;
    for (int price : prices) {
        // 更新历史最低价：今天更便宜就把它当作新的买入点
        low = Math.min(low, price);
        // 假设今天卖出，利润 = 今天价格 - 历史最低买入价，打擂台记录最大值
        res = Math.max(res, price - low);
    }
    return res;
}
```

> 顺序很关键：**先更新 `low` 再算利润**，保证「同一天既买又卖」时利润为 `price - price = 0`，不会出现负利润（当天买当天卖利润本就是 0，符合题意）。

### 复杂度

| 类型 | 复杂度 | 说明 |
|------|--------|------|
| 时间 | O(n) | 只遍历数组一遍 |
| 空间 | O(1) | 只用 `low`、`res` 两个变量 |

> 暴力双循环枚举所有「买入天 × 卖出天」是 O(n²)，一次遍历把它压到 O(n)，是本题的最优解。

## 遍历过程图解

以 `prices = [7,1,5,3,6,4]` 为例：

```
天/价格    low(历史最低)   price - low   res(最大利润)
  7          7               0            0
  1          1               0            0
  5          1               4            4
  3          1               2            4
  6          1               5            5   ← 最大
  4          1               3            5
```

最终 `res = 5`（第 2 天以 1 买入、第 5 天以 6 卖出）。

---

## 易错点

1. **更新顺序**：建议**先 `low = min(low, price)` 再算 `price - low`**，语义最清晰（今天价格减今天及之前的最低点）。若反过来先算利润再更新 low，在最低点那天会算出 `price - 旧low` 的负值（被 res 忽略），结果虽仍正确但容易绕晕。
2. **`low` 初始值**：用 `Integer.MAX_VALUE`，保证第一天一定会更新为 `prices[0]`。
3. **`res` 初始为 0 而非负数**：题目规定不能获利就返回 0，全程下跌时 `price - low ≤ 0`，`res` 保持 0 正好符合要求。
4. **只能买卖一次**：本题限制单次交易，不能像「买卖股票 II」那样把所有上涨段利润累加。
5. **卖出必须在买入之后**：因为 `low` 只记录**当前及之前**的最低价，天然保证了买入日 ≤ 卖出日，无需额外判断。
