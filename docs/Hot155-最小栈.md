# LeetCode 155. 最小栈

对应源码：[Hot155_MinStack_1.java](../src/s12_stack/Hot155_MinStack_1.java)（辅助栈）、[Hot155_MinStack_2.java](../src/s12_stack/Hot155_MinStack_2.java)（单栈存差值）

## 题目描述

设计一个支持 `push`、`pop`、`top` 操作，并能在**常数时间**内检索到最小元素的栈。

- `push(x)` —— 将元素 x 推入栈中
- `pop()` —— 删除栈顶的元素
- `top()` —— 获取栈顶元素
- `getMin()` —— 检索栈中的最小元素

## 💡 大白话解析

普通栈的 `push/pop/top` 都是 O(1)，唯一的难点是 **`getMin()` 也要 O(1)**。

如果每次 `getMin()` 都遍历一遍栈，那是 O(n)，不合格。核心矛盾在于：**栈顶元素弹掉之后，最小值可能"变回去"，所以必须把历史最小值也记下来。**

两种记录方式：

| 方法 | 记什么 | 空间 |
| :--- | :--- | :---: |
| 方法一：辅助栈 | 每个位置**当时的最小值**，和数据栈同步升降 | 2n |
| 方法二：差值栈 | 每个位置和当时最小值的**差值**，外加一个 min 变量 | n + 1 |

## 方法一：辅助栈（同步栈）

再开一个栈 `minstack`，让它和数据栈**同高**：

```
数据栈    minstack（栈顶 = 当前最小值）
  -3   ←    -3      push(-3)：min(-2, -3) = -3
   0   ←    -2      push(0) ：min(-2,  0) = -2
  -2   ←    -2      push(-2)：min(MAX,-2) = -2
         MAX_VALUE  哨兵（构造函数垫入）
```

`pop` 时两个栈一起弹，`minstack` 的栈顶就自动回退成"弹之前那一层的最小值"，**不需要任何计算**。

```java
class MinStack {
    Deque<Integer> stack;      // 数据栈
    Deque<Integer> minstack;   // 辅助栈：栈顶 = 当前最小值

    public MinStack() {
        stack = new ArrayDeque<>();
        minstack = new ArrayDeque<>();
        minstack.push(Integer.MAX_VALUE);   // 哨兵，省去 push 时的判空
    }

    public void push(int x) {
        stack.push(x);
        minstack.push(Math.min(minstack.peek(), x));
    }

    public void pop() {
        stack.pop();
        minstack.pop();     // 必须同步弹
    }

    public int top()    { return stack.peek(); }
    public int getMin() { return minstack.peek(); }
}
```

## 方法二：单栈存差值

只留一个栈，但**栈里不存原值，存差值** `diff = value - 入栈时的 minvalue`，再用一个变量 `minvalue` 记住当前最小值。

关键洞察：

- `diff < 0` → 新值比旧最小值还小，**它自己就是新的最小值**
- `diff >= 0` → 最小值没变，原值可以用 `minvalue + diff` 还原

以 `push(-2) → push(0) → push(-3)` 为例：

```
操作          栈内 diff（底→顶）    minvalue    说明
push(-2)      [ 0 ]                 -2         空栈特殊处理：diff 记 0
push(0)       [ 0, 2 ]              -2         0 - (-2) = 2 ≥ 0，min 不变
push(-3)      [ 0, 2, -1 ]          -3         -3 - (-2) = -1 < 0，刷新 min
pop()         [ 0, 2 ]              -2         弹到 -1 < 0 → min = -3 - (-1) = -2
top()         —                     -2         栈顶 diff=2 ≥ 0 → 原值 = -2 + 2 = 0
```

`pop` 弹到负差值时，说明**弹掉的正是当前最小值本身**，需要回滚。回滚公式由定义直接反推：

> 入栈时 `diff = 新min - 旧min`，所以 `旧min = 新min - diff`

```java
class MinStack {
    Deque<Long> stack;   // 差值栈，用 long 防溢出
    long minvalue;

    public void push(int value) {
        if (stack.isEmpty()) {
            stack.push(0L);        // 空栈：自己减自己
            minvalue = value;
        } else {
            long diff = value - minvalue;
            stack.push(diff);
            if (diff < 0) minvalue = value;   // 刷新最小值
        }
    }

    public void pop() {
        long val = stack.pop();
        if (val < 0) minvalue = minvalue - val;   // 弹掉的是最小值，回滚
    }

    public int top() {
        long top = stack.peek();
        return top < 0 ? (int) minvalue : (int) (minvalue + top);
    }

    public int getMin() { return (int) minvalue; }
}
```

## 复杂度分析

| 方法 | push / pop / top / getMin | 空间 |
| :--- | :---: | :---: |
| 方法一 辅助栈 | 全部 O(1) | O(n)，两个等长栈 |
| 方法二 差值栈 | 全部 O(1) | O(n)，一个栈 + 一个变量 |

## ⚠️ 易错点

1. **辅助栈忘了同步 pop**：只弹数据栈不弹 `minstack`，两栈错位后最小值全乱。
2. **差值栈用 `int` 存 diff**：`value - minvalue` 在极端值（如 `Integer.MIN_VALUE - Integer.MAX_VALUE`）会溢出，**必须用 `long`**。
3. **`pop` 时把回滚条件写成 `val <= 0`**：`diff == 0` 表示新值和当时最小值相等，弹掉它之后最小值仍然是同一个数，**不需要回滚**；只有严格 `< 0` 才回滚。
4. **`top()` 忘了分情况**：栈顶 `diff < 0` 时原值就是 `minvalue` 本身，不能再 `minvalue + diff`（那会算出比最小值还小的数）。
5. **空栈 `push` 的特殊处理**：方法二里空栈时 `minvalue` 还没赋值，必须先定 `minvalue = value` 再压 `0L`，顺序反了差值就错了。
6. **API 命名**：本题解中方法名为 `min()`，LeetCode 标准接口是 `getMin()`，提交时注意改名。

## 🧠 方法对比与选型

| 维度 | 辅助栈 | 差值栈 |
| :--- | :--- | :--- |
| 理解难度 | 低（直观同步） | 高（要推回滚公式） |
| 空间 | 2n | n + 1 |
| 溢出风险 | 无 | 有，需 long |
| 面试推荐 | ✅ 首选，讲得清 | 加分项，被追问"能否省空间"时抛出 |

## 🧠 记忆口诀

> **辅助栈：同高同降，弹了就回退。**
> **差值栈：负数即最小，弹出负数 `min -= diff` 回滚；top 看正负，负取 min、正取 min+diff。**
