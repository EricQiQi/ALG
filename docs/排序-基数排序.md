# 排序算法

## 基数排序 (Radix Sort)

### 核心思想

> **从最低位到最高位，逐位做计数排序——每一轮只关心当前位的数字（0\~9）**

不用比较大小，而是按"位"分配。先从个位排起，再排十位、百位……高位排序不会打乱低位已经排好的相对顺序（因为高位相等时就看低位，低位有序就整体有序）。排完最大位数的轮数，数组就彻底有序。

---

### 图像记忆法：逐位上色，低位到高位

```
原始 [170, 45, 75, 90, 802, 24, 2, 66]   max=802 → 3 位

第 1 轮 exp=1（个位）：只按个位 0,5,5,0,2,4,2,6 计数排序
  → [170, 90, 802, 2, 24, 45, 75, 66]
       ↑个位 0 的在前，2 次之，4 次之，5 次之...

第 2 轮 exp=10（十位）：只按十位 7,9,0,0,2,4,7,6 计数排序
  → [802, 2, 24, 45, 66, 170, 75, 90]
       ↑十位 0 的在前（802/2 十位都是 0，但个位 2<0 已在上一轮保序）

第 3 轮 exp=100（百位）：只按百位 1,0,0,0,8,0,1,0 计数排序
  → [2, 24, 45, 66, 75, 90, 170, 802]
       ↑百位 0 的在前 → 百位相同的看十位→看个位 → 前轮已排好 → 自然有序

每轮只关心一位数字（0-9），用 10 格计数排序
```

**为什么高位排序不会打乱低位？** 因为若两个数当前高位相同，这一轮它们被分到同一个格子里；稳定计数排序保证同格内相对顺序不变——也就是沿用了上一轮按低位排好的顺序。

### 代码结构速记

```
radixSort(arr)
├── max = 找最大值（决定排几轮）
├── for (exp = 1; max / exp > 0; exp *= 10)   ← 逐位：个→十→百→...
│   └── countingSortByDigit(arr, exp)
│       ├── count[10]                         ← 只有 0~9 十个格
│       ├── for 前→后: count[digit]++         ← 统计当前位每个数字出现几次
│       ├── for 前缀和: count[i] += count[i-1] ← 算出"≤ i 的总共几个"= 落位上界
│       ├── for 后→前:                          ← 倒序放置保稳定！
│       │   ├── output[count[digit] - 1] = arr[i]
│       │   └── count[digit]--
│       └── 把 output 拷贝回 arr
└── 结束
```

---

### 关键易错点

**1. `exp *= 10` 逐位推进，终止条件 `max / exp > 0`**

`exp` 代表当前处理的是哪一位（1→个、10→十、100→百…）。`max / exp == 0` 说明最高位也排完了。用 `max` 而非定死位数，可以自适应少排几轮。

**2. 取当前位的数字：`(arr[i] / exp) % 10`**

先整除把"当前位"挪到个位，再 `%10` 取最后一位。忘了整除或取模都会拿到错误的位。

**3. 内层计数只有 10 格（0\~9）**

每位数字只可能是 0~9，所以 `count` 长度固定 10、不随值域变化。这是基数排序能 O(n) 的关键——每轮计数排序 O(n+10) ≈ O(n)。

**4. 第二轮前缀和 + 倒序放置 = 稳定**

```java
// 前缀和：count[i] 变成 "≤ i 的元素个数"，也就是 i 应该放到的最后一个位置+1
for (int i = 1; i < 10; i++) count[i] += count[i - 1];
// 倒序遍历原数组放置：保证同 digit 元素保持原相对顺序 → 稳定
for (int i = n - 1; i >= 0; i--) {
    output[--count[digit]] = arr[i]; // 先 -- 再用（取最后一个空位）
}
```

如果**正序**遍历，同 digit 的后来者会覆盖先到者的位置，稳定性就毁了。

**5. 只能排非负整数（或先做偏移）**

本实现用整除取位，负数在 Java 中 `/` 向零取整会出问题。要排负数需先平移到非负、排完再移回，或者改用"最高位单独处理符号"的 MSD 写法。

### 复杂度

| | 平均 | 最坏 | 最好 |
|---|---|---|---|
| 时间 | O(d · (n + 10)) ≈ O(d·n) | O(d·n) | O(d·n) |
| 空间 | O(n + 10) ≈ O(n) | O(n) | O(n) |

> d = 最大值的位数（`⌊log₁₀(max)⌋ + 1`）。当 d 是常数或远小于 log n 时，基数排序真正的线性碾压 O(n log n) 比较排序；但如果 max 极大（比如 long 范围），d 可到 19，优势就不那么明显了。

> **记忆口诀**：基数排序逐位排，个十百千轮到完；每轮十格计数排，倒序放置稳如山；高位相同看低位，前轮有序本轮不乱
