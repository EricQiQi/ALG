# 排序算法

## 冒泡排序 (Bubble Sort)

### 核心思想

> **相邻两两比较，大的往后冒：每一轮把当前最大的元素"冒"到末尾**

像水里的气泡，大的越往上浮得越远。每走一轮，末尾就多一个已排好的元素。

---

### 图像记忆法：大数往后冒

```
每一轮从前往后扫，相邻比大小，大的换到后面

[64, 34, 25, 6] 
  ↓ 第 1 轮：最大的 64 冒到最后
[34, 25, 6, | 64]
  ↓ 第 2 轮：次大的 34 冒到倒数第二
[25, 6, | 34, 64]
  ↓ 第 3 轮
[6, | 25, 34, 64]

竖线右边是已排好的"尾巴"，每轮向左缩短一格
```

---

### 一句话记住

```
外层管轮数，内层比相邻，大的往后换，一轮定一个最大值
```

---

### 代码结构速记

```
bubbleSort(array)
├── n = array.length
├── for (i=0; i<n-1; i++)          ← 共 n-1 轮
│   ├── swapFlag = false           ← 本轮是否发生过交换
│   ├── for (j=0; j<n-1-i; j++)    ← 每轮少比已排好的尾巴
│   │   └── if (arr[j] > arr[j+1]) swap + swapFlag=true
│   └── if (!swapFlag) break       ← 一整轮没交换 → 已有序，提前退出
└── 结束
```

---

### 关键易错点

**1. 内层边界是 `j < n-1-i`，不是 `j < n-1`**

- `-1`：因为要访问 `arr[j+1]`，j 最大到 `n-2`，否则越界。
- `-i`：每轮结束后末尾 i 个元素已排好，不用再比，省去无用比较。

**2. 外层是 `i < n-1` 而非 `i < n`**

n 个元素最多 n-1 轮就能全部归位，最后一轮没必要。

**3. `swapFlag` 提前终止是优化点**

若某一轮**一次交换都没发生**，说明数组已经有序，直接 `break`。这让**最好情况（已排序）降到 O(n)**，是冒泡排序区别于朴素写法的关键。

**4. `arr[j] > arr[j+1]` 用 `>` 保证稳定性**

相等时不交换，相同元素的相对顺序不变，所以冒泡是**稳定排序**；改成 `>=` 就会破坏稳定性。

---

### 复杂度

| | 平均 | 最坏 | 最好 |
|---|---|---|---|
| 时间 | O(n²) | O(n²) | O(n)（带 swapFlag）|
| 空间 | O(1) | O(1) | O(1) |

> 最好情况 O(n) 依赖 swapFlag 优化：数组本已有序时，一轮扫描无交换即退出。空间 O(1)，原地排序。

> **记忆口诀**：冒泡相邻比大小，大的往后冒，一轮定一个，无交换就早退
