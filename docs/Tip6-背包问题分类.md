# 背包问题分类

## 一、两个分类维度（总览）

背包问题的「骨架」是同一段 DP：`dp[j]` 表示容量/金额为 `j` 时的最优解。变化只在两个维度上：

```
维度一（按物品可重复性）：01 背包 / 完全背包 / 多重背包 / 分组背包
   → 决定「内层背包遍历方向」（倒序 or 正序）

维度二（按求解目标）：最大价值 / 能否装满 / 最少数 / 方案数
   → 决定「状态含义 + 转移运算符」（max / or / min / sum）
```

> 一句话：**可重复性定遍历方向，求解目标定转移**。两者自由组合，就覆盖了 LeetCode 所有背包题。

---

## 二、维度一：按物品可重复性

| 类型 | 每种数量 | 内层背包方向 | 原因 | 典型题 |
|------|---------|-------------|------|--------|
| **01 背包** | 仅 1 个 | **倒序**（容量 → w[i]） | 保证 `dp[j-w[i]]` 是「上一物品」旧值，每件只选一次 | 416 分割等和子集 |
| **完全背包** | 无限个 | **正序**（w[i] → 容量） | 让 `dp[j-w[i]]` 已是「含当前物品」新值，可重复选 | 322 零钱兑换、279 完全平方数 |
| **多重背包** | 有限 k 个 | 倒序 + 二进制拆分 | 把 k 个拆成若干「01 物品」 | — |
| **分组背包** | 每组最多选 1 | 组内遍历 | 组间互斥 | — |

```
01 背包（倒序）：j 从容量往小走
  dp[j] 用到的 dp[j-w] 还是「没放当前物品」的值 → 每件最多放一次

完全背包（正序）：j 从小往容量走
  dp[j] 用到的 dp[j-w] 可能「已放当前物品」→ 同一物品可反复放
```

> 核心区分一句话：**01 倒序防重选，完全正序允许重选**。

## 三、维度二：按求解目标

同一套骨架，只换「状态含义 + 转移运算符」即可解四类问题：

| 求解目标 | `dp[j]` 含义 | 转移 | 初始化 | 典型题 |
|---------|-------------|------|--------|--------|
| **最大价值** | 容量 j 的最大价值 | `max(dp[j], dp[j-w]+v)` | 全 0 | 经典背包 |
| **能否装满** | 容量 j 能否凑出 | `dp[j] \|= dp[j-w]` | `dp[0]=true` | 416 分割等和子集 |
| **最少数** | 容量 j 的最少件数 | `min(dp[j], dp[j-w]+1)` | 上界哨兵，`dp[0]=0` | 322、279 |
| **方案数** | 容量 j 的方案数 | `dp[j] += dp[j-w]` | `dp[0]=1` | 518 零钱兑换 II |

> 转移运算符与目标一一对应：**最大用 max、可行性用 or、最少数用 min、方案数用 sum(+=)**。

---

## 四、易错：求「方案数」时遍历顺序改变语义

求最值/可行性时，物品/背包谁在外层结果一致（max/min/or 不受顺序影响）。**但求方案数时，顺序决定是「组合」还是「排列」**：

| 目标 | 外层 | 内层 | 语义 | 例子 |
|------|------|------|------|------|
| **组合** | 物品 | 背包（正序） | `{1,2}` 与 `{2,1}` 算同一种 | 518 零钱兑换 II |
| **排列** | 背包（正序） | 物品 | `{1,2}` 与 `{2,1}` 算两种 | 377 组合总和 IV |

```
外层物品：先固定物品 1，再把物品 2 往已含 1 的方案上叠
  → 每种物品只在一个「层」被加入，顺序被打消 → 组合

外层背包：对每个金额 j 都尝试所有物品
  → 同一金额下不同加入顺序被分别计数 → 排列
```

> 记忆：**外层物品 = 组合，外层背包 = 排列**。求「最少数」（如 322）无此讲究，min 自动去序。

## 五、本项目中的背包题

| 题目 | 类型 | 求解目标 | 状态与转移 |
|------|------|---------|-----------|
| [279 完全平方数](Hot279-完全平方数.md) | 完全背包 | 最少数 | `dp[i]=min(dp[i-j*j]+1)`，初始化 `dp[i]=i` 上界 |
| [322 零钱兑换](Hot322-零钱兑换.md) | 完全背包 | 最少数 | `dp[j]=min(dp[j-coin]+1)`，哨兵 `amount+1` 表「凑不出」 |

> 两题同构：平方数/硬币都无限供应、求「凑满最少件数」。区别仅在「面额来源」（枚举平方数 vs 给定数组）与「是否可能无解」（322 可能凑不出需返回 -1，279 必能用 1 凑出）。

## 六、速记

```
按数量分：01(倒序) / 完全(正序) / 多重(拆分) / 分组(组间互斥)；
按目标分：最大价值 max、可行性 or、最少数 min、方案数 sum；
方案数再看顺序：外层物品=组合，外层背包=排列；
最值/可行性不挑顺序，方案数才挑。
```
